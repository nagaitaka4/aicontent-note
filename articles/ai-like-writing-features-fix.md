# AIっぽい文章の特徴と直し方。直す前と後を並べた

==AIっぽい文章の特徴の1つは、動詞で言う所を名詞や決まり文句にすることです。==
「継続課金の理由になりません」は、言葉としては正しくても、話すときにはまず使いません。
ほかにも、1文に話を2つ詰めこむ、同じ文末が続くといった形があります。

---

## AIっぽい文章の特徴：名詞や決まり文句で言っている所

==名詞や決まり文句は、話すときの言葉に直すと固さが減ります。==
下の表は、ChatGPTの料金の記事で人が直した文です。
使わない言葉のリストで調べると0件でしたが、直した所は20か所以上ありました。

| 直す目印 | 直す前（AIの下書き） | 直した後 |
|---|---|---|
| **動詞に戻せる名詞**「継続課金」 | 継続課金の理由になりません | ==**有料を続ける**理由になりません== |
| **決まり文句**「取れる手」 | どちらに当たるかで、取れる手が変わります | どちらなのかで、**やること**が変わります |
| **「〜状態です」で止める** | 使える場所が狭い状態です | 使える場所が**限られます** |

自分の文章で探すときは、漢字の名詞が文の主語や目的語になっている所を見ます。
声に出して読み、話すときに言わない言い方なら、動詞に戻します。

---

## 名詞のほかにもある、AIっぽい文の形と直し方

==名詞のほかに人が直すことが多いのは、文のつなぎ方と終わり方です。==
どれも、このサイトで記事やX投稿を書くときに、実際に直してきた形です。

| 形 | 例 | 直し方 |
|---|---|---|
| ==**1文に話を2つ詰めこむ**== | 「〜が効き、一方で、〜は逆になります」 | **2文に分ける**（下に実例） |
| **まとめ・つなぎの決まり文句** | 「ここまで3つの方法を説明してきました」「という点が重要です」 | **削って**、言いたいことから書く |
| **文の始めのつなぎが多い** | 「また、」「さらに、」「次に、」が3回続く | **減らして**、文を短く切る |
| **同じ文末が続く** | 「〜ています。」が4文続く | 1つ**変える**か、文をまとめる |
| **「〜させる」が続く** | 「集めさせて、まとめさせた」 | **誰が何をするか**を主語にして書く |
| **何のことかが抜けた言葉** | 「明確なライン」 | 「どこまで似たら**パクリかの線**」と書く |
| **資料の言い分で終わる** | 「◯◯は〜としています」 | **読む人にとって何が変わるか**まで書く |

### 1文に話を2つ詰めこむと、何が逆なのか分からなくなる

AIと書いた別の記事で、人が読んで直した文です。

【バッド】<br>
ブログ運営はルールを手元に残せるかが効き、一方で、散った数字を1枚にまとめる作業は逆になります。

【グッド】<br>
ブログ運営で効いてくるのは、トンマナや禁止事項を手元のファイルに残せることです。<br>
逆に、複数のツールに散った数字を1枚にまとめる作業では、この強みが活きません。

直す前の文は、「何が効くのか」「何が逆なのか」を読む人が補わないと分かりません。
2文に分けると、1文に話が1つになり、対比も「逆に、」の一言で伝わります。

## 読む人は、どこでAIっぽいと感じる？

[広島大学の卒業論文](https://home.hiroshima-u.ac.jp/jshira/papers/AI%E7%94%9F%E6%88%90%E6%96%87%E3%81%8B%E3%82%89%E3%81%BF%E3%81%9F%E3%80%8C%E8%87%AA%E7%84%B6%E3%81%AA%E6%97%A5%E6%9C%AC%E8%AA%9E%E3%80%8D%E3%81%AB%E3%81%A4%E3%81%84%E3%81%A6%E3%81%AE%E7%A0%94%E7%A9%B6%EF%BC%88%E5%A4%A7%E8%A5%BF%E5%A4%A2%EF%BC%89.pdf)では、20代16人が文章を読んで、「AIらしい」「人間らしい」と感じた所を書いています。
==AIらしいと感じた所で多かったのは、具体性のない中身と、普段使わない言葉==でした。

【ポイント】<br>
「福音に他ならない」という言い方を、一般の人が使うとは思えないと挙げた人もいました。

【メモ】<br>
卒業論文で、学術誌に載った研究ではありません。<br>
使ったAIには、古いモデル（GPT-3.5）も入っています。

## AIっぽい文章を直すときのプロンプト

==AIに頼むときは、使わない言葉を並べるより、「主語を人か物に戻し、動詞で書く」と書き方を指示します。==

記事を書くAIに、私が毎回読ませている指示から3行を抜き出します。

【ペン】<br>
・人が声に出して言わない言い回しを書かない<br>
・主語を人か物に戻し、動詞で書く<br>
・声に出して読んで、言いにくければ直す

AIに直させるなら、下書きと一緒にこの3行を渡してください。
直した所を前と後で並べてもらうと、どこが変わったかを自分の目で確かめられます。

機械で拾える言い回しは、使わない言葉のリストにもしています。
「を余儀なく」「に他なりません」「と言えるでしょう」などです。

【アラート】<br>
この3行とリストを使って書いた記事でも、私が読み返して「AI丸出し」と感じたことがあります。<br>
指示で減らしても、最後は人が読んで直します。

## AIっぽいかどうかは、ツールより読み返して確かめる

私が作った[AIっぽい文章チェッカー](https://aicontent-note.com/ai-like-text-checker/)は、AIっぽく読まれやすい所に、直し方の例つきで印を付ける無料ツールです。
==このツールでは、AIが書いたかどうかは判定できません。==

### 使い方

・**貼る**：X投稿やメール、ブログ記事などを、入力欄に貼る。記事を丸ごと貼ってもよい<br>
・**出た所を読み返す**：結果は「AIっぽく読まれやすい所」「伝わりにくい言い回し」「X投稿の文字数」に分かれて出る<br>
・**自分でも読む**：0件でも、最後は声に出して読み返す

スマホでも、同じ画面で使えます。
文章を貼るとその場で結果が出て、貼った文章はどこにも送られず、保存もされません。

### チェッカーが拾う形と、拾わない形

| この記事で紹介した形 | チェッカーで |
|---|---|
| 「〜の要否」のような、決まった言い回し | **拾う** |
| まとめ・つなぎの決まり文句 | **拾う** |
| 文の始めのつなぎ（3回以上） | **拾う** |
| 同じ文末（4文以上） | **拾う** |
| 使役（させる）の重なり | **拾う** |
| 何のことかが抜けた言葉 | **1行目だけ**拾う |
| 継続課金のような、記事ごとに変わる名詞と、状態ですで止める文 | ==**拾わない**== |
| 1文に話を2つ詰めこむ | ==**拾わない**== |

拾う形は、このサイトの公開記事70本で試し、ふつうの文章に出すぎる形を外して決めました。
名詞の形は記事ごとに変わるので、一覧にしても追いつきません。
