# AIの定期実行で寝ている間の作業を任せるには？指示に書く5つのこと

寝ている間は、パソコンを閉じても動く仕組みか、スリープしないパソコンに任せます。
指示は、==目標・完了の条件・見たい証拠・前提・守ることの5つ==に分けて書く方法があります。
私も毎朝の調査を2か月以上AIに任せていますが、投稿や公開は結果を読んでから自分で決めています。

---

## どこで動くか。AIの定期実行4つの違い

Claude Codeのデスクトップのタスクは、スリープ中やふたを閉じている間は飛ばされます。
閉じたまま動かしたいなら、クラウドで動くタスクを選びます。

| 定期実行 | どこで動くか（2026年11月時点の公式ヘルプ） | 間隔と上限 |
|---|---|---|
| [Claude Code（デスクトップのスケジュールタスク）](https://code.claude.com/docs/ja/desktop-scheduled-tasks) | **自分のパソコン**。アプリが開いていて、スリープしていない間だけ動く。ふたを閉じるとスリープする。過去7日間に飛ばした分は、起きたあとに直近の1回だけ実行 | Claudeに頼めば1分ごとから（画面の入力欄からは1時間ごと） |
| [Claude Code（クラウドのスケジュールタスク）](https://code.claude.com/docs/ja/routines) | ==クラウド。ノートパソコンを閉じていても動く==。手元のパソコンのファイルには直接アクセスできない | 1時間ごとから・Pro以上の有料プラン |
| [ChatGPT（スケジュール済みタスク）](https://help.openai.com/ja-jp/articles/10291617-scheduled-tasks-in-chatgpt) | バックグラウンドで処理する。パソコンを閉じたときの動きは、ヘルプに書かれていない | 有効にできるタスクは無料3件〜Pro 15件。無料の繰り返しは1日1回までで、1時間ごとや正確な時刻の指定は有料プラン |
| [Gemini（アプリのスケジュール）](https://support.google.com/gemini/answer/16316416?hl=ja) | バックグラウンドで準備し、決めた時刻までに用意する。パソコンを閉じたときの動きは、ヘルプに書かれていない | 毎日・毎週・毎月の繰り返し。同時に10個まで |

私は毎朝の調査をデスクトップのタスクで動かしていて、67日のうち65日は動いた記録が残りました。
ChatGPTとGeminiのタスクは使っていないので、ヘルプに書かれている範囲だけを並べています。

## 指示に書く5つのこと

[カンリーのテックブログ（Zenn）](https://zenn.dev/canly/articles/ca6875cd79539f)で紹介されていたAIによる開発の事例では、指示に書くことを5つに分けていました。
私が毎朝動かしている調査の指示に当てはめると、次のようになります。

| 書くこと | 中身 | 例えば（私の毎朝の調査） |
|---|---|---|
| **目標** | 何のために動かすか | その日の調査の結果を、朝のうちに用意する |
| **完了の条件** | 何が出そろったら終わりか | 決めた項目を出したら終わり。材料が無い日は0件で終えてよい |
| **見たい証拠** | 報告に何を付けさせるか | ==製品名や数字には、公式の出典のURLと原文を付ける== |
| **前提** | すでに分かっていること | 読んでほしいファイルと、その順番を書く |
| **守ること** | してはいけない操作 | 投稿・送信はしない / ブラウザは読むだけ / 書き換えてよいファイルを決める |

### 使える型の例

［例：〜］の所を、自分の作業に置き換えて使えます。

```
実行する時間：［例：毎朝］
目標：［例：AI関連のニュースを調べて、重要なものを最大3つ選ぶ］
完了の条件：［例：ニュースの題・要点1行・出典のURLを並べたら終わり］
当てはまるものが無い日は0件でよい。
見たい証拠：製品名・数字・日付には、公式の出典のURLと原文を付ける
前提：［例：私は中小企業向けのAI活用の記事を書いている］
守ること：送信・投稿・購入はしない。
結果は報告するだけにする。
```

## 思いどおりにならなかった日に分かったこと

指示どおりに動いたのに、困ったこともありました。

| 起きたこと | 原因 | 直したこと |
|---|---|---|
| **祝日に、出すはずのものを出さずに終えた** | 指示に「土日祝はこの手順をしない」と書いていた | ==止める条件を「材料が無いとき」だけにした== |
| **前日に直した内容が、朝の結果に入っていなかった** | 直した内容をファイルに保存していなかった | 直した版をファイルに入れ直した |
| **2本の定期実行を別々に動かしたら、片方の結果をもう片方が使えなかった** | 同じ朝に別々に動いていて、結果を受け渡していなかった | 1本にまとめた |

## 投稿・送信・公開は人が決める

朝に結果を読んで決めやすいように、指示の最後に「判断が要る点」を1〜3行、AIがすすめる案から書かせています。

・**私がAIに任せること**：調べる / まとめる / 出典を付ける<br>
・**私が自分で決めること**：投稿、送信、公開 / 出たものを使うかどうか

指示に「送信しない」と書くことと、設定で送信できないようにすることは別です。
操作を制限する設定は、[Claude Codeの許可、どこまで自動でいいか。モードの選び方](https://aicontent-note.com/claude-code-permission-modes/)にまとめています。
