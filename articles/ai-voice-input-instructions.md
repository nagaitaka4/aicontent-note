# AIへの指示は音声入力で速くなる？手打ちに戻った理由と向く場面

AIへの指示が音声入力で速くなる人はいます。
私の場合、==言いたいことがまとまっているときは楽==でした。
長く話すと誤字脱字の書き直しが増え、手打ちのほうが速く感じました。

---

## 音声入力で速くなるという人の理由

[レバテックLAB](https://levtech.jp/media/detail_972/)に、AIへの指示をほぼ音声で出している人のインタビューがあります。
ChatGPTやClaudeに付いている音声入力ではなく、有料の専用アプリを使っているそうです。

| 理由 | 中身 |
|---|---|
| **打つより速く入る** | その人の体感では、タイピングの3倍以上。測ってはいないそうです |
| **長い指示を最初から出せる** | 打つのが面倒だと短い指示で済ませ、やり直しが増える。話すなら長い指示も面倒にならず、やり直しが減る |
| **画面を見たまま話せる** | 直してほしい資料だけを表示して「ここが違う」と話せる。入力欄を見に行かなくていい |

---

## 私が手打ちに戻った理由

私もMacの標準の音声入力で、AIへの指示を話していました。
使い始めは速く感じましたが、一度は全部手打ちに戻しました。

| 引っかかったこと | 中身 |
|---|---|
| **考えを言葉にするのが苦手** | 話しながら、伝えたいことをうまくまとめられない |
| **長く話すと誤字脱字が多い** | AIはある程度汲み取ってくれていると思うが、結局もう一度書き直す。==打つほうが速い気がした== |
| **切り替えが紛らわしい** | 音声入力に切り替える操作が紛らわしく、ショートカットもうまく割り当てられなかった |

---

## 音声入力が向く場面、打つほうが速い場面

音声入力をやめたエンジニアの記事もあります。
Qiitaの「[私が「AI音声入力」をやめた理由 ― Claude Codeでの開発で気づいたこと](https://qiita.com/MasaoSasaki/items/9909e9a5f1f3fffceccc)」です。

| 場面 | 向くのは |
|---|---|
| **考えがまとまっていて、言葉にできる** | ==音声==（私：楽だった） |
| **考えがまとまっていないまま、AIに指示する** | 人による（インタビュー：AIが汲み取るので音声でもよい／私：手打ちのほうが速かった） |
| **指示を出す前に、頭の中をそのまま話して整理してもらう（壁打ち）** | 音声（Qiita） |
| **箇条書き・改行・前の返答の引用が多い** | 手打ち（Qiita） |
| **周りに人がいる** | 音声は使いづらい（インタビュー） |

## 試すなら、Macの標準の音声入力でショートカットを1つにそろえる

音声入力の専用アプリを買う前に、Macなら無料の標準機能で試せます。
ショートカットを1つ決めれば、アプリごとに押し方を覚えなくてよくなります。

1. 「システム設定」→「キーボード」を開く<br>
2. 「音声入力」をオンにする（「有効にする」を押す。音声を共有しないなら「今はしない」）<br>
3. 「ショートカット」で押しやすいキーを選ぶ（一覧に無ければ「カスタマイズ」）<br>
4. ClaudeやChatGPTの入力欄をクリックしてキーを押し、話す。止めるときはもう一度押す（Escでも止まり、30秒黙っても止まる）

手順はAppleの「[Macで音声入力を使う](https://support.apple.com/ja-jp/guide/mac-help/mh40584/mac)」にもあります。

【チェック】<br>
**誤字が多いときは、同じ設定の「マイクの入力元」で別のマイクを選んでみます。**

私も今、もう一度音声入力を試しています。
音声のほうがいい気もしてきましたが、「5（ご）」と言ったのに「後」と入るような打ち直しは、まだまだあります。

【アラート】<br>
会社の情報を声で話すなら、声がどこへ送られて文字になるかを確かめます。

・**Macの標準**：Macの中だけで文字にするかは、手順1の画面の「キーボードショートカット」→音声入力の説明で分かる<br>
・**ChatGPTのマイクのアイコン**：OpenAIのモデルで文字にする。音声はチャットが履歴にある間、保持される（[音声入力のFAQ](https://help.openai.com/ja-jp/articles/12168547)）<br>
・**Claude Codeの専用の音声入力（[`/voice`](https://code.claude.com/docs/ja/voice-dictation)）**：Anthropicのサーバーで文字にする。日本語で話すなら`/config`で言語を日本語にする（空だと英語で文字になる）

文字になった指示が学習に使われるかは、[ChatGPTに学習させない設定。会社の情報を入れる前に](https://aicontent-note.com/chatgpt-training-opt-out/)と[Claudeに会社の情報を渡して大丈夫か。データが学習に使われる条件](https://aicontent-note.com/claude-company-data-training/)にまとめています。
