# AIが肯定ばかりするのはなぜ？イエスマンにしない頼み方

AIが肯定ばかりするのは、==使う人の満足を重視する作り==が一因と研究者は見ています。
対人関係の相談を11種類のAIで調べたある研究では、AIは人の回答より平均49%高い頻度で相談者の行動を肯定しました。
頼み方の工夫はありますが、AIの「問題ない」は鵜呑みにせず、大事な判断は自分で決めるのが安全です。

---

## AIが肯定ばかりするのはなぜ？研究と公式の説明

同じ研究の実験では、肯定してくれるAIほど信頼され、また相談したいと答える人が増えました。

| 内容 | 出典 |
|---|---|
| **起きていること**：ChatGPT・Gemini・Claudeなど11種類のAIは、倫理的に問題のある行動の相談でも、相談者の行動を支持した | Science誌の研究（[ビジネス+IT](https://www.sbbit.jp/article/cont1/183491)の紹介記事） |
| **研究チームが挙げた原因**：AIが、==使う人が満足し、使い続ける回答を重視するように作られている== | 同上 |
| **OpenAIの説明**：その場の「いいね」などの評価を重視しすぎて、ChatGPTのGPT-4oが過剰に褒め、賛同するようになった。2025年4月に、その更新を元に戻した | OpenAIの発表（[ITmedia AI＋](https://www.itmedia.co.jp/aiplus/article/2504/30/1250430151/)の記事） |

## イエスマンにしない頼み方

悩みの相談や企画の壁打ち、原稿のレビューで、AIが賛成ばかりすると感じたら、頼み方を変えてみてください。

| 頼み方 | 例えば |
|---|---|
| **判断を任せず、観点を出させる** | 「どう思う？」と聞く代わりに、判断に要る観点を5つ挙げてもらい、観点ごとに1つずつ質問してもらう |
| **自分の結論や好みを先に言わない** | ==「この案、いいと思うんだけど」を付けずに案を渡す==。目的や条件など、判断に要る情報は渡す |
| **何を基準に判断するかを先に渡す** | 「結論の根拠になる数字が無ければ、『良い』と判定しない」と先に書く |
| **案を作ったAIとは別のAIに見てもらう** | 案を作った会話を知らない別のAIに、原稿だけ渡して読ませる |

1つ目は、[京都大学 学生相談センター](https://www.assdr.kyoto-u.ac.jp/ssc/consulting_ai/)が、AIに悩みを相談するときの注意として勧めている頼み方です。

### 使える型の例

［例：〜］の所を、自分の仕事に置き換えて使えます。

```
以下の［例：企画書］を、次の基準で確認してください。
［例：目的に合っているか／実現できる内容か］
良い点と問題のある点を、それぞれ理由とともに挙げてください。
判断に必要な情報が足りなければ、足りない情報を教えてください。

対象：
［ここに企画書などを貼る］
```

理由が付いていれば、指摘が当たっているかを自分で確かめられます。
記事のレビューに使う型は、[AIに記事をレビューさせても良くならない？指摘を重ねて分かった頼み方](https://aicontent-note.com/ai-article-review-how-to/)にまとめています。

## 頼み方を工夫しても、大事な判断は自分で決める

上の頼み方を使っていても、AIが見落としたまま「公開してよい」と判定した記事がありました。
自分で読み直すと、言い切れないことを言い切っていて、構成から作り直しました。

今は、次のように分けています。

・**AIに任せる**：指摘を出す / 指摘を直す / 下書きを作る<br>
・**自分で決める**：言いたいことと見出しの並び / 公開するかどうか

AIが賛成してくれたときほど、私は一度自分で読み直しています。
自分で考える所の残し方は、[AIを使うと思考力は落ちる？落ちる使い方と、私が手放さない判断](https://aicontent-note.com/ai-thinking-ability-decline/)にも書いています。
