# ブログのアイキャッチをAIで作る方法。80枚作って決めた頼み方の型

ブログのアイキャッチをAIで作る方法に正解はなく、私は参考画像を決めて頼みます。
参考画像の借り方によってはパクリになるので、==取り入れる所と変える所を分けて書くようにしています==。
80枚ほど作って固まった頼み方の型と、1枚目に出た失敗の直し方をまとめました。

---

## ブログのアイキャッチをAIで作る流れ

私が作るときの流れは4つです。
私がいちばん手をかけるのは、2つ目の頼み方です。

| 手順 | ポイント |
|---|---|
| **1. 参考画像を選ぶ** | よそのメディアのアイキャッチから、記事の題材に近く、直近の自分のアイキャッチと色や組み方が続かないものを選ぶ |
| **2. 頼み方（プロンプト）を書く** | 取り入れる所と変える所を分けて書く |
| **3. 画像生成AIで作る** | 参考画像を添付して、頼み方を貼る |
| **4. サイズを整えて、アイキャッチに設定する** | 頼んだ大きさに整え、WordPressなら投稿の「アイキャッチ画像」に設定する |

私はアイキャッチを、ChatGPTの画像生成の機能を使って作っています。
頼み方の文章は、自分で書いても、AIに書かせてもかまいません。
私の場合は、Claude Code（パソコンの作業をAIに任せるツール）に参考画像と題を渡して書かせています。

---

## 参考画像を決め、取り入れる所と変える所を分けて頼む

参考画像を渡すだけだと、人物や部品までそっくりになることがあります。
どこを借りて、どこを変えるかを分けて書きます。

| 取り入れる所 | 変える所 |
|---|---|
| **組み方**（文字と絵の置き方） | **人物**（人数・並び・性別・髪型・服装） |
| **背景の飾りの入れ方・色の使い方** | **人物が持つ物・画面の中身**（記事のテーマに） |
| **絵のタッチ**（線・頭身・影） | **背景に置く物**（記事のテーマに合う物に） |
| **フォントの雰囲気** | **文字**（記事の題に） |

==借りるのは見せ方までにして、人物や部品の形は変えます==。
他社の画像をAIに添付する前に、その画像の利用条件を確かめておくと安心です。

## プロンプトに毎回書く項目

==毎回同じなのは項目と言い方で、参考画像・人物・文字・色の中身は記事ごとに変えます==。

| 項目 | 何を書くか |
|---|---|
| **サイズ** | 横と縦のピクセル数（1行目に書く） |
| **取り入れる所と変える所** | 上の表のとおり分けて書く |
| **余白** | 文字と絵のかたまりは高さの6割前後。上下約110px・左右約50〜60px空け、==余白には何も置かない== |
| **文字** | 場所ごとに一字一句。大きさの比・色・太さも。題の1行は太めで、高さは画面の約12% |
| **絵のタッチ** | 「人物と物の描き方は参考画像と同じ」と書く。参考画像と違う形容は足さない |
| **全体の見た目** | すっきり見やすく。部品は絞り、背景の色を広く見せる |
| **背景と色** | 背景の色と、使う色ごとの役目。真っ白は使わない（ブログの白い背景と同化する） |
| **最後の1行** | 「画像内の日本語テキストは、上に指定した文言だけにしてください」 |

### 日本語のタイトルも、画像の中に入れられる

文字は入れず、あとで別のツールで入れる、とよく言われます。
私は題も、画像生成でそのまま入れています。

場所ごとに一字一句書くと、ここ最近は指定どおりに出ています。
ただ、誤字や余計な文字が無いかは、毎回目で見ます。

### そのまま使える頼み方の型

［　］の中を記事に合わせて書き換え、参考画像を添付して貼ります。
私が毎回使っている頼み方から、記事ごとに変わる所を［　］にしました。

```
添付の画像を参考に、ブログ記事のアイキャッチを1枚作ってください。サイズは横［1200］px×縦［630］pxです。

■取り入れるもの（参考画像のいい所）
・組み方：［例：左に文字、右に人物と小物］
・背景：［例：1色のべた塗りに、斜めの模様をうっすら］
・余白と配置：文字と絵を合わせたかたまりは画面の高さの6割前後に収め、上下は端から約［110］px、左右は約［50〜60］px空ける。上下・左右の余白には、飾りも含めて何も置かない。片側に寄せない
・文字の大きさ：題でいちばん大きい1行の高さは、画面の高さの約12%。文字を大きくしすぎず、周りに広い余白を残す
・絵のタッチ：人物と物の描き方（輪郭線の有無・頭身・顔の描き込み・影）は参考画像と同じにする
・全体の見た目：デザイナーが作ったような、すっきり見やすい、今どきのデザインにする。部品は絞り、背景の色を広く見せる。フラットでよいが、さびしくはしない
・品質は参考画像と同じ水準以上にする
・フォント：［例：太くて角ばったゴシック体］。題は太めにする

■変えるもの
・人物：［例：30代の女性、肩までのボブ、ベージュのシャツ］。参考画像の人物とは、人数・並び・性別・髪型・服装を変える
・人物が持つ物・画面の中身：［例：付箋を貼った紙の束］
・背景に置く物：［例：観葉植物と壁の時計］
・参考画像にあるロゴ・文字・マークは入れない

■文字（この［2］か所だけ）
1. ［例：上の中央］：「［例：記事の題］」［例：濃い紺］、いちばん太い。題でいちばん大きい
2. ［例：題の下］：「［例：題を補う短い一言］」［例：濃い紺］、中くらいの太さ。1の約［0.5］倍

■配色
［例：淡いアプリコット色］の背景を広く見せる。［例：深い青緑］は［例：題の1語と絵の中の小物］だけ。真っ白は使わない。

画像内の日本語テキストは、上に指定した文言だけにしてください。
```

## アイキャッチのサイズは、横と縦のピクセル数で伝える

このブログでは「横1200px×縦630px」と頼みます。
==「16:9」は1200×630より縦に長いので、切ると文字や絵がずれることがあります==。
自分のブログは、テーマの推奨サイズに合わせます。

## 1枚目に出た失敗と直し方

1枚目をそのまま使えることは少なく、見てから直すことが多いです。

| 1枚目に出たこと | 頼み方の直し方 |
|---|---|
| **画面いっぱいで、余白が無い** | 「文字と絵は画面の高さの6割前後に収め、上下約110px、左右約50〜60px空ける。余白には何も置かない」と書く |
| **部品が多く、ごちゃごちゃしている** | 「部品は絞り、背景の色を広く見せる」と書く |
| **シンプルすぎて、さびしい** | 人物を入れる |
| **背景が地味** | 例えば、背景を明るい色1色にし、絵の後ろにだけ、はっきりした色の大きな円を1つ置く |
| **ありえない絵**（パソコンの裏側に画面が映る） | 人物と画面の向きをそろえて書く。画面の中身を見せたいなら、人物を画面の横か手前に置く |
| **参考画像と絵の雰囲気が違う** | 参考画像と違う形容（参考画像より細い線など）を消し、表の「絵のタッチ」の書き方に戻す |

==何度も出た直し（余白・絵のタッチなど）は、次から毎回の頼み方に足します==。
