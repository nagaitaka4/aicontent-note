# ブログのアイキャッチをAIで作る方法。80枚作って決めた頼み方の型

ブログのアイキャッチをAIで作るなら、参考画像を1枚決めて頼むのが近道です。
取り入れる所と変える所を分け、余白や文字の大きさを==毎回同じ言い方で書くと、絵柄が変わっても仕上がりの水準がそろいます==。
80枚ほど作って固まった頼み方の型と、1枚目に出た失敗の直し方をまとめました。

---

## ブログのアイキャッチをAIで作る流れ

流れは4つです。
いちばん大事なのは、2つ目の頼み方です。

| 手順 | ポイント |
|---|---|
| **1. 参考画像を1枚選ぶ** | よそのメディアのアイキャッチから、記事の題材に近く、直近の自分のアイキャッチと色や組み方が続かないものを選ぶ |
| **2. 頼み方（プロンプト）を書く** | ==取り入れる所と変える所を分けて書く== |
| **3. 画像生成AIで作る** | 参考画像を添付して、頼み方を貼る |
| **4. サイズを整えて、アイキャッチに設定する** | 頼んだ大きさに縮め、WordPressなら投稿の「アイキャッチ画像」に設定する |

私は画像をChatGPTで作っていて、この記事の例もChatGPTで作ったものです。
頼み方の文章は手で書かず、参考画像と記事の題をAIに渡し、下の項目を守らせて書かせています。
私が使っているのは、Claude Code（パソコンの作業をAIに任せるツール）です。

プランごとの画像生成の上限は、[ChatGPT有料プランの違い。Go・Plus・Proと画像生成の上限](https://aicontent-note.com/chatgpt-free-paid-difference/)にまとめました。

## 参考画像は1枚に決め、取り入れる所と変える所を分けて頼む

参考画像を渡すだけだと、人物や部品までそっくりになることがあります。
どこを借りて、どこを変えるかを分けて書きます。

| 取り入れる所 | 変える所 |
|---|---|
| **組み方**（文字と絵の置き方） | **人物**（性別・髪型・服装） |
| **背景の飾りの入れ方・色の使い方** | **人物が持つ物・画面の中身**（記事のテーマに） |
| **絵のタッチ**（線・頭身・影） | **背景に置く物**（記事のテーマに合う物に） |
| **フォントの雰囲気** | **文字**（記事の題に） |

==借りるのは見せ方までにして、人物や部品の形は変えます==。
どこまで似せると問題になるかは、[ロゴのパクリはどこまで？AIで作るときの著作権・商標と類似チェック](https://aicontent-note.com/logo-plagiarism-how-far-ai-copyright-font/)で調べました。

## プロンプトに毎回書く項目

==毎回同じなのは項目と言い方で、参考画像・人物・文字・色の中身は記事ごとに変えます==。

| 項目 | 何を書くか |
|---|---|
| **サイズ** | 横と縦のピクセル数（1行目に書く） |
| **取り入れる所と変える所** | 上の表のとおり分けて書く |
| **余白** | 文字と絵のかたまりは高さの6割前後。上下約110px・左右約50〜60px空け、==余白には何も置かない== |
| **文字** | 場所ごとに一字一句。大きさの比・色・太さも。題の1行は太めで、高さは画面の約12% |
| **絵のタッチ** | 「人物と物の描き方は参考画像と同じ」と書く。参考画像と違う形容は足さない |
| **全体の見た目** | すっきり見やすく。部品は絞り、背景の色を広く見せる |
| **背景と色** | 背景の色と、使う色ごとの役目。真っ白は使わない（ブログの白い背景と同化する） |
| **最後の1行** | 「画像内の日本語テキストは、上に指定した文言だけにしてください」 |

### 日本語のタイトルも、画像の中に入れられる

文字は入れず、あとで別のツールで入れる、とよく言われます。
私は題も、画像生成でそのまま入れています。

場所ごとに一字一句書くと、ここ最近は指定どおりに出ています。
ただ、誤字や余計な文字が無いかは、毎回目で見ます。

### 項目を全部入れた頼み方の実物

表の項目を全部入れると、1本はこのくらいの長さになります。
別の記事のアイキャッチで、実際に使った頼み方の1回目です。

```
添付の画像を参考に、ブログ記事のアイキャッチを1枚作ってください。サイズは横1200px×縦630pxです。

■取り入れるもの（参考画像のいい所）
・地は2色の塗り分け：くすんだセージグリーンを広く見せ、深い緑の大きな曲線の面を右上と左下の角から入れる。曲線はゆったりした大きな弧にする
・天秤を主役に置く見せ方。天秤は明るいクリーム色で、深い緑の面の上にかかるように置き、皿の上の物だけ朱色にする
・左に文字、右に天秤と人物を置く組み方。文字はセージグリーンの面の上に置き、深い緑の面に重ねない
・余白と配置：文字・天秤・人物を合わせたかたまりは画面の高さの6割前後に収め、上下は端から約110px、左右は約50〜60px空ける。上下・左右の余白には、きらめきなどのあしらいも含めて何も置かない（地の2色の塗り分けだけは端まで届いてよい）。片側に寄せない
・文字の大きさ：題でいちばん大きい1行（「有料プランの違い」）の高さは画面の高さの約12%（約75px）。3段の文字のかたまりは高さ約220pxに収める。文字を大きくしすぎず、周りに広い余白を残す
・絵のタッチ：人物と物の描き方は参考画像と同じにする。深い緑の細い輪郭線に、べた塗り。影・グラデーション・効果線はつけない。人物は小さめで、顔は目と口を点と線で簡単に描く程度。変えるのは人物の性別・髪型・服装だけ
・仕上がりの目標：デザイナーが作ったような、すっきりと見やすい、おしゃれで今どきのデザインにする。部品は絞り、地の色を広く見せる。フラットでよいが、さびしくはしない
・品質は参考画像と同じ水準以上にする
・フォント：すっきりした今どきのゴシック体。字間はやや広め。題の「有料プランの違い」だけ太く、ほかは中くらいの太さ

■変えるもの
・参考画像の左上のロボット・丸い枠・右上のロゴ・右下の小さな題は入れない
・天秤の形：参考画像の飾りの多い古い形ではなく、まっすぐな横棒と細い柱、三角の台の、すっきりした形にする。皿は浅い円盤
・天秤の左の皿：朱色の硬貨を3枚重ねた山（硬貨の面には丸い線だけ。記号や文字は入れない）
・天秤の右の皿：朱色の枠の小さな画像のカード（中に山と太陽の絵）。天秤はわずかに右へ傾ける
・人物：天秤の右下に、天秤を見上げる小さな人物を1人。30代の女性、肩までのボブ、クリーム色のシャツに深い緑のパンツ。片手をあごに当てて考えている。セージグリーンの面の上に立たせる
・きらめき：参考画像と同じ4つの角の星形を、天秤の上に小さく2つだけ（朱色）
・どの製品のロゴも描かない

■文字（この3か所だけ。字面の左端を1本の縦線にそろえる）
1. 1段目：「ChatGPT」深い緑（#123B35）、中くらいの太さ。2段目の約0.55倍
2. 2段目：「有料プランの違い」深い緑（#123B35）、いちばん太い。題でいちばん大きい
3. 3段目：「Go・Plus・Proと画像生成の上限」深い緑（#123B35）、中くらいの太さ。2段目の約0.4倍。「画像生成の上限」だけ朱色（#E8532E）にし、その下に朱色の細い下線

■配色
くすんだセージグリーン（#BFD2C6）の地を広く見せるのを主役に、深い緑（#123B35）を曲線の面と文字と輪郭線に、明るいクリーム色（#F5F0E6）を天秤と人物のシャツに。朱色（#E8532E）は硬貨・画像のカードの枠・きらめき・「画像生成の上限」だけ。真っ白は使わない。

画像内の日本語テキストは、上に指定した文言だけにしてください。
```

## アイキャッチのサイズは、横と縦のピクセル数で伝える

このブログでは「横1200px×縦630px」と数字で頼みます。
==「16:9」で頼むと1200×630より縦長に出て、切ると構図が崩れます==。
自分のブログのサイズは、テーマの推奨サイズに合わせます。

## 1枚目に出た失敗と直し方

1枚目をそのまま使えることは少なく、見てから直すことが多いです。

| 1枚目に出たこと | 頼み方の直し方 |
|---|---|
| **画面いっぱいで、余白が無い** | 「毎回書く項目」の表の「余白」「文字」の行を、割合まで書く |
| **部品が多く、ごちゃごちゃしている** | 表の「全体の見た目」の1行を書く |
| **シンプルすぎて、さびしい** | 人物を入れる |
| **背景が地味** | 例えば、背景を明るい色1色にし、絵の後ろにだけ、はっきりした色の大きな円を1つ置く |
| **ありえない絵**（パソコンの裏側に画面が映る） | 人物と画面の向きをそろえて書く。画面の中身を見せたいなら、人物を画面の横か手前に置く |
| **参考画像と絵の雰囲気が違う** | 参考画像と違う形容（参考画像より細い線など）を消し、表の「絵のタッチ」の書き方に戻す |
