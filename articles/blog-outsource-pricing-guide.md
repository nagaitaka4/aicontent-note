# ブログ代行の相場はいくら？運用代行の料金目安と失敗しない選び方

ブログ代行の料金は、記事作成のみなら1本5,000〜5万円程度、テーマ設計から公開まで含む運用代行なら月10万〜30万円程度が目安です。ただし記事を書くだけのサービスと、更新が続く状態を引き受けるサービスとでは、含まれる作業がまったく違います。

このノートでは相場の全体像に加えて、料金表には出てこない「依頼側に残る工程」まで整理します。このメディア自体をAIで運用しているので、その実測値も添えます。

---

## ブログ代行の料金相場【依頼内容別】

料金の幅は広く、依頼内容で1本数千円から月100万円以上まで変わります。

| 依頼内容 | 料金目安 | 特徴 |
|---|---|---|
| 記事作成のみ（テーマと構成は発注側が用意） | 1本5,000〜5万円程度 | 文字数・専門性・修正範囲で変わる |
| テーマ設計〜公開まで込み（SEOコンサルなし） | 月10万〜30万円程度 | 月額型・継続前提の契約が基本 |
| SEOコンサル込みの本格運用 | 月30万〜100万円程度 | 調査・分析・効果測定まで含む |

違いは担当範囲です。記事作成のみは書く工程だけ、運用代行はテーマ設計から公開まで、SEOコンサル込みは調査・効果測定まで担い、この差が金額に出ます。

### 文字単価で見た場合の相場

文字単価で提示されることもあります。記事単価だけでは文字数による総額差が見えないため、両方を押さえると比較しやすいです。

[ランサーズの費用相場ガイド](https://www.lancers.jp/c/article/article-cost/12986/)（2023年8月公開）は、ブログ記事・コラム記事の文字単価を0.8円〜5円以上としています。取材記事は6.6円〜20円以上です。[クラウドワークスの発注相場](https://crowdworks.jp/pages/guides/employer/pricing)（2026年8月時点）でも、ブログ記事作成は1円〜/文字です。

【メモ】<br>
3,000文字なら単価1円で3,000円、5円で15,000円。同じ「1本」でも5倍の開きが出ます。

記事作成以外の工程にも単価はつきます。クラウドワークス側では記事構成の企画が1,000円〜/記事、校正と入稿が3,000円〜/記事です。工程を分けると総額は積み上げになります。単価が上下する背景は「[コンテンツ運用代行の単価が二極化している理由](https://aicontent-note.com/content-outsource-price-polarization/)」で整理しています。

### ブログ代行とブログ運用代行は何が違うのか

同じ名称でも、実態は大きく2つに分かれます。

| 記事作成サービス（執筆代行） | 運用代行サービス |
|---|---|
| 指定テーマの記事を1本ずつ納品 | テーマ選定から公開まで一括対応 |
| テーマ・キーワード・構成は自社で準備 | 運用方針の設計から担う場合もある |
| 公開・入稿作業は自社が担当 | WordPress入稿・公開設定も含む |
| 記事単価型での契約が基本 | 月額型・継続前提の契約が基本 |

社内の負担を減らしたいなら運用代行型です。料金の内訳は「[コンテンツ運用代行とは？料金・内容・依頼する前に知っておくこと](https://aicontent-note.com/content-operation-outsource-what-is/)」でも整理しています。

## 料金表に出てこない「自社に残る工数」

「安い外注先にしたのに社内が楽にならない」はよく起きます。**残る工数は依頼範囲で変わります。**記事作成だけを頼んだ場合、以下は自社に残ります。

・テーマ選定とキーワード調査<br>
・構成確認と修正指示<br>
・画像の準備とWordPressへの入稿

テーマ設計から公開まで含む運用代行なら多くは委託先に移り、記事作成型では全部残ります。外注費だけを比べても、自社工数を含めたコストは見えません。

### AIでも縮まなかった工程がある

以下は一般論ではなく、このメディアの実測値です。AI（Claude Code）で記事を制作していて、1本の制作時間は当初8時間ほど、現在は4〜5時間です。ただし縮んだ時間の中身ははっきり分かれます。

・大幅に縮んだ：出力がぶれるたび直していた軌道修正<br>
・変わらない：事実確認 / 方針決定 / 優先順位づけ<br>
・変わらない：最終的な品質判断

縮んだのは軌道修正だけで、判断は減っていません。ここまでが実測で、ここから先は考察です。**誰が書くかを変えても、何を書くかを決める工程は依頼側に残る**——外注でも同じ構造になるのではないかと考えています。

【ポイント】<br>
価格の安さより、自社の工数がどれだけ減るかを先に試算する。それが費用対効果を判断する起点です。

社内で回す場合との比較は「[社内更新と外注、どちらが本当にコスパがいいのか](https://aicontent-note.com/in-house-vs-outsource-cost/)」にあります。

## ブログ代行を選ぶときの4つの基準

料金の目安がつかめたら、次は依頼先の判断です。価格以外の4点を確認します。

### 基準①：運用の実績と体制

納品実績（件数・ジャンル・継続期間）と品質管理の方法を確認します。スポット対応型と継続運用型で体制は違います。

### 基準②：進行方法

定期面談型・非同期型・フォーム完結型に分かれます。面談を組みにくいなら非同期型、認識をこまめに揃えたいなら面談型です。当サービスは面談・通話なしで、事業内容や目的は最初にヒアリングフォームで伺います。

### 基準③：SEO費用の範囲

「SEO込み」の定義はサービスごとに違います。

【チェック】<br>
契約前に確認するポイント<br>
・キーワード選定は含まれているか<br>
・テーマ設計（どの記事を書くか）まで担うか<br>
・記事構成の作成は含まれているか<br>
・効果測定のレポートはあるか

確認しないまま契約すると、後から追加費用や認識のズレが生じます。当サービスの場合、SEOコンサルとキーワードの詳細調査は月額に含みません。

### 基準④：任せられる範囲

テーマ選定・構成案・入稿・修正回数のどこまでが「込み」かを確認します。範囲が広いほど月額は上がりますが手離れは良くなります。「一括対応」でも実態は「執筆のみ＋入稿補助」のこともあります。

## ブログコンサルとの違い

「ブログコンサル」と「ブログ代行」は、依頼できる範囲が根本的に違います。

| ブログコンサル | ブログ代行 |
|---|---|
| 設計・助言が中心 | 実作業まで引き受ける |
| 手を動かすのは自社 | 手を動かすのは委託先 |
| ノウハウが社内に残りやすい | 更新が止まらない状態が手に入る |

社内に人がいて助言だけ欲しいならコンサル型、時間がないなら代行型です。**人はいても時間がない場合にコンサルを選ぶと、結局更新は止まります。**

## 料金を公開しているかも判断材料になる

料金非公開のサービスは少なくありません。事前に分かれば見積もり前に候補を絞れるので、「記事本数と金額」「含まれる作業」の2点が公開されているかを見ます。

参考として、当サービスの場合は次のとおりです。

・料金：通常プランは月4本8万円〜月8本15万円（初月限定のお試しは月4本5万円）<br>
・主に含むもの：テーマ設計 / 構成 / 執筆 / WordPress入稿 / 公開 / アイキャッチ作成 / 月次アクセスレポート<br>
・含まないもの：SEOコンサル / キーワード詳細調査 / 競合分析 / 広告運用 / 成果保証

この価格帯で公開まで含められるのは、AIを使った制作体制が前提にあるからです。安さではなく、**更新が止まらない状態を継続的に提供する**ために設計した結果です。詳細は[サービスページ](https://aicontent-note.com/service/)にあります。

ただし判断の中心は価格ではありません。「月額いくらで何本書けるか」より、「依頼して自社の更新が回るか」で選ぶことをおすすめします。

外注のタイミングに迷う場合は「[ブログ更新が止まる理由と、外注を検討するタイミングの見極め方](https://aicontent-note.com/blog-update-outsource-timing/)」もご覧ください。
