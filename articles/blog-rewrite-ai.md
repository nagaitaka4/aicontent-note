# ブログのリライトをAIに任せるには？直す記事の選び方と効果の確かめ方

AIに==直す記事の候補と直し方の案を出させ、直すかは人が決める==方法があります。
Webアナリストの[小川卓さん（オウンドメディア戦略ラボ）](https://www.hatena.ne.jp/ownedmedia/article/ga4-mcp-improvement-ideas)のサイト改善の進め方を、リライトに当てはめます。
私は検索で11〜20位の記事から候補を出させ、効いたかは1週目で決めずに約1か月後に見ています。

---

## 直す記事は、Search Consoleの順位と表示で選ぶ

私は2週間おきに、AIにGoogle Search Console（サーチコンソール）の表を読ませています。
次の表の上の2つに当てはまる記事を書き出させます。

| Search Consoleで見ること | どう扱うか | 理由 |
|---|---|---|
| **平均11〜20位で、表示がある** | ==最初の候補にする== | すでに検索結果に出ている |
| **平均順位は良いのに、クリックが0** | 候補に書き出す | 表示されても、クリックされていない |
| **表示がほとんど無い**（公開から日が浅い記事も含む） | 後回し | 数字から直す所を判断しにくい |

### 使える型①：直す記事の候補を出してもらう

表は、[Search Consoleのヘルプ](https://support.google.com/webmasters/answer/7576553?hl=ja)にある［エクスポート］ボタンで書き出して渡せます。
［例：〜］の所を、自分のブログに置き換えて使えます。

```
Search Consoleのページ別の数字（直近［例：3か月］）を渡します。
次のどちらかに当てはまる記事を、直す候補として書き出してください。
・平均掲載順位が11〜20位で、表示がある
・平均掲載順位は良いのに、クリックが0
直せるのは［例：月2本］。候補は多くても［例：5本］までに絞ってください。
記事ごとに、表示回数・平均掲載順位・クリック数と、
候補にした理由を1行で添えてください。
直し方の案は、まだ出さなくてかまいません。
```

### 数字を見るときの2つの注意点

・**掲載順位は平均**。検索結果に表示されたときの順位を平均した数字。平均15位でも、毎回15位に出ているわけではない（[Search Consoleのヘルプ](https://support.google.com/webmasters/answer/7042828?hl=ja)）<br>
・**表示が少ない記事のクリック率は、1クリックで大きく動く**。私は、表示が3桁に届かない記事のクリック率は根拠にしていない

---

## AIに頼むときに入れる4つの条件

「この記事の改善案を出して」とだけ頼むと、どの記事にも当てはまる一般論が返りやすいと、小川さんは書いています。
小川さんが挙げる条件をリライトに当てはめると、次の4つです。

| 条件 | 理由 |
|---|---|
| **案は3つまで。どの数字を見てそう考えたかを書く** | 数字のある案なら、直したあとに同じ数字で確かめられる |
| **各案に、効果の確かめ方を書く** | ==何がどう変われば効いたと言えるかを、直す前に決めておける== |
| **直せる本数の範囲で**（型①で指定） | 直しきれない量の案が出ないようにする |
| **分からないことは「確認が必要」と書く** | 原因を取り違えたまま直すと、直しても数字は変わらない |

### 使える型②：選んだ記事の直し方を出してもらう

型①で選んだ記事を1本ずつ渡します。

```
［例：インデックス未登録の確認方法の記事］の、
どこを直せばよいか案を出してください。
記事の本文と、この記事のSearch Consoleの数字
（ページ全体と、検索語ごとの表示回数・平均掲載順位・クリック数）を渡します。
条件：
・出す案は3つまで。どの数字を見てそう考えたかを書く
・案ごとに、「何がどう変われば効いたと言えるか」を添える
・数字だけで言えないことは、理由を作らず「確認が必要」とだけ書く
```

記事を直すと決めたら、本文の書き直しもAIに任せられます。
どこまで任せるかは、[本文執筆・リライトはどこまで任せられるか【Claude Code実践】](https://aicontent-note.com/claude-code-writing-rewrite/)に書きました。

## 直す候補と案は、採用・保留・見送りに分ける

小川さんは、出てきた案を3つに分けて、理由を一言ずつ書くよう勧めています。

| 分け方 | 分ける理由（私の場合） | 私のブログの例 |
|---|---|---|
| **採用** | 本文を開いて、直す所を確かめられた（数字だけでは記事のどこに問題があるか分からない） | 3か月で202表示・平均74.6位の記事。順位では候補外だが、本文で予告した確認結果の追記を3週間放置していたので直した |
| **保留** | 別の数字で確かめてから決める | 検索順位が14位前後で続いている記事は、候補に残したまま、まだ直していない |
| **見送り** | 同じ手が前に動かなかった | 内部リンクを3本足しても26日で動かなかったページに、さらに足す案は見送った |

---

## 効果は同じ長さの期間で比べ、1回で決めない

小川さんは、直す前の4週と直した後の4週を比べるよう勧めています。
表示回数・クリック数・平均掲載順位を、曜日をそろえ、当日を除いて比べます。

・**最新のデータは、まだそろっていないことがある**。集まったデータが使えるようになるまで、ふつう2〜3日かかる（[Search Consoleのヘルプ](https://support.google.com/webmasters/answer/2571221?hl=ja)）<br>
・==1週目の差では決めない==。採用の例の記事は、直した前後1週の平均順位が64位から58位に上がったが、そこでは決めなかった。約1か月後に見たら、表示がほぼ0になっていた（理由は数字だけでは分からなかった）<br>
・**数字が動かなかったら、「今のところ効いたと言える材料がない」と記録する**。もう少し様子を見るか、別の案を試すかは、その時点で決める<br>
・**同じ時期に別の手を入れない**。同じ時期に別の手も入れていた記事は、表示が2倍になっても、どちらが効いたか分からなかった

私が判定まで見た例では、検索の数字で効いたと言える結果は出ていません。
それでも、直す前の数字と確かめ方を残しておけば、効かなかった手を繰り返さずに済みます。
