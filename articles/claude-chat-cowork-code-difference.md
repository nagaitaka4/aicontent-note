# Claudeのチャット・Cowork・Claude Codeの違い

==聞くならチャット、任せるならCowork==です。
自作のスクリプト（決まった作業をこなす小さなプログラム）などを、自分のパソコンで直接動かす仕事だけ、Claude Codeを開きます。
そういう仕組みが無いなら、チャットとCoworkで足ります。

---

## その場で聞くならチャット、任せるならCowork、自作のスクリプトを自分のパソコンで動かすならClaude Code

迷ったら、下の表の==「こんなときに」の列だけ見れば、どれを開くか決まります==。
「頼み方の例」は、自分の頼みごとに近いものを探す目安です。

【メモ】<br>
**Pro・Maxで切り替えが無ければ、たいていチャットとCoworkの統合後です。選ばずに頼めます（確かめ方は3つ目の見出し）。**

| 使うもの | こんなときに | 頼み方の例 | 使えるプラン |
|---|---|---|---|
| チャット | その場で答えを受け取る（表やファイルも作れる） | 「このメールを丁寧に直して」 | 無料から |
| Cowork | 頼んで離れて、出来上がりを受け取る | 「競合5社を調べて、比較表とスライドにして」 | 有料プラン |
| Claude Code（ローカル＝自分のパソコンで動かす） | 自作のスクリプトを自分のパソコンで動かす。フォルダもやり取りの記録もパソコンに残る | 「このフォルダの下書きを、チェック用のスクリプトにかけて直して」 | 有料プラン |

無料プランで使えるのは、チャットだけです（[料金ページ](https://claude.com/ja/pricing)）。
プランの選び方は、[Claudeに課金すべきか。料金・制限より先にモデルで決める](https://aicontent-note.com/claude-subscription-change-june-2026/)に書きました。

Claude Codeは、デスクトップアプリの「コード」を開いて、作業の場所に「ローカル」を選べば使えます。
別に入れるものは無く（[公式](https://code.claude.com/docs/en/overview)）、頼むのも日本語で大丈夫です。
**名前に「Code」とありますが、コードが書けなくても使えます。**

---

## CoworkとClaude Code（ローカル）の違いは、クラウドに任せるか、自分のパソコンで続けるか

==ファイルを読んで書くだけなら、どちらでもできます==。
違うのは、作業がどこで進むかです。
Pro・Maxでは、2026年10月6日以降に新しく始めるCoworkはクラウドで進みます（[公式](https://support.claude.com/en/articles/15520349-use-claude-cowork-on-web-desktop-and-mobile)）。

|  | Cowork（Pro・Max） | Claude Code（ローカル） |
|---|---|---|
| 作業が進む場所 | Anthropicのクラウド | 自分のパソコン |
| パソコンを閉じたら | 作業は続く。ただし手元のファイルは使えなくなる | 進むのは、パソコンが動いていて、アプリを開いている間 |
| やり取りの履歴の保存先 | Claudeのアカウント | 自分のパソコン |

Coworkは、Claude Codeと同じ仕組みで、コード以外の仕事をするものです。Coworkもクラウドの上でプログラムを動かせます（[公式](https://support.claude.com/en/articles/13345190-get-started-with-claude-cowork)）。
どちらも「任せる」道具なので、次の3つで分けます。

・手元のファイルを使わない調べものや資料づくりを、任せて離れたい → Cowork<br>
・手元のファイルを読んで書くだけ → どちらでもよい<br>
・自作のスクリプトを手元で動かしたい、記録も1台のパソコンに置きたい → Claude Codeのローカル

2つ目で迷ったら、Coworkから始めて構いません。
統合後の画面にはCoworkの切り替えが無いので、ふだんの会話でそのまま頼めば大丈夫です。
手元のフォルダを使うときの条件は、最後の見出しにまとめました。

私は、記事づくりにClaude Codeのローカルを使っています。
自作のチェック用スクリプト（決まった手順で文章を点検する小さな仕組み）を、下書きと同じフォルダで動かして直すからです。

Coworkの実際の使われ方は、[Claude Coworkの使い方｜実際の9割は開発以外だった](https://aicontent-note.com/claude-cowork-usage-data/)にまとめています。

【ポイント】<br>
**出発点はチャットかCowork。手元で動かしたいスクリプトが出てきたら、Claude Codeに切り替える。**

---

## チャットとCoworkは1つになる。自分の画面の見分け方

==Pro・Maxで、入力欄に「チャット」「Cowork」の切り替えがあれば、まだ統合前の画面==です。
1つになると切り替えが消え、Claudeが道具を選びます。

・Coworkでしかできなかった仕事も、どの会話からでも頼める<br>
・ProとMaxのプランから順に届く。同じプランでも、届く時期は人によって違う。一度変わると元に戻せない<br>
・Claude Codeは、今までどおりデスクトップアプリから開ける（[公式ヘルプ](https://support.claude.com/en/articles/16761823-claude-cowork-and-chat-are-one-claude)）

Pro・Maxなのに切り替えが無いときは、アプリならまず最新にします。
Webなら「ホーム」の入力欄で確かめます。
それでも無ければ、統合後の画面です（[公式](https://support.claude.com/en/articles/15520349-use-claude-cowork-on-web-desktop-and-mobile)）。

---

## Web版・デスクトップアプリ・スマホ。どこで開けばいいか

==チャットと、手元のファイルを使わないCoworkは、Webで足ります==。
手元のフォルダを使う仕事をするなら、デスクトップアプリを入れます。

・チャットとCowork：Web、デスクトップアプリ、スマホのどれでも開ける。Coworkが手元のフォルダに届くのは、デスクトップアプリで始めた作業で、アプリを開いている間だけ<br>
・Claude Code：デスクトップアプリで、作業の場所をローカルにして使う

Claude Codeにも、アプリを閉じても続く「クラウド」や、スマホから使う方法があります（[公式](https://code.claude.com/docs/en/desktop)）。
手元のフォルダで続ける仕事なら、ローカルで足ります。
