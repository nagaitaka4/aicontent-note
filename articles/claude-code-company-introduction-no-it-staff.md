# Claude Code導入の手順。IT担当がいない会社が決める4つ

==Claude Codeを会社に入れるときは、申し込む前に4つを決めます。==
契約、管理する人、渡さない情報、最初の業務です。
1人で試すなら個人のPro・Max、2人以上を会社として使うならTeamが基準です。

---

## Claude Codeを会社に導入する手順。先に4つを決める

IT担当がいなくても、決める順番が分かれば進められます。
まず、この表の上から順に決めてください。

| 順番 | 決めること | IT担当がいなくてもできる決め方 |
|---|---|---|
| ① 契約 | 個人のPro・Maxか、会社のTeamか | 1人で試すならPro・Max。2人以上を会社として使うならTeamが基準 |
| ② 管理する人 | お金を管理する人と、人を招く人 | 使う人のうち、お金を任せる人を1人決める。招待は別の人に任せられる |
| ③ 渡さない情報 | Claude Codeに渡さないもの | パスワードやAPIキーなど、渡さないものを1枚に書いて共有する |
| ④ 最初の業務 | 最初に任せる仕事 | 1人・1業務を決める。元に戻せる仕事から |
| そのあと | 申し込みとログイン | 申し込む → 人を招く → 各自がインストールしてログイン → 1回試す |

【ポイント】<br>
**①と②はセットで決めます。<br>
誰の名前で契約して、誰がお金を管理するかです。**

---

## ① 契約：個人のPro・MaxかTeamか

==1人で試すだけなら、個人のPro・Maxで足ります。==
**会社で何人かが使うなら、まずTeamの条件を見てください。**
Teamは2人からで、申し込む人には会社のドメインのメールアドレスとカードが要ります。

| 比べる所 | 個人のPro・Max（1人ずつ契約） | Team（2〜150人） |
|---|---|---|
| 料金（月払い） | Pro 月22ドル／Max 月110ドルから | スタンダードシート 1人月27.50ドル／プレミアムシート 1人月137.50ドル |
| 使える量の目安（Proを1として） | Pro 1／Max 5か20 | スタンダード 1.25／プレミアム 6.25 |
| Claude Code | 使える | どちらのシートでも使える |
| 人の追加・削除と請求 | 1人ずつ別の契約・別の請求 | 管理する人が招く・外す。請求は会社で1つ |
| 送った内容の学習 | 本人が設定で選ぶ | 最初から使わない設定 |
| 支払い | 契約ごとに払う | 会社で1つ。カードだけ（銀行振込も不可） |
| 申し込みに要るもの | 個人のメールアドレスでよい | 申し込む人は会社のドメインのメールアドレス |

料金は、日本から[料金ページ](https://claude.com/pricing)を開いたときの表示（消費税10%込み・2026年10月9日）です。
年払いにすると、Proは月18ドル、Teamは月22ドルと110ドルになります。

使える量は、5時間ごとの区切りで見た目安です（[Teamプランの説明](https://support.claude.com/en/articles/9266767-what-is-the-team-plan)）。
どのプランにも、5時間ごとの上限と週の上限があります。

### シートは、まずスタンダードで始める

**Teamは、全員をスタンダードシートで始めるのが無難です。**
上限に何度も当たる人だけ、プレミアムシートに上げます。

上げると差額がすぐ請求されます。下げるのは次の更新日からで、年払いなら1年ごとの更新日です。

・個人のMax 5x並みに使う人は、プレミアムシート（月137.50ドル）が目安<br>
・Max 20x並みに使う人は、プレミアムシートでも量が足りない<br>
・足りない分は、使用クレジット（使った分だけかかる料金）で払う

### 3人なら、いくら違うか

たとえば3人で使うなら、Teamのスタンダードシート3つで月82.50ドルです。
同じ3人がProを1つずつ契約すると、月66ドルです。

**安いのはPro3つですが、人の追加・削除と請求は1人ずつのままです。**
学習の設定も、本人まかせになります。
公式も、Maxは個人向けで、チームで使うならTeamを見るよう案内しています（[Maxプランの説明](https://support.claude.com/en/articles/11049741-what-is-the-max-plan)）。

### 「プレミアムシートでないと使えない」は古い情報

「TeamではプレミアムシートでないとClaude Codeが使えない」と書いた解説もあります。
いまは、[公式ヘルプ](https://support.claude.com/en/articles/11845131-use-claude-code-with-your-team-or-enterprise-plan)の冒頭に、すべてのシートに含まれるとあります。
2026年1月から、スタンダードシートにも入りました（[Anthropicのお知らせ](https://claude.com/resources/articles/claude-team-updates)）。

### 独自ドメインのメールが無いと、申し込みで止まる

Teamを申し込む人は、gmailなどのメールアドレスでは申し込めません（[Teamの始め方](https://support.claude.com/en/articles/9267247-get-started-with-the-team-plan)）。
会社のドメインとメールを先に用意します。
まだ会社全体へ入れる段階でなければ、まず1人が個人のPro・Maxで試す手もあります。

私の場合は、1人なので、個人のMax（5x）を個人のgmailで契約しています。
Teamにするなら、まず独自ドメインのメールが要ります。

ProとMaxの選び方は、[Claudeに課金すべきか。料金・制限より先にモデルで決める](https://aicontent-note.com/claude-subscription-change-june-2026/)に書きました。

【メモ】<br>
**後払いの請求書払いが要るなら、Teamでは足りません。<br>
請求書払いは、営業を通して契約するEnterprise（50席から）だけです。**

## ② 管理する人：誰がお金を管理し、誰が人を招くか

==お金を任せる人をプライマリオーナーにし、招待は管理者に任せます。==
お金を任せない人は、管理者までにしておきます。
オーナーにすると、請求と支払い方法を触れるからです。

| やること | おすすめの担当 |
|---|---|
| お金の管理（請求を見る・支払い方法を変える・使用クレジットを買う） | オーナーから上 |
| シートの買い足し | プライマリオーナーに任せる |
| メンバーの招待・削除、シートの種類の付け替え | 管理者から上 |

Teamの役割は、ユーザー → 管理者 → オーナー → プライマリオーナーの順に、できることが増えます。
プライマリオーナーは、組織に1人だけです（[役割と権限](https://support.claude.com/en/articles/9267276-roles-and-permissions)）。

### お金で驚かないための4つ

・プライマリオーナーも、シートを1つ使う。使わない人がなっても1人分かかる（あとで譲れる）<br>
・招待しただけで、シートを1つ使う。招待は21日で切れる<br>
・招待リンクは最初からオン。入った人は承認なしで加わり、空きが無ければシートが自動で増える<br>
・人を外しても、シートの数を減らさないと請求は下がらない。年払いなら、減らせるのは1年ごとの更新日

招待リンクは、社内のチャットに貼るだけで人が入れて便利です。
そのぶん、シートが増えても気づきにくくなります。
使わないなら、管理画面で止めておきます（[招待リンクの説明](https://support.claude.com/en/articles/13776697-join-an-organization-via-invite-link)）。

使える量の上限に達しても、最初の設定では、上限が戻るまで使えなくなるだけです。
追加の料金は出ません。

超えても続けたいときだけ、オーナーから上の人が使用クレジットを前払いで買います（[使用クレジットの管理](https://support.claude.com/en/articles/12005970-manage-usage-credits-for-team-and-seat-based-enterprise-plans)）。
そのとき、月の上限額を、会社全体と1人ずつに決められます。

【チェック】<br>
**誰がお金を管理し、誰が人を招くかを、申し込む前に決めておいてください。**

## ③ 渡さない情報と、④ 最初の業務

==渡さないものを1枚に書いてから、使い始めます。==
最初の業務は、1人・1つ・元に戻せる仕事からです。

### ③ 渡さない情報を1枚に書く

**Claude Codeに渡さないものを1枚に書き、使う人全員で共有します。**
たとえば、パスワード・APIキー・カード番号・お客さんの個人情報です。

**渡さないものは、Claude Codeを起動するフォルダに置かないでください。**
Claude Codeは、起動したフォルダのファイルを読めます（[権限の説明](https://code.claude.com/docs/en/permissions)）。
貼り付けなくても、フォルダに置いてあれば読まれることがあります。

正直に言うと、Claude Codeの案内どおりに作業を進めていたら、その流れでAPIキーを渡していました。
キーは作り直しました。
**渡さないと決めていても、手順の途中で渡してしまうことはあります。**

学習に使われる条件と、渡してしまったときの対応は、[Claudeに会社の情報を渡して大丈夫か。データが学習に使われる条件](https://aicontent-note.com/claude-company-data-training/)にまとめました。

### ④ 最初の業務は、1人・1つから

1人が、元に戻せる仕事を1つ任せます。
たとえば、記事の下書き、社内の手順書、お客さんの名前を消した表の集計です。

私の場合、最初は練習用のファイルで操作を覚えました。
そのあとで、記事の下書きと、書き方のルールの文書を任せました。
ブログ運用を止めずに回したかったのと、ルールを書いておけば毎回説明しなくて済むからです。

ファイルを書き換える前に確認を出すかどうかは、許可の設定で決めます。
選び方は[Claude Codeの許可、どこまで自動でいいか。モードの選び方](https://aicontent-note.com/claude-code-permission-modes/)に書きました。

【ポイント】<br>
**最初から全員・全業務で始めなくて大丈夫です。<br>
1人が1つの仕事で回してから広げます。**

## 申し込んで、メンバーを招き、ログインする

==4つが決まったら、会社のメールで申し込み、メンバーを招きます。==
その前に、会社のメールで個人のPro・Maxを使っている人がいないかを確かめます。

### 申し込む前に：会社のメールで個人のPro・Maxを使っている人がいたら

**申し込む本人が使っている場合**は、そのアカウントのままTeamに上げます。
最初の設定では、今のアカウントがそのままTeamに変わります。
個人のプランは自動で解約され、日割りで返金されます。

そのとき、今の会話やプロジェクトは会社側に移り、個人には戻せません。
個人の分を残したいなら、「個人アカウントを別に保つ」にチェックを入れます。
チェックを入れると、個人の契約と請求はそのまま続きます。

App Storeで買った人は、Teamが別に作られ、個人の契約は続きます。
止めたいときは、Apple側で自分で解約します。

**招かれる社員が使っている場合**は、招く前に次の3つを伝えておきます（[個人アカウントの移し方](https://support.claude.com/en/articles/9267400-move-your-personal-claude-account-to-a-team-or-enterprise-organization)）。

・本人が「両方残す」か「会社のアカウントだけにする」を選ぶ。両方残すなら、個人の請求も続く<br>
・会社のアカウントに移した会話は、個人に戻せない。招かれた時点で決めなくても、あとで移せる<br>
・会社のアカウントだけにすると、個人のPro・Maxは自動で解約される。App Storeで買った人は個人のアカウントを残す形しか選べないので、先にAppleで解約してから移す

【メモ】<br>
**移すか残すかは、本人が選びます。<br>
招く前に、この2択があることを伝えておいてください。**

### 申し込みからログインまで

1. お金を任せる人が、会社のメールアドレスでClaudeにログインし、Teamを選ぶ（月払いか年払いはここで選ぶ）
2. メンバーを招く（会社が許可したドメインのメールアドレスに限る）
3. 各自がClaude Codeを入れて起動する。「サブスクリプション付き Claude アカウント」を選び、会社のTeamを選んで「認可」を押す
4. 本番の前に、消してもいいフォルダで④の業務を1回試す（どう動くか、何を聞いてくるかを見る）

手順3の項目は、英語の画面では「Claude account with subscription」と出ます。
ログインで「Pro・Maxが必要」と出たら、選び間違いです（[Claude CodeのFAQ](https://support.claude.com/en/articles/12386420-claude-code-faq)）。
`/login`でログインし直して、会社のアカウントを選びます。

私はエンジニアではないので、最初は画面の英語が分かりませんでした。
画面のスクショをAIに見せながら入れました。
入れ方は[Claude Codeとは何か？できること・使い方を実際に使って整理した](https://aicontent-note.com/claude-code-introduction/)に書いています。
