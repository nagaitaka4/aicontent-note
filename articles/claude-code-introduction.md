# 非エンジニアがClaude Codeでできること。始め方と詰まった所

==非エンジニアでも、Claude Codeに記事づくりや事務の作業を任せられます。==
デスクトップアプリなら、ターミナルもNode.jsも要らずに始められます。
私が詰まったのは、以前ターミナルから入れたときの英語の表示と、変更がぶつかったとき、どのAIを使うかでした。

---

## 非エンジニアがClaude Codeでできること：私が任せている10の作業

==Claude Codeは、パソコンのファイルを直接作って直します。==
チャットのAIに答えをもらうのとは違い、作業そのものを任せる使い方になります。
私が今任せている作業は、この10個です。

| 分野 | できること | 例えば |
|---|---|---|
| 記事 | **ブログ記事の構成・下書き・チェック** | ==決めておいたルールに沿って構成から書き、言い回しの癖までチェックする== |
| 記事 | **WordPressへの入稿** | ブラウザごしに、書いた記事を下書きに入れる。公開ボタンだけ人が押す |
| 記事 | **アイキャッチ画像の仕上げ** | 作った画像のサイズを合わせ、名前を付け直し、色を整える |
| 発信 | **SNS投稿の下書きとチェック** | Xの下書きを書き、文字数と1行目を確かめる |
| 調べる | **毎朝の調べ物** | 毎朝決まった時間に、Macが起きていれば自動で調べて、まとめを残す |
| 調べる | **アクセスの数字を読む** | 検索の数字を表にして、見られていないページ・伸びたページを拾う |
| 事務 | **請求書PDFを作る** | 決まった形の請求書をPDFで作る |
| 事務 | **メルカリ出品の下準備** | 写真のフォルダを渡すと、整理して説明文まで用意する |
| 事務 | **カレンダー登録** | 予定を伝えると、カレンダーに入れる |
| 環境 | **ルールと引き継ぎのファイル** | ==毎回説明していたことをファイルに書き、次の日も同じ前提で動いてもらう== |

## Claude Codeの始め方：デスクトップアプリなら、ターミナルは要らない

==アプリを入れてサインインし、「コード」で作業の場所を「ローカル」にしてフォルダを選べば始められます。==
Node.jsや、ターミナルで動かす版のClaude Codeを入れる必要はありません（[公式の始め方](https://code.claude.com/docs/en/desktop-quickstart)）。

・**有料プランが要る**：個人ならPro・Maxで使えます。パソコンはMac・Windowsです<br>
・**最初は小さなフォルダで**：中身をよく知っている小さなフォルダで、その中で終わる作業を1つ頼みます。例えば画像のサイズ合わせや、下書きのチェックです。公式も、よく知っている小さなものから始めるよう勧めています

## Claude Codeで詰まった所：入れるときと、使い始めてから

==英語の表示で止まったときは、画面のスクショをAIに見せて聞けば先へ進めました。==
使い始めてから止まったのは、変更がぶつかったときと、どのAIを使うかです。

| いつ | 詰まった所 | 何が起きたか | 今はどうしているか |
|---|---|---|---|
| 入れるとき | **ターミナルの英語の表示** | 解説動画どおりに進まず、表示も英語で、エラーか正常かも分からない | ==スクショをClaudeとChatGPTに見せて「この画面は正常ですか？」と聞いた==。今はデスクトップアプリで、ターミナルを使わない |
| 使い始めてから | **変更のぶつかり** | コミットとプッシュの意味が分からないまま、VS Codeで作業していた。変更がよくぶつかって（コンフリクト）、どうしたらいいかも分からず止まった | ==作業の前に、最新の状態にそろえてもらう==。ぶつかったら両方の変更を並べて見せてもらい、どちらを残すか選ぶ |
| 使い始めてから | **どのAIを使うか** | Claudeのチャットか、Claude Codeか。ChatGPTならWorkか、ふだんのチャットか、Codexか。どれが一番求める答えを出すのか分からない | 今も決めきれていない。今は、記事づくりはClaude Code、ふだんのチャットはChatGPTで使っている |
