# 社労士業務の就業規則・36協定に、Claude Codeを当てはめた

社労士業務のうち、就業規則・36協定などの規程作成、助成金・補助金の申請書類の作成は、Claude Codeを使えばかなりの範囲を任せられると感じています。

規程作成・書類作成など半自動化できると思いますが、最終的な判断などの責任は、社労士に残ります。

【インフォ】<br>
この記事の結論<br>
・就業規則・36協定などの規程作成 → たたき台作成は任せられる<br>
・助成金・補助金の申請書類作成 → たたき台作成は任せられる<br>
・最終的な届出・法的な判断と責任 → 社労士資格者に残る

---

## Claude Codeという「環境」があれば、何が変わる？

就業規則や36協定は、条件が変わるたびに全体の整合性を見直す必要があります。[前回](https://aicontent-note.com/claude-code-lawyer-case-management/)整理したClaude Codeの環境効果は、ここにも同じように当てはまります。

ここでいう環境とは、条件・条文・変更履歴をまとめて扱える作業環境のことです。

| 項目 | フォーマットを手作業で編集 | 環境がある場合 |
|---|---|---|
| 条件反映 | 都度全文を見直す | 条件を伝えれば整合性を保って反映できる |
| イレギュラー対応 | テンプレートにない条件は自己判断で書き換え | 細かい条件を伝えるほど精度が近づく |
| 整合性 | 変更のたびに全体を確認 | 変更履歴が残り、関連箇所を洗い出せる |

【ポイント】<br>
就業規則は条文同士が依存し合っているため、1か所の変更が関連条項にまで影響することがありますが、Claude Codeの環境だとリスクを切り離して、作業することができます。

## 社労士業務でClaude Code環境を使うと、具体的に何ができる？

就業規則・36協定の整備だけでなく、社労士業務全般について、実際に任せられる範囲を業務ごとに整理しました。

| 業務領域 | 具体的にできること |
|---|---|
| 規程作成 | 就業規則・36協定・育児介護休業規程・賃金規程など各種規程のたたき台作成 |
| 手続き書類 | 助成金・補助金の申請書類、労働条件通知書などのたたき台作成 |
| 労務管理 | 労働者名簿・賃金台帳など法定三帳簿の整理 |
| 制度設計 | 人事評価制度・賃金制度のたたき台作成 |

顧問先ごとに作業スペースを分ける考え方は[ディレクトリ構造とは？AI業務が整理されるフォルダ設計の考え方](https://aicontent-note.com/directory-structure-basics/)で整理しています。希望を具体的に伝えるほど、たたき台は実務に近づきます。

## 顧客の労務情報を、安全に運用するには

Claude Code環境では、給与や個人情報を含む労務情報という機微な情報も、次の仕組みで安全に運用しやすいです。

| 項目 | 具体的にできること |
|---|---|
| バックアップ | 作業データは外部のクラウド上に自動で保存され、パソコンの故障やファイルの消失があっても失われない |
| 変更履歴 | 誰が・いつ・どこを変更したかが記録され、必要ならいつでも前の状態に戻せる仕組み（「Git」と呼ばれる。[こちらで非エンジニア向けに解説しています](https://aicontent-note.com/git-basics/)） |
| チーム共有 | 顧問先ごとの作業スペースを事務所メンバーだけに絞って共有できる仕組み（「GitHub」というサービス上で管理しており、担当外の顧問先のスペースはそもそも見えない） |
| セキュリティ | 二段階認証に標準対応で、プランによってはSSO連携・操作ログの確認も可能 |
| 働き方 | インターネット環境があれば、オフィスの外からでも複数人で共同編集しながら作業できる |

この5つがそろっているからこそ、就業規則や労務情報のような機微な情報も、Claude Code環境に安心して任せられます。

【ポイント】<br>
顧問先が変わったり増えたりしても、同じ使い方で対応できます。社労士に残る責任という前提は変わりませんが、たたき台作成・整理の範囲であれば対応できない工程はほとんどないはずです。

## 環境を整える人がいれば十分

AIへの詳しさより、条件や条文を整理して渡せる仕組みがあるかどうかが分かれ目になりそうです。仕組みさえ整っていれば、日々の運用は無理なく回せるはずです。同じ基準は社労士業務に限らず当てはまるので、他の職種ではどうか気になる方は[Claude Codeと相性が良い職種・業種まとめ](https://aicontent-note.com/claude-code-compatible-jobs/)で確認できます。
