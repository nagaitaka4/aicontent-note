# 弁護士業務の案件管理と書類作成に、Claude Codeを当てはめた

弁護士業務のうち、契約書や各種書類の作成、案件ごとの管理・整理は、Claude Codeを使えばかなりの範囲を任せられると感じています。

書類作成など半自動化できると思いますが、最終的な法的な判断とその責任は、弁護士資格を持つ人に残ります。

【インフォ】<br>
この記事の結論<br>
・契約書・各種書類の下書き作成 → 任せられる<br>
・案件ごとの管理・整理・検索 → 任せられる<br>
・最終的な法的な判断と責任 → 弁護士資格者に残る

---

## なぜチャット型AIでは、契約書や案件管理に限界があるのか

複数の文書を管理しながら整合性を保ち、最新版を維持する。これは契約書や案件管理に共通する業務構造です。この構造は、チャット型AI（GPT等）が苦手とする領域と重なります。

・文脈の持ち出し：会話の外に情報を持ち出せず、案件が複雑になるほど同じ説明を繰り返す必要がある<br>
・変更の追跡：編集履歴が残らず、途中の内容が消えても元の状態に戻せない<br>
・複数文書の参照：契約書・関連書類を横断して確認する仕組みがなく、矛盾や重複に気づきにくい

【ポイント】<br>
原因はAIの文章力ではなく、ファイル・文脈・複数文書の整合性をまとめて扱える「環境」が欠けていることです。

## Claude Codeという「環境」があれば、何が変わる？

ここでいう環境とは、ファイル・文書・案件情報をまとめて扱える作業環境のことです。

| 項目 | チャット型AI | 環境がある場合 |
|---|---|---|
| ファイル | 消える・戻せない | 残る・最新版がすぐ分かる |
| 文脈 | 都度説明し直す | 経緯ごと残る |
| 複数文書 | 1つずつしか見られない | 横断して整合性を確認できる |

### なぜClaude Code環境では解決できるのか

Claude Code環境では、案件ごとの作業スペースにファイルとやり取りの経緯がそのまま残ります。文脈は会話をまたいで参照でき、複数の文書を横断して確認しながら作業できます。条件を最初に整理してしまえば、複数の文書にまたがる案件でも、整合性を合わせる作業は、ほとんど発生しません。

## 弁護士業務でClaude Code環境を使うと、具体的に何ができる？

案件管理と書類作成について、実際に任せられる範囲を業務ごとに整理しました。

| 業務領域 | 具体的にできること |
|---|---|
| 案件管理 | 案件ごとに作業スペースを分けて管理。変更履歴が自動で残り、前の状態にいつでも戻せる |
| 資料整理 | 資料の整理・内容の確認・評価 |
| 書類作成 | 契約書・内容証明・レポート・議事録・申請書類など、各種書類のたたき台作成 |
| タスク管理 | 案件ごとに対応が必要な確認事項やタスクを一覧化し、完了したものから消し込んでいく |

案件ごとに作業スペースを分ける考え方は[ディレクトリ構造とは？AI業務が整理されるフォルダ設計の考え方](https://aicontent-note.com/directory-structure-basics/)で、非エンジニア向けに整理しています。たたき台は、希望する条件や形式を伝えるほど、その内容に近づけて作成できます。

## 案件情報を預けても安全なのか

案件情報という機微な情報を扱う以上、避けて通れない部分です。ここも具体的に整理します。

| 項目 | 具体的にできること |
|---|---|
| バックアップ | 作業データは外部のクラウド上に自動で保存され、パソコンの故障やファイルの消失があっても失われない |
| 変更履歴 | 誰が・いつ・どこを変更したかがすべて記録され、必要ならいつでも前の状態に戻せる。「Git」と呼ばれる仕組みで、詳しくは[こちらで非エンジニア向けに解説しています](https://aicontent-note.com/git-basics/) |
| チーム共有 | 案件ごとの作業スペースを、事務所メンバーだけに絞って共有できる。「GitHub」というサービス上で管理しており、担当外の案件のスペースはそもそも見えない |
| セキュリティ | 二段階認証に標準対応。プランによってはSSO連携・操作ログの確認も可能 |
| 働き方 | インターネット環境があれば、オフィスの外からでも作業できる。複数人での共同編集も、誰が何を変更したかを追跡しながら進められる |

この5つがそろっていることで、契約書や案件情報のような機微な情報を扱っても、ある程度の安全性は確保できます。

【ポイント】<br>
案件の内容が変わっても、同じ使い方で対応しやすいはずです。使い方さえ覚えれば、Claude CodeやAIを初めて使う人でも無理なく運用できると感じています(ただし一般的なPCの操作に慣れていることが前提で、利用者や環境によっても変わります。Claude Code自体が初めての方は[Claude Codeとは何か？できること・使い方を実際に使って整理した](https://aicontent-note.com/claude-code-introduction/)から確認してみてください)。

最終的な判断とその責任は、弁護士資格を持つ人に残ります。今回、案件管理と書類作成という範囲に限って当てはめてみた中では、対応できない工程はあまり見当たりませんでした。あくまで今回当てはめた範囲での実感です。

## 環境を整える人がいれば十分

弁護士自身がAIに詳しくなる必要はないと思っています。専門知識を深めるより、案件や文書をまとめて扱える環境を整える人がいれば、それで十分なはずです。

ここからは私自身の考えですが、導入する事務所とそうでない事務所とでは、近い将来何らかの差が生まれていくのではないかと考えています。自分の業務でも同じ基準が使えるか気になる方は、[Claude Codeと相性が良い職種・業種まとめ](https://aicontent-note.com/claude-code-compatible-jobs/)で確認できます。
