# Claude Codeの許可、どこまで自動でいいか。モードの選び方

==Claude Codeの確認を減らしたいなら、モードは「自動」にします==。
「編集を受け入れる」は、ファイル操作以外の多くのコマンドを毎回聞くので、かえって確認が増えます。
お金や公開中のサイト、人の情報に触る操作と、消したら戻せない操作だけは、手動で見ます。

---

## モードの違いと、選び方

モードは、入力欄の下のモード選択で切り替えます。

![Claude Codeのデスクトップアプリのモード選択。自動（デフォルト）・手動・編集を受け入れる・プランの4つと、その下に権限をバイパス（有効にする）が並んでいる](https://aicontent-note.com/wp-content/uploads/2026/09/img_0071_01.png "入力欄の下のモード名を押すと開く一覧")

| モード | 何をするか | 向いている場面 |
|---|---|---|
| **自動** | 危ない操作だけ止め、あとは聞かずに進める | **普段の作業はすべてこれ** |
| 手動 | 変更の前に毎回聞く | お金・公開中のサイト・人の情報・戻せない削除に触るとき |
| 編集を受け入れる | ファイル編集と一部のファイル操作は聞かずに進め、それ以外の多くのコマンドは毎回聞く | 自動が選べないとき |
| プラン | 先に計画だけ出し、ファイルは変えない | 大きな作業の前に進め方を見たいとき |
| 権限をバイパス | ほぼ何も聞かずに進める | 普段は使わない |

自動では、別のAIが操作を見て、危ないものだけを止めます。

【メモ】<br>
ターミナルで使っているなら、Shift+Tabで切り替えます。

---

## 確認を読まずに「許可」している人は多い？どんな危険がある？

==確認を読まずに「許可」を押している人は多い、と公式は見ています==。
根拠は次の2つです（[公式ブログ](https://claude.com/blog/auto-mode-default-in-claude-code)）。

・確認の97%で「許可」が押されている<br>
・公式の実験では、確認が50回を超えると、人が危ないコマンドを止められた割合は約5%まで下がった

読まずに押すと、次のような操作が通ってしまうことがあります。

| 起きうること | 例 |
|---|---|
| 頼んだ範囲を超える | 社内へのアップロードに失敗し、誰でも見られる共有サイトへ上げようとする（公式の実例） |
| 戻せない削除 | 前からあるファイルやデータを消す |
| 外への持ち出し | パスワードや社内のファイルを外へ送る |
| 仕込まれた指示に従う | 読み込んだページに書かれた命令どおりに動く |

公式は、手元の作業フォルダで元に戻せる操作を、害の大きさ0として採点しています。
下書きの書き換えのような作業なら、読まずに押しても大きな問題にはなりにくいです。
危ないのは、外に出る・消える・お金が動く操作です。

---

## だから、確認を読まないなら「自動」のほうが安全

==公式の比較では、人が13.6%しか止められなかった危ないコマンドを、「自動」は89%止めました==。

・「編集を受け入れる」は、ファイル操作以外の多くのコマンドを毎回聞く。自動なら、危なくないものは聞かずに進む<br>
・「編集を受け入れる」は、作業フォルダ内の通常の削除も自動で進む。自動なら、前からあるファイルを消す操作は止まる

---

## 「今後は聞かない」を押すとどうなるか

==「今後は聞かない」を押したコマンドは、そのプロジェクトでは次から聞かれなくなります==。
そのコマンドは、自動のチェックを通らずに実行されます（[公式](https://code.claude.com/docs/en/auto-mode-config)）。

・押すのは、毎日使う安全な操作だけにする<br>
・許可は、そのプロジェクトの .claude/settings.local.json に残る<br>
・許した操作も自動にチェックさせたいなら、次の設定を足す

【ポイント】<br>
足す場所：~/.claude/settings.json<br>
足す設定：autoMode.classifyAllShell を true

Claude Codeに、この2つを伝えれば足してくれます。

---

## 自動にしても、手動で見る操作

公式も、重大な変更は[今も自分で見ることを勧めています](https://claude.com/blog/auto-mode-default-in-claude-code)。
次の作業をする間だけ、モードを「手動」に切り替えて、1つずつ読んでから許可します。

【チェック】<br>
・公開中のサイトやブログを変える<br>
・支払いや請求、アカウントの設定に触る<br>
・顧客の名簿など、人の情報を扱う<br>
・消したら戻せないファイルやデータを消す

判断できないときは、何をする操作かをClaude Codeに日本語で説明させてから許可します。

---

## 自動なのに確認が出るとき

自動でも、次のときは聞かれます。

| 確認が出る理由 | 減らし方 |
|---|---|
| 自分で「毎回聞く」に登録した操作 | よく使う操作なら、登録を外す |
| 開いているフォルダの外のファイルを初めて読む | 次からも許可する側を選べば、もう出ない |
| セッションのアーカイブなど、アプリの一部の操作 | 減らせない |
| 自動が続けて何度も止めたあと | 出た確認で許可すれば、自動に戻る |

---

## 「権限をバイパス」は押さなくていい

==「権限をバイパス」は、ほぼ何も聞かずに進めるモードで、普段の作業には使いません==。
公式は、壊れても困らない隔離した環境（コンテナやVM）の中だけで使うよう書いています（[公式](https://code.claude.com/docs/en/desktop)）。

【メモ】<br>
モード選択の「有効にする」は、押しても設定が開くだけです。
