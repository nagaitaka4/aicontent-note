# Claude Codeの許可、どこまで自動でいいか。モードの選び方

==Claude Codeの確認を減らしたいなら、モードは「自動」にします==。
「編集を受け入れる」は、ファイル以外の操作を毎回聞くので、かえって確認が増えます。
お金や公開中のサイトに触る操作と、消したら戻せない操作だけは、手動にして自分で見ます。

---

## モードの違いと、選び方

モードは、入力欄の下のモード選択で切り替えます。

![Claude Codeのデスクトップアプリのモード選択。自動（デフォルト）・手動・編集を受け入れる・プランの4つと、その下に権限をバイパス（有効にする）が並んでいる](https://aicontent-note.com/wp-content/uploads/2026/09/img_0071_01.png "入力欄の下のモード名を押すと開く一覧")

| モード | 何をするか | 向いている場面 |
|---|---|---|
| **自動** | 危ない操作だけ止め、あとは聞かずに進める | **普段の作業はすべてこれ** |
| 手動 | 変更の前に毎回聞く | お金・公開中のサイト・戻せない削除に触るとき |
| 編集を受け入れる | ファイル編集は聞かずに進め、それ以外は毎回聞く | 自動が選べないとき |
| プラン | 先に計画だけ出し、ファイルは変えない | 大きな作業の前に進め方を見たいとき |
| 権限をバイパス | ほぼ何も聞かずに進める | 普段は使わない |

自動では、別のAIが操作を見て、危ないものだけを止めます。
2026年8月14日から、Pro・Max・Teamでは自動が最初から選ばれています（[公式](https://claude.com/blog/auto-mode-default-in-claude-code)）。

---

## 確認も少なく、安全なのは「自動」

==確認の回数も、安全さも、「自動」のほうが上です==。
公式の実験では、人は危ないコマンドの13.6%しか止められず、自動は89%を止めました（[公式ブログ](https://claude.com/blog/auto-mode-default-in-claude-code)）。

・「編集を受け入れる」は、ファイル編集以外のコマンドを毎回聞く。自動なら、危なくないものは聞かずに進む<br>
・ファイルを消す操作は、「編集を受け入れる」だと誰もチェックしない。自動なら、前からあるファイルを消す操作は止まる<br>
・確認の97%は「許可」が押されている。読まずに押すくらいなら、自動に任せたほうが安全

「編集を受け入れる」を使うのは、自動がモード選択に出ないときです。

「今後は聞かない」で許可した操作は、自動でもチェックされません。
気になるなら、次の設定を足します。

【メモ】<br>
Claude Codeに「全体の設定に<br>
autoMode.classifyAllShell を true で足して」と頼む

## 自動にしても、手動で見る操作

公式も、重大な変更は[今も自分で見ることを勧めています](https://claude.com/blog/auto-mode-default-in-claude-code)。
次の作業をする間だけ、モードを「手動」に切り替えて、1つずつ読んでから許可します。

【チェック】<br>
・公開中のサイトやブログを変える<br>
・支払いや請求、アカウントの設定に触る<br>
・顧客の名簿など、人の情報を扱う<br>
・消したら戻せないファイルやデータを消す

判断できないときは、何をする操作かをClaude Codeに日本語で説明させてから許可します。

---

## 自動なのに確認が出るとき

自動でも、次のときは聞かれます。

| 確認が出る理由 | 減らし方 |
|---|---|
| 自分で「毎回聞く」に登録した操作 | よく使う操作なら、登録を外す |
| 開いているフォルダの外のファイルを初めて読む | 次からも許可する側を選べば、もう出ない |
| セッションのアーカイブなど、アプリの一部の操作 | 減らせない |
| 自動が続けて何度も止めたあと | 出た確認で許可すれば、自動に戻る |

---

## 「権限をバイパス」は押さなくていい

==「権限をバイパス」は、ほぼ何も聞かずに進めるモードで、普段の作業には使いません==。
公式は、壊れても困らない隔離した環境（コンテナやVM）の中だけで使うよう書いています（[公式](https://code.claude.com/docs/en/desktop)）。

【メモ】<br>
「権限をバイパス　有効にする」を押しても、設定画面が開くだけです。<br>
その場では切り替わりません。

確認を減らしたいだけなら、自動で足ります。
