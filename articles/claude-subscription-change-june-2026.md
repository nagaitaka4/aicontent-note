# Claudeに課金すべきか。料金・制限より先にモデルで決める

==Claudeに課金するかは、使うモデルで候補を絞り、使用量で決めます==。
Claude Codeの最新版では、Proでも標準が重いOpusです。
Fableを使わないならMax 5xは枠の単価が下がらないので、先にモデルを見直します。

---

【インフォ】<br>
6月に予定されていた課金の変更は実施されていません（後半で説明）

## Claudeに課金すべきか：4つの手順で決める

上から順に答えると、1つの結論に着きます。
何回当たったら「よく」か、という基準は公式にはありません。

### 手順1：使いたいものはどれか

・チャットでHaikuかSonnetを使うだけで、上限にほぼ当たらない → **無料のまま**<br>
・チャットだけだが、無料で上限によく当たる → Haikuで足りる作業はHaikuに、長い会話は新しいチャットに。それでも当たるならPro（手順3へ）<br>
・Claude Code / Opus / Fableのどれかを使いたい → **Pro以上**（どれも無料では使えない。手順2へ）

### 手順2：Fableをどう使いたいか

・Fableの使用クレジットが月80ドルを超えそうなほど使う → **Max 5x**（手順3へ）<br>
・それより少なく使う → **Pro＋使用クレジット**（手順3へ）<br>
・使わない → **Pro**（手順3へ）

FableはProでは最初から別料金（使用クレジット）です。
Maxなら、週次上限の最大50%まで追加料金なしで使えます。

### 手順3：そのプランで使って、上限によく当たるか

・いいえ → **手順1と2で出たプランのまま**（使用量を理由に、さらに上げる必要はない）<br>
・まだ使っていない → まず手順1と2で出たプランで始める<br>
・はい → 手順4へ（ProでもMaxでも同じ）

### 手順4：当たる原因を直し、それでも止まるなら種類で分ける

まず、当てはまる使い方を直します。

1. 同じチャットやセッションを長く続けている → 新しいチャットにする。Claude Codeはコンパクトか新しいセッション<br>
2. その作業に要るより重いモデルを使っている → 1段軽いモデルに。精度が要る作業は下げない

直しても止まるなら、右下のゲージで、止まっているのがどの上限かを見ます。

| 止まっている上限 | いまのプラン | 行き先 |
|---|---|---|
| 5時間制限 | Pro | 使用クレジットの月の支払いが80ドル未満ならPro＋使用クレジット、超えそうならMax 5x |
| 5時間制限 | Max 5x | Max 20x |
| 週次上限のうちFableの枠だけ | Max | Opusなど別のモデルに切り替える。Fableを続けるなら使用クレジット |
| 全モデルの週次上限 | Pro・Max | リセットを待つか使用クレジット。Proで使用クレジットが月80ドルを超えそうならMax 5x（週次の倍率は非公開なので、足りるかは使って確かめる） |

80ドルは、Max 5x（100ドル）とPro（20ドル）の月額の差です（税別）。
Fableの枠を使い切った後も、別のモデルならプランの上限の範囲で続けられます（[Fableの公式ヘルプ](https://support.claude.com/en/articles/15424964-claude-fable-models-on-your-plan)）。
週次上限がMaxで何倍になるかは、公開されていません。

原因の見分け方は、後半の「上限に当たる原因を見分ける」で説明します。

## モデルで、上限の減り方が変わる

同じプランでも、選ぶモデルで上限の減り方が違います。
公式は、軽い順にHaiku、Sonnet、Opus、Fableと説明しています（[Claude Academy](https://academy.claude.com/tutorials/choosing-the-right-claude-model)）。

・原文は「Opus is heavy, and Fable uses the most.」。倍率の数字は出ていない<br>
・Claude Codeの既定はOpus 5.5（v2.1.280以降。Pro / Max / Team共通。[公式ドキュメント](https://code.claude.com/docs/en/model-config)）<br>
・Opus 5.5は前のOpusより安く、同じ上限で25%長く使える（[9月22日の告知](https://x.com/ClaudeDevs/status/2102438800836489554)）。それでもSonnetよりは重い<br>
・Fableは、Proでは最初から使用クレジット。Maxは週次上限の最大50%まで追加料金なし（[Fableの公式ヘルプ](https://support.claude.com/en/articles/15424964-claude-fable-models-on-your-plan)）

**最新版でモデルの設定を変えていなければ、ProでもClaude Codeは重いOpusで動きます**。
下げるのは、Sonnetで足りる作業だけです。
精度が要る作業まで下げると、品質も下がります。

### どの作業に、どのモデルを使うか

同じClaude Academyのページが、モデルごとの向き不向きと例を挙げています。

| モデル | 向いている作業（公式） | 公式の例 |
|---|---|---|
| Haiku | 短く答えられる単純な質問 | 記事の要約 |
| Sonnet | 文章やコンテンツの作成。迷ったときの汎用 | コードのデバッグ |
| Opus | 問い直しながら深める調査・分析 | 長く専門的な論文の分析 |
| Fable | つながった手順が多い長い作業。結果だけ伝えて段取りを任せたい作業 | ラフなアイデアから動くものを作る |

同じページには、重いモデルの使いすぎへの注意もあります。
SonnetやHaikuで足りる作業にOpusやFableを使うと、上限を必要以上に使うかもしれない、という注意です。
プランを上げる前に、この表で作業ごとのモデルを見直せば、上限の減り方を抑えられる場合があります。

私の場合は、基本をOpusにして、精度がほしいところだけFableに切り替えています。

### モデルの切り替え方

・チャット：入力欄にあるモデル名を押して選ぶ<br>
・Claude Code：`/model`で、いまのモデルの確認と切り替えができる

## 料金：Max 5xは、5時間ごとの枠で見るとProの5倍

ProとMaxの大きな違いは、料金と使える量です。
金額はドル建てで、税は含まれていません。

| プラン | 月額（税別） | 5時間ごとの量 | 支払い |
|---|---|---|---|
| Pro | 20ドル（年払いは年200ドル一括・月換算約17ドル） | Freeの少なくとも5倍 | 月払い・年払い |
| Max 5x | 100ドル | Proの5倍 | 月払いのみ |
| Max 20x | 200ドル | Proの20倍 | 月払いのみ |

出典は[料金ページ](https://claude.com/ja/pricing)と[Maxプランの公式ヘルプ](https://support.claude.com/en/articles/11049741-what-is-the-max-plan)です。
**5時間ごとの枠だけで比べると、Max 5xは料金も量もProの5倍で、枠の単価は下がりません**。
料金より5時間ごとの量が大きく伸びるのは、Max 20x（料金10倍・量20倍）だけです。

公式が倍率を示しているのは、5時間ごとの量だけです。

Maxには量のほかに、次の3つが付きます（料金ページ）。

・すべてのタスクで高い出力制限<br>
・高度な Claude 機能への早期アクセス<br>
・高トラフィック時の優先アクセス

私の画面では、Max 5xは「$110（消費税込み）」と表示されていました。

### 無料からProに課金すると増えるもの

無料で使えるのはHaikuとSonnetで、Claude Codeは使えません。
料金ページのProの項目から、選ぶときに効くものを抜き出します。

・より多くの使用量<br>
・Claude Code<br>
・より多くのClaudeモデル（OpusとFable。FableはProでは使用クレジット）<br>
・プロジェクトの上限がなくなる（無料は最大5つ）

## 制限：5時間制限と週次上限

Claudeの上限は、時間の区切りが違う2つです。
Pro・Maxには、5時間ごとの上限に加えて週次上限があります。

・5時間制限：5時間ごとにリセットされる、使える量の上限。Freeにもある<br>
・週次上限：全モデルにかかる週ごとの上限。リセットの時刻はアカウントごとに決まっている<br>
・5x／20x：Proの「5時間ごとに使える量」の5倍と20倍<br>
・使用クレジット：上限を超えた利用やProでのFableを、APIの標準料金で続ける仕組み。自分で有効にして残高を足す

チャットとClaude Codeは、同じ上限を分け合います（[公式ヘルプ](https://support.claude.com/en/articles/11145838-use-claude-code-with-your-pro-or-max-plan)）。
チャットで使った分だけ、Claude Codeで使える量が減ります。

【インフォ】<br>
9月14日から、Claude Codeの週次上限は通常より25%多い<br>
9月22日に、使用量を1回リセットできる権利が配られた（10月22日まで）

出典は[8月30日の告知](https://x.com/ClaudeDevs/status/2093742321473065266)と[9月22日の告知](https://x.com/ClaudeDevs/status/2102438800836489554)です。
9月22日には、Claude Codeの5時間制限も20%増えました。

## 上限に当たる原因を見分ける

当たる原因が分かれば、プランを上げる前に直せます。
チャットは設定の画面、Claude Codeは右下のゲージで見ます。

### チャット：会話の長さと、選んでいるモデル

同じチャットを長く続けた後に当たるなら、会話の長さが原因の候補です。
重いモデルを選んだままでないかも、入力欄のモデル名で確かめます。

残りの量は、設定の使用量の画面（英語表示では Settings → Usage）で見られます。
9月22日に配られたリセットも、ここから使えます。

### Claude Code：右下のゲージと/usage

デスクトップアプリでは、入力欄の右下にあるゲージを押すと、残りが見られます。

![Claude Codeのデスクトップアプリで、入力欄の右下のゲージを押した画面。プランの使用量上限・Max (5x)の下に、5時間制限34%・週間・全モデル26%・週次・Fable 21%のバーとリセットの時刻が並んでいる](https://aicontent-note.com/wp-content/uploads/2026/09/img_0027_01.png "入力欄の右下のゲージを押した画面（Max 5x）")

5時間制限は画面でも同じ名前で、「週間・全モデル」が週次上限です。
「週次・Fable」は、週次上限のうちFableに使える分を指します。

ゲージの「詳細な内訳を見る」を押すと、`/usage`が開きます。
過去24時間で、どんな使い方が使用量を消費したかが出ます。

![Claude Codeの/usageの画面。何が使用制限を消費していますか？の下に、150kコンテキスト以上で実行91%、8時間以上アクティブなセッションから85%、サブエージェントを多用したセッションから55%と並んでいる](https://aicontent-note.com/wp-content/uploads/2026/09/img_0027_02.png "/usageの内訳の読み方の例（私の1台・過去24時間）")

読み方の例として、私の画面の数字を挙げます。
**91%が、150kコンテキスト以上で実行した分**でした。
会話やファイルが積み上がり、一度に読む量が15万トークンを超えた状態です。

85%が8時間以上続いたセッション、55%がサブエージェントを多く使ったセッションからです。
画面に「概算、重複あり」とあるとおり、合計は100%になりません。
1台のマシンの24時間分で、チャットでの利用は含みません。

この画面のヒントは、タスクの途中ではコンパクトを、別のタスクでは新しいセッションを勧めています。
原因がセッションの長さなら、プランより先にこちらを直します。

## 例：モデルを知ってから、必要なプランが決まった

ここからは私の例です。
手順のどこに当たるかを添えます。

### Proのときは、標準のSonnetのままだった（手順1）

Proのときは、標準のままSonnetを使っていました（9月22日より前の話です）。
正直に言うと、モデルにそこまで差があるとは知りませんでした。

### OpusとFableを知って、Max 5xにした（手順2と3）

OpusとFableを使い出したうえに、Proでは開発中によく上限に当たっていました。
そこでMax 5xにしました（手順2と3）。
止まった回数は数えていません。

### Max 5xでも、Fableのままだと止まった（手順4の2）

Fableのまま切り替えを忘れると、5時間制限にかなり早く当たります。
作業が止まったことが、2〜3回ありました。
20xにしなくても、使い方を直せば止まらなくなりました。

【チェック】<br>
Fableを使うときは、右下のゲージをこまめに見る

使用クレジットとMax 20xは、使ったことがありません。

## 6月に予定されていた課金の変更はどうなったか

6月15日から、自動化の利用を別のクレジットに分ける予定がありました。
**この変更は一時停止され、実施されていません**。

| 項目 | 当初の予定 | いま |
|---|---|---|
| Agent SDK・`claude -p`・他社アプリ | 別のクレジットから引く | これまでどおりプランの上限から引く |
| 月ごとのクレジット（Pro 20ドル／Max 5x 100ドル／Max 20x 200ドル） | 配られる | 配られない |

出典は[Agent SDKの公式ヘルプ](https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan)です。
Anthropicは、変更する前に知らせるとしています。
変わるまでは、Agent SDKなどを使っていても、手元で対応することはありません。

## 結局、Claudeに課金すべきか

手順の答えを、短く並べ直します。

・チャットでHaikuかSonnetだけ → 無料。モデルと会話の長さを直しても当たるならPro<br>
・Claude CodeかOpusを使う → Pro<br>
・Fableを使う → 使用クレジットが月80ドル未満ならPro＋使用クレジット、超えそうならMax 5x<br>
・上限に当たる → まず長いセッションと、要らない重いモデルを直す<br>
・Proで直しても5時間制限に当たる → 使用クレジットが月80ドル未満ならそのまま、超えそうならMax 5x<br>
・Max 5xで直しても5時間制限に当たる → Max 20x<br>
・Fableの週次の枠だけ尽きる → 別のモデルへ。Fableを続けるなら使用クレジット<br>
・全モデルの週次上限が尽きる → リセット待ちか使用クレジット。Proで月80ドルを超えそうならMax 5x

**まずは使用量のバーを見て、何で減っているかを確かめてください**。
