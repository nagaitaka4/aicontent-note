# ブログは外注か内製か。AIで書く実費と代行の相場を並べた

払う金額だけなら、==AIで内製するほうが運用代行よりずっと安い==です。
ただ、私の場合、慣れたいまも1本を公開するまでに、ならして3時間ほどかかります。
その時間を毎月取れるなら内製、取れないなら外注です。

---

## 外注の相場と内製の実費。月にいくら払うのか

**公開まで任せる運用代行と比べると、内製のツール代はずっと安く済みます。**
やり方は、AIを使って自分たちで書く内製、記事作成だけの外注、運用代行の3つです。

| やり方 | 月に払う金額 | 自分たちでやる作業 |
|---|---|---|
| AIで内製（Claude Codeで構成から入稿まで） | 始めるだけなら月約3,500円（22ドル）から。私は月約2万円（130ドル。ブログ以外の開発にも使うプランの金額） | テーマ決め / 内容の確認と直しの依頼 / アイキャッチの画像づくり / 公開していいか決める |
| 記事作成だけ外注 | 1本5,000〜5万円（月4本なら月2万〜20万円） | テーマ決め / 構成の確認と修正の指示 / 画像の準備と入稿 |
| 公開まで任せる運用代行 | 月10万〜30万円（本数と任せる範囲で変わる） | 最初のすり合わせ / できた記事の確認 |

円は、2026年10月時点の1ドル158円で換算しています。

記事作成だけの外注が1本5,000円で月4本なら月2万円で、私のツール代と同じくらいです。
月約3,500円のProだけで始めるなら、内製のほうが安く済みます。

外注の金額は、代行会社などが自社のページで出している目安です。
幅が何で決まるかは、[ブログ代行の相場はいくら？運用代行の料金目安と失敗しない選び方](https://aicontent-note.com/blog-outsource-pricing-guide/)にまとめています。

私は、ブログ運用の代行を請ける側ですが、自分のブログはAIで内製しています。

---

## AIで内製すると、何にいくら払うのか

==Claude Codeで始めるなら、払うのは月22ドル（約3,500円）のProだけ==です。
私が払っているのは、月130ドル（約2万円）です。

【メモ】<br>
**Claude Codeは、手元のファイルを読んで作業を進めるClaudeの道具。Pro・Maxの契約に含まれます**（[公式](https://support.claude.com/en/articles/11145838-use-claude-code-with-your-pro-or-max-plan)）。

| ツール | 月額 | 何に使っているか |
|---|---|---|
| Claude Max 5x（私の契約） | 100ドル＋消費税10%＝110ドル（約1万7,000円） | Claude Codeで構成・執筆・チェック・WordPressへの入稿まで |
| Claude Pro（いちばん安く始めるなら、これだけ） | 20ドル＋消費税10%＝22ドル（約3,500円・月払い） | 同じClaude Codeが使える。使える量はMaxより少ない |
| ChatGPT Plus（私の契約） | 20ドル（約3,200円）。いま日本で新しく契約すると月3,000円 | アイキャッチの画像 / 書いた記事を別のAIに見てもらうレビュー |

料金は、[Claudeの料金ページ](https://claude.com/ja/pricing)と[ChatGPTの料金ページ](https://chatgpt.com/ja-JP/pricing/)で2026年10月2日に確かめました。
日本では、Claudeの料金に消費税10%が加算されます。

プランの利用上限に収まる限り、1本ごとの料金はかかりません。
私は、記事のほかに開発の作業にも使っているのでMaxにしています。
ChatGPTは記事を書くのに必須ではなく、画像とレビューのために足しています。

私と同じように、Claude ProとChatGPT Plusの2つを使うなら、月に約6,500円からです。
ProとMaxのどちらにするかは、[Claudeに課金すべきか。料金・制限より先にモデルで決める](https://aicontent-note.com/claude-subscription-change-june-2026/)に書きました。

## ツール代は安い。ただ、1本を公開するまでに、ならすと3時間ほどかかる

==3時間は、私が自分で動いた時間の目安==です。
毎回測った数字ではなく、2〜4時間ほどのばらつきをならした体感です。

時間を使っているのは、次の作業です。

・何を書くか、どの順で出すかを決めて、指示を出す<br>
・構成と本文を確認して、直してほしい所をコメントに書いて頼む<br>
・アイキャッチの画像を作る<br>
・公開していいか決める

書くこと自体は、Claude Codeが進めます。

いちばん効いたのは、WordPressへの入稿を自動にできたことです。
見つけた直しも、そのままClaude Codeに直してもらえるようになりました。

**それでも、記事づくりは相変わらず安定せず、構成と本文を読んで直す作業は残っています。**

人に残る工程は、[ブログ運用はどこまで自動化できたか。人に残った2つの判断](https://aicontent-note.com/blog-operation-automation-limit/)に表でまとめています。

【ポイント】<br>
**いまの私でも、月4本なら自分が動く時間は月12時間ほどです。**

## 外注か内製かは、浮くお金とかける時間で決める

==運用代行から内製に替えると、お金が浮く代わりに時間がかかります==。

たとえば、月4本で月10万円の運用代行の見積もりをもらったとします。
金額は、自分の見積もりに置き換えてください。

| | 運用代行に頼む（月10万円の見積もりの例） | AIで内製（月4本・ツール代は私の金額） |
|---|---|---|
| 月に払う金額 | 10万円 | 約2万円（始めるだけなら約3,500円） |
| 自分たちに残る作業と時間 | 最初のすり合わせ / できた記事の確認（時間は測っていない） | 月12時間ほど |

この例で内製に替えると、払う金額は月に約8万円下がります。
一方、内製では自分が月12時間ほど動きます。
運用代行でも記事を確認する時間は残るので、12時間すべてが外注との差ではありません。

決め方は、次の3つです。

・毎月その時間を取れる → 内製<br>
・取れない。手を離したい → 公開まで任せる運用代行<br>
・下書きを自分で直すのは難しいが、テーマ決め / 修正の指示 / 入稿はできる → 記事作成だけの外注

運用代行を頼むタイミングは、[ブログ更新が止まる理由と、外注を検討するタイミングの見極め方](https://aicontent-note.com/blog-update-outsource-timing/)に書いています。

いま記事作成だけを外注しているなら、払っている月額と、内製のツール代を比べます。
ツール代は、始めるだけなら月約3,500円です。
その差額と引き換えに、月12時間ほど使えるかで決めます。

【チェック】<br>
**先に「月に何時間取れるか」を数える。金額を比べるのは、そのあと。**
