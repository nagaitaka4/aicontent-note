# ロゴのパクリはどこまで？AIで作るときの著作権・商標と類似チェック

ロゴのパクリに==「ここまで」という明確なライン==は、国内外で見つかりませんでした。
著作権は「参考にしたか」を見ますが、商標は参考にしていなくても紛らわしければ問われます。
たまたま似た場合の扱いと類似チェックのやり方を、作例と公式の資料で確かめます。

## ロゴのパクリはどこまで？明確なラインは無く、著作権と商標で見る所が違う

「何％似たらアウト」という共通の数値ラインは、公的機関の資料にありません。
デザイナーの団体も、似ているかの一般的な基準は示していません。
代わりに、著作権と商標で「見る所」が決まっています。

【本】<br>
There is no mechanical test<br>
（USPTO TMEP §1207.01・2026年5月版）

米国特許商標庁（USPTO）の[審査基準](https://tmep.uspto.gov/RDMS/TMEP/current)の一文で、紛らわしいかを機械的に判定する方法は無い、という意味です。
米国著作権局も、許可なく使える量に決まった公式は無いと書いています（[Fair Use Index](https://www.copyright.gov/fair-use/)）。

文化庁は、著作権法の解釈を「個別具体的な事案に応じた司法判断によるべきもの」としています。
出典は、[「AIと著作権に関する考え方について」](https://www.bunka.go.jp/seisaku/bunkashingikai/chosakuken/pdf/94037901_01.pdf)のPDF p.3です。

日本グラフィックデザイン協会（JAGDA）にも、[『著作権Q&A』](https://archive.jagda.or.jp/pdf/qa.pdf)という資料があります。
似ているかの判断基準を問う質問には、「一般的な基準はなく」と答えています（p.24）。
海外でも、米国の[AIGA](https://www.aiga.org/resources/aiga-standards-of-professional-practice)などデザイン団体の倫理規定に、似ている程度の具体的な基準はありません。

### ぱっと見で分かる：ケースごとに関係するルールと、起こりうること

数値のラインは無くても、どのケースでどのルールが関係し、何が起こりうるかは資料で分かります。

| よくあるケース | 関係するルール | 起こりうること |
|---|---|---|
| 有名ブランドのロゴに寄せた | 商標・不正競争防止法。広く知られた有名ブランド（日本では全国的に知られた「著名」なもの）で、イメージを弱める・汚す、ただ乗りする使い方なら、商品・サービスが違っても、紛らわしくなくても守られる | 条件にあたれば、警告・使用の差止め・損害賠償 |
| 商品・サービスが同じ・似ている登録ロゴと、見た目・読み・イメージのどれかが紛らわしい | 商標。参考にしていなくても問われ、日本では知らなくても過失が推定される | 出願は拒絶。使っていれば警告・差止め・損害賠償 |
| 既存の作品をリファレンスにして、形や描き込みまで似せた | 著作権。登録していない作品にもある | 差止め・損害賠償 |
| 商品・サービスが違う、有名ではない登録ロゴと似ている | 商標は「マーク×商品・サービス」の組み合わせ。見るのは業界名ではなく、商品・サービスの類似・関連 | 関連しないと判断されれば侵害にならない。関連すれば2行目と同じ |
| テイストやよくある形だけが似た | 著作権ではアイデアの扱い | 著作権では問われない。商標は2行目・4行目で見る |
| リファレンスなしで作ったら、たまたま似た | 著作権は参考にしたか（依拠）が要る。AIの学習データに入っていた作品なら、知らなくても依拠が推認されうる | 人が知らずに作り、学習データにも無ければ著作権では問われない。商標は2行目・4行目で見る |

表の根拠は、このあとの見出しで、条文や資料へのリンクと一緒に書きます。
規模のイメージは、次のとおりです。

・登録されている商標は、日本で約230万件（2024年末）、米国で約350万件（2025年度）（[特許庁](https://www.jpo.go.jp/resources/report/nenji/2025/document/index/0202.pdf)、[USPTO](https://www.uspto.gov/sites/default/files/documents/USPTOFY25WorkloadTables.xlsx)）<br>
・警告状の件数は、米国の公的機関も持っていない（[USPTOの議会報告書](https://www.uspto.gov/sites/default/files/trademarks/notices/TrademarkLitigationStudy.pdf)、2011年）<br>
・日本の企業調査では、過去5年に商標で警告状を受けたのは回答者の約5%、訴えられたのは1%未満（[特許庁](https://www.jpo.go.jp/resources/statistics/chizai_katudo/2025/index.html)、2025年度）<br>
・訴訟になっても、米国で裁判まで進むのは100件に1〜2件ほど（同じ議会報告書、2001〜2010年のデータ）

どれも「自分のロゴが問われる確率」ではありません。
確率を示す公的な統計は、見つかりませんでした。

著作権と商標では、比べる相手も見る所も違います。

| | 著作権 | 商標 |
|---|---|---|
| 比べる相手 | 既存の作品。商品・サービスが同じかどうかは要件に入らない | 登録されたロゴ（国によっては、登録していなくても使われているロゴ）のうち、商品・サービスが同じ・似ている（関連する）もの。有名ブランドは、条件を満たせば商品・サービスが離れていても対象 |
| 見る所 | 形や描き込みといった表現が共通しているか（類似性） | 見た目・イメージ・読み（外観・観念・称呼）で紛らわしいか |
| 参考にしたか | 問われる（依拠性） | 問われない |
| 主な資料 | 文化庁・Feist判決（米国） | 特許庁・商標法・TMEP（米国）・EUIPO（EU）・WIPO |

==商標法の条文には、知っていたかどうかの要件がありません==。
[商標法](https://laws.e-gov.go.jp/law/334AC0000000127)は、登録商標の使用を「専有する」と定めています（第25条）。
似た範囲の使用も、侵害と「みなす」としています（第37条）。

特許庁の[審議会の資料](https://www.jpo.go.jp/resources/shingikai/sangyo-kouzou/shousai/shohyo_shoi/document/t_mark_paper12new/02.pdf)も、商標権侵害の要件として「依拠性は不要」と書いています。

### 著作権で守られないもの

・よくある図形や、よく知られた記号（[37 CFR 202.1](https://www.ecfr.gov/current/title-37/part-202/section-202.1)、[Compendium §906](https://www.copyright.gov/comp3/chap900/ch900-visual-art.pdf)）<br>
・フォント（書体）の形そのもの（37 CFR 202.1(e)、Compendium §906.4）<br>
・プロンプトだけで生成した部分。人が加えた表現や、選び方、修正は守られうる（[米国著作権局 Part 2](https://www.copyright.gov/ai/Copyright-and-Artificial-Intelligence-Part-2-Copyrightability-Report.pdf)）

文字やフォントを並べただけのロゴも、米国著作権局が登録を断る例に挙げています（Compendium §914.1）。
日本では、印刷用書体が著作物になるための要件を示した最高裁判決があります（[ゴナU事件](https://www.courts.go.jp/assets/hanrei/hanrei-pdf-54774.pdf)）。
顕著な特徴といった独創性と、美術鑑賞の対象になる美的特性の両方が要る、という内容です。

**書体の形が守られないなら、フォントのデータも自由？**<br>
米国では、書体を作るプログラム（ソースコード）が、著作権の登録を受けられる場合があります。
出典は、米国著作権局の[Compendium §723](https://www.copyright.gov/comp3/chap700/ch700-literary-works.pdf)です。
使ってよいかは、フォントのライセンスで決まります（最後の見出し）。

**AIで作ったロゴは、守られない？**<br>
著作権は、事案ごとの判断です。
商標では、AIで作ったこと自体は、登録を妨げる理由として扱われていません。

人が作ったロゴと同じ拒絶理由（商標法 第3条・第4条）に当たらなければ、登録を受けられます。
上の審議会の資料（p.43）の整理で、議論用の資料なので確定した基準ではありません。

## 商標で「問われる」と何が起きる？出願の審査・警告・有名ブランド

商標で問われるのは、出願から登録後までの過程と、ロゴを使っている場面です。
どちらも、商品・サービスの近さと、見た目・読み・イメージの近さで見られます。
有名ブランドだけは、この見方に例外があります。

### 出願したとき：審査で拒絶され、登録後も覆ることがある

日本では、先に出願された似た登録商標があると、登録を受けられません。
商品・サービスも、同じか似ている場合です（商標法 第4条第1項第11号）。

似ているかは、マークは外観・称呼・観念を総合して見ます。
商品・サービスは、「類似群コード」が同じなら類似と推定されます。
例えば、書籍と新聞は類似、書籍とタオルは非類似です（[特許庁](https://www.jpo.go.jp/system/basic/trademark/index.html)）。

米国では、審査官が連邦のデータベースで、登録済みと出願中の商標を必ず調べます。
紛らわしさは、拒絶の理由でいちばん多いものです（[USPTO](https://www.uspto.gov/trademarks/search/likelihood-confusion)）。

審査に通った後も、安心とは限りません。
第三者からの異議や、登録を無効・取り消しにする請求で覆ることがあります。
手続きは、日本では商標法 第43条の2・第46条に、米国では[USPTOのページ](https://www.uspto.gov/trademarks/i-received-letter)にあります。

### 使っているとき：権利者から警告や請求が来る

商標権は、登録によって生まれます（商標法 第18条）。
商標法による差止めや損害賠償は、登録された商標の話です。
著作権は、登録しなくても生まれます（[著作権法](https://laws.e-gov.go.jp/law/345AC0000000048) 第17条第2項）。

登録していない表示でも、周知・著名なら、持ち主は[不正競争防止法](https://laws.e-gov.go.jp/law/405AC0000000047)で差止めや損害賠償を求められます（第3条・第4条）。

日本では、登録していなくてもロゴは使えます。
ただし、他人が似た商標を登録していれば、警告や損害賠償の請求を受けるおそれがあります。
出典は、[特許庁のよくある質問](https://www.jpo.go.jp/faq/yokuaru/trademark/shouhyou_seido_faq.html)の1-2です。
請求されるのは、使用の差止め（第36条）と損害賠償（第38条）です。

【ポイント】<br>
知らずに使っていても、過失があったと推定されます。<br>
（商標法 第39条で、特許法 第103条を準用）

刑事罰もあります（第78条）。
ただ、検挙は近年、年200件前後で、多くはフリマなどでの偽ブランド品の販売です（[警察庁](https://www.npa.go.jp/publications/statistics/safetylife/2026_nenpou_teisei.pdf)）。

米国では、訴えられる前に警告（cease-and-desist letter）が届くことがあります。
訴えられれば、差止め、相手の利益、損害（最大3倍）、訴訟費用を求められます（[15 U.S.C. §1117](https://www.law.cornell.edu/uscode/text/15/1117)）。

商標権は、「マーク」と「商品・サービス」の組み合わせです。
どちらかが似ていなければ、侵害になりません（特許庁 よくある質問 1-5）。

**どこまで離れた商品・サービスなら大丈夫？**<br>
見るのは業界名ではなく、商品・サービスが似ているか・関連するかです。

・日本の類似群コードは、類似すると推定する審査の目安（[特許庁「商標制度の概要」](https://www.jpo.go.jp/system/trademark/gaiyo/seidogaiyo/chizai08.html)）<br>
・出願の区分（第◯類）も、類似の範囲を決めたものではない（同じページ）<br>
・米国では、マークが似ているほど、商品やサービスの近さは少なくてよい（TMEP §1207.01(a)）

### 有名ブランドは、条件を満たせば商品・サービスが違っても守られる

同じ「Dove」でも、石けんとアイスは別々の持ち主が登録できます（[USPTO](https://www.uspto.gov/trademarks/search/likelihood-confusion)）。
この例外が、有名なブランドです。

日本では、他人の商品と混同を生ずるおそれがある商標は、登録を受けられません（商標法 第4条第1項第15号）。
登録していない表示でも、著名なものは、混同が無くても不正競争防止法で守られます（第2条第1項第2号）。

経済産業省の[テキスト](https://www.meti.go.jp/policy/economy/chizai/chiteki/pdf/unfaircompetition_textbook.pdf)では、著名とは全国的に世間一般に知られていることです。
問題にするのは、顧客を引きつける力の不当な利用や、ブランドイメージの希釈化・汚染です。

米国では、有名な商標（famous mark）は、混同も競合も無くても差止めを求められます。
条件は、次のとおりです（[15 U.S.C. §1125(c)](https://www.law.cornell.edu/uscode/text/15/1125)）。

・有名とは、米国の一般の消費者に広く知られていること<br>
・理由になるのは希釈化で、識別力を弱めたり、イメージを汚したりすること<br>
・比較広告、パロディや論評、報道、非商業的な使用は除かれる<br>
・金銭の請求ができるのは、故意の場合

同じ「COACH」でも、混同のおそれなしとされた例もあります。
試験対策の教材と、高級バッグの組み合わせです（TMEP §1207.01(a)(i)）。

EUでは、名声（reputation）のある商標は、商品・サービスが似ていなくても守られることがあります。
マークが似ていて、正当な理由なく名声にただ乗りしたり、害したりする場合です。
ただし、商品・サービスがかけ離れ、公衆が2つを結び付けなければ当てはまりません（[EUIPO](https://guidelines.euipo.europa.eu/2319054/1788248/trade-mark-guidelines/section-5-trade-marks-with-reputation-article-8-5-eutmr-)）。

この記事の作例は、有名なカフェチェーンのテイストを借りた架空のロゴです。
実在のブランドと並べたときは、このルールも関わります。

### 登録していないロゴは、どう扱われる？

日本は、先に出願した人が登録を受ける先願主義です（[特許庁の制度の説明](https://www.jpo.go.jp/system/trademark/gaiyo/seidogaiyo/chizai08.html)）。
先に使っていても、広く知られているといった事情がなければ、後から登録した人の権利を侵害する可能性があります。

出願の前から使っていて広く知られていれば、使い続ける権利があります（先使用権、商標法 第32条）。
地域などで広く知られた表示なら、紛らわしい使い方を不正競争防止法で止められます（第2条第1項第1号）。

米国では、登録しなくても、使っているだけで権利（common law rights）が生まれます（[USPTO](https://www.uspto.gov/trademarks/i-received-letter)）。
先に使われている未登録の商標と紛らわしい出願は、登録を拒絶されます（[15 U.S.C. §1052(d)](https://www.law.cornell.edu/uscode/text/15/1052)）。

## ロゴの類似を作例で比べる。商標と著作権で見る所を分けて

見本Aをリファレンスにして、例B〜Eを作りました。
比べる見方は、商標と著作権で次のようにそろえます。

・商標：見た目（外観）、イメージ（観念）、読み（称呼）、商品やサービスの4つ<br>
・著作権：参考にしたか（依拠）と、共通しているのが形や描き込み（表現）か、テイストやよくある形か（類似性）の2つ

### 商標の見方で比べる

商標は、並べて見分けられるかではなく、記憶に残る印象で比べます（TMEP §1207.01(b)）。
誰の記憶かというと、その商品やサービスを選ぶ人（需要者）です（[特許庁 商標審査基準](https://www.jpo.go.jp/system/laws/rule/guideline/trademark/kijun/document/index/20_4-1-11.pdf)）。

つづりが違っても、読みが同じなら紛らわしいとされます。
USPTOは、架空の「T. Markey」と「Tee Marquee」で例を示しています（[USPTO](https://www.uspto.gov/trademarks/search/likelihood-confusion)）。

| 商標の見方 | 例B | 例C | 例D | 例E |
|---|---|---|---|---|
| 見た目（外観） | シルエット・モチーフ・タッチ・アクセント・カラー・レイアウトが共通。目・羽角・羽のライン・胸のドットが違う | シルエット・モチーフ・レイアウトが共通。タッチ（直線）・アクセント（満月）・カラー（ネイビー）が違う | シルエット・タッチ（カーブ）・アクセント（三日月）・カラーの系統・レイアウトが共通。モチーフ（キツネ）が違う | シルエット・タッチの系統・レイアウトが共通。モチーフ（灯台）・アクセント・カラー（インディゴ）が違う |
| イメージ（観念） | 同じ（月とフクロウ） | 同じ（月とフクロウ） | 違う（月とキツネ） | 違う（灯台と波） |
| 読み（称呼） | 近い（LUNOWL／LUNOUL） | 違う（YUVANTE） | 違う（KUROMIST） | 違う（SUMIRO） |
| 商品・サービス | 同じ（カフェ） | 同じ（カフェ） | 同じ（カフェ） | 同じ（カフェ） |

表から言えることは、次のとおりです。

・例Bは、4つの見方すべてに、見本Aとの共通点がある<br>
・例Cはイメージが同じで、例Dは見た目の多くが同じ。共通している見方が違う<br>
・資料は、見た目とイメージの両方を比べるとし、どちらを重く見るかは書いていない<br>
・例Eは、見た目の一部と、商品やサービスが共通

TMEPによると、文字と図形を組み合わせたロゴでは、文字に重みを置くことが多いです（§1207.01(c)(ii)）。
商品・サービスが違えば判断は変わりえますが、違う商品・サービスでも関連するとされることがあります。

### 著作権の見方で比べる

4つとも見本Aをリファレンスにしたので、参考にした（依拠）側に入ります。
共通しているものは、例ごとに違います。

・例B：フクロウの形と、羽のカーブの描き込みまで<br>
・例C：フクロウというモチーフと、円と白いリングのシルエット（描き込みは違う）<br>
・例D：円と白いリングのシルエット、カーブのタッチ、月のアクセント（モチーフは違う）<br>
・例E：円と白いリングのシルエットと、カーブのタッチの系統（モチーフは違う）

文化庁は、表現上の本質的な特徴を感じ取れるかで、類似性を判断するとしています（PDF p.34）。
作風や画風といったアイデアが似るだけなら、侵害にはならないとも書いています（PDF p.24）。

ただ、==アイデアと表現の区別は「ケースバイケース」==で、資料は具体的な線を示していません（PDF p.25）。

## リファレンスなしで作ったロゴが、たまたま似ていたら

互いを知らない2人の詩人が同じ詩を書いても、どちらもオリジナルです。
米国の最高裁が、Feist判決で示した例です。
ただし、AIで作った場合は、学習データとの関係という条件が加わります。

【本】<br>
two poets, each ignorant of the other<br>
（[米国最高裁 Feist判決](https://www.law.cornell.edu/supremecourt/text/499/340)・1991年）

人が互いを知らずに作って似ただけなら、著作権の侵害にはなりません。
日本の文化庁も、知らない作品で学習データにも無ければ「偶然の一致に過ぎない」としています（PDF p.36）。

**参考にしたかは、どうやって判断される？**<br>
見る機会があったことと、似ている程度から推認されます（[文化庁 概要版](https://www.bunka.go.jp/seisaku/bunkashingikai/chosakuken/pdf/94057901_01.pdf) p.12）。
米国では、見ることができた合理的な機会があったかを見ます（[第9巡回区 17.18](https://www3.ce9.uscourts.gov/jury-instructions/node/340)）。

見る機会について、米国の陪審説示と判決には、次の考え方があります。

・==作品がウェブサイトに載っているだけでは、広く流通したことにならない==（17.18のコメント）<br>
・SNSの投稿も、相手がアルゴリズムで見た合理的な可能性まで示す必要がある（2025年の判決）<br>
・偶然では説明できないほど似ていると、見る機会があったと推定されうる（17.18）<br>
・その場合も、ゼロから作ったことを示せば、推定を覆せる（17.17）

この判決（Woodland v. Hill）では、Instagramの投稿へのアクセスは推測にとどまるとされました。
ゼロから作ったと示すには何が要るかを、具体的に挙げた公式資料や判決は見つかりませんでした。

**学習データに入っていた作品に似たら？**<br>
自分が知らなくても、通常は依拠が推認されます（文化庁 PDF p.35）。

【メモ】<br>
学習した作品の表現が出力されない状態が、技術的に担保されていれば、依拠が無いとされる場合もあります（文化庁 注45）。

米国著作権局のPart 3は学習が主題で、利用者が作ったものが似た場合の責任は、正面から扱っていません。

**商標は、たまたまでも問われる？**<br>
商標は、参考にしたかを問いません。
たまたまでも、商品・サービスが同じ・似ているもので紛らわしければ、出願や使用の場面で問われえます。

![架空のカフェのロゴ2つの作例。円の中にコーヒー豆と湯気を配した「HOLVENTA」と「ORVASKA」が並び、ネーミングは違うが構成が似ている](https://aicontent-note.com/wp-content/uploads/2026/09/img_0068_05.png "ネーミングは違っても、円・コーヒー豆・湯気のようなよくあるモチーフの組み合わせは、別々に作っても似ることがある（説明のための架空の作例）")

例Fの2店とも相手のロゴを知らず、AIの学習データにも無い想定なら、著作権は偶然の一致の側です。
学習データに入っていれば、上の推認が関わります。
商標では、同じカフェなので、商標の見方でそのまま比べられます。

米国の審査では、3本の横棒と2本の横棒のマークが、紛らわしいとされた例もあります。
船とキャンピングカーのマークです（TMEP §1207.01(c)）。

## ロゴの類似チェックのやり方と、調べきれない範囲

USPTOは、ぶつかる商標をすべて見つける確実な方法は無いと書いています。
それでも、公開前に確かめられることはあります。
著作権と商標に分けて、調べきれない範囲と一緒に並べます。

【本】<br>
There’s no surefire way<br>
（[USPTO](https://www.uspto.gov/trademarks/search/federal-trademark-searching)）

### 著作権の側で確かめること

・① 何をリファレンスにしたか、AIに何を入れたかを書き出す<br>
・② リファレンスと自分のロゴを並べ、共通しているのが表現か、テイストやよくある形かを見る<br>
・③ [Google Lens](https://support.google.com/websearch/answer/1325808?hl=ja)で画像検索し、似た作品がネットに出ていないかを見る

①は、参考にしたか（依拠）のうち、自分の手元の記録で確かめられる部分です。
実在のロゴを画像としてAIに入れること（Image to Image）は、依拠が認められる例に挙がっています。
作品名などの固有名詞をプロンプトに入れることも同じです（文化庁 PDF p.34〜35）。

【アラート】<br>
画像検索で何も出なくても、オリジナルとは言えません。<br>
ネットに無い作品や、検索で拾えない作品があります。

AIの学習データにどの作品が入っていたかも、利用者からは分かりません。
それでも、前の見出しのとおり、見る機会や高い類似から依拠は推認されえます。

### 商標の側で確かめること

・① 商品やサービスの類似群コードを調べる<br>
・② 読みで探す：「称呼(類似検索)」にネーミングの読みを入れ、①のコードで絞る<br>
・③ 見た目で探す：J-PlatPatの図形等分類表や、WIPOのGlobal Brand Database<br>
・④ 有名ブランドを探す：J-PlatPatには、周知や著名と認められた商標を探す検索もある<br>
・⑤ 登録していないロゴを探す：同じか似た商品やサービスでの使用を、ネットで探す<br>
・⑥ 見つかったロゴを、商標の4つの見方で並べる

①は、J-PlatPatの「商品・役務名検索」で調べられます（例：印刷物は26A01）。
②の称呼の検索では、音や響きが似た読みも出てきます（[INPIT J-PlatPat操作マニュアル](https://www.inpit.go.jp/content/100888006.pdf)）。

③の[Global Brand Database](https://www.wipo.int/en/web/global-brand-database)は無料で、ロゴ画像を上げて形・カラー・コンセプトで探せます。
日本の商標も入っています。
USPTOの検索は、今のところ画像での検索に対応していません（[USPTO](https://www.uspto.gov/trademarks/search/design-search-codes)）。

文字だけの商標には図形の分類が付かないので、図形の検索は②と合わせて使います。
⑤は、使っているだけで権利が生まれる国があるためです。
USPTOも、州の登録とネットの調査を勧めています（[USPTO](https://www.uspto.gov/trademarks/basics/why-search-similar-trademarks)）。

【アラート】<br>
検索結果は、紛らわしいかの法的な見解でも、登録の保証でもありません。<br>
（[WIPOの利用規約](https://www.wipo.int/en/web/global-brand-database/terms_and_conditions)、[INPITのFAQ](https://faq.inpit.go.jp/FAQ/2024/03/000288.html)）

### 公開前に、似た登録ロゴが見つかったとき

ここから3つの見出しは、公的機関が挙げている選択肢と相談先だけを書きます。

見つかったロゴと自分のロゴは、上の⑥のとおり商標の見方で並べます。
調べ方や結果の見方は、[知財総合支援窓口](https://chizai-portal.inpit.go.jp/about/)に相談できます。
全国47都道府県にあり、相談は無料です。

出願まで考えているなら、次の見出しのコンセント制度も関わります。

### 出願して、似た登録商標を理由に登録を受けられないとき

日本には、2024年4月に始まった「コンセント制度」があります（商標法 第4条第4項）。
先の権利者の承諾があり、混同のおそれが無ければ、似た商標でも登録を受けられます。
ただし、同じ商標で商品・サービスも同じなら使えません（[特許庁 Q&A](https://www.jpo.go.jp/system/trademark/gaiyo/consent/consent_qa.html)）。

米国では、拒絶されたら3か月以内に応答できます。
違いの主張、商品の絞り込み、同意書（consent agreement）などです（[USPTO](https://www.uspto.gov/trademarks/maintain/responding-office-actions)）。
同意書は、なぜ混同しないかまで書いたもののほうが、重く見られます（TMEP §1207.01(d)(viii)）。

### ロゴを使っていて、警告が来たとき

警告は、権利者の主観的な判断によることが多く、誤用や濫用もあります。
INPITは、正当性を調べてから対応するよう案内しています（[INPIT](https://faq.inpit.go.jp/FAQ/2024/01/000210.html)）。

USPTOも、警告を受けただけでは訴えられたことにならないと書いています（[USPTO](https://www.uspto.gov/trademarks/i-received-letter)）。
中には、相手を怖がらせる目的の警告もあります。
それでも、何もしないことにもリスクがある、としています。

侵害にあたるかについて、特許庁は電話やメールでは答えていません。
判断を求めるなら、特許庁の判定制度があります（商標法 第28条）。

手数料は4万円です（[料金一覧](https://www.jpo.go.jp/system/process/tesuryo/hyou.html)）。
審理は、2024年の平均で8か月ほどでした（特許行政年次報告書2025年版）。
相談は、上の知財総合支援窓口で無料でできます。

## ロゴを公開・納品する前に見る、AIツール・フォント・コンペの規約

似ているかとは別に、使ったツールやフォントの規約で決まることがあります。
そのロゴを使ってよいか、商標登録できるかです。
コンペに出すなら、サービスごとのルールも加わります。

### AIツールの利用規約

・[OpenAI](https://openai.com/policies/terms-of-use/)と[Canva](https://www.canva.com/policies/ai-product-terms/)は、ほかのユーザーも似た出力を得ることがあると書いている<br>
・Canvaのテンプレートで作ったロゴは、商標登録できない。無料の単純な線や図形と、全フォントでゼロから作れば登録できる（[Canvaのヘルプ](https://www.canva.com/help/trademarks-logo/)）<br>
・[Adobe Firefly](https://www.adobe.com/legal/licenses-terms/adobe-gen-ai-user-guidelines.html)は、商標を出させる指示や、他人の作品を参照画像に上げることを、禁止の例に挙げる

**クライアントのロゴが他社とかぶったら、独占できない？**<br>
規約で生成物の権利を受け取っても、他人の似た生成物には及びません（OpenAI）。

商標登録すると、登録した商品・サービスについて、そのロゴの使用を専有できます（商標法 第25条）。
似たロゴの使用も、似た商品・サービスの範囲で止められます（第37条）。
ただし、範囲はマークと商品・サービスの組み合わせで、似たロゴ全般を独占できるわけではありません。

### フォントのライセンス

**有料フォントなら、ロゴに使っていい？**<br>
答えは、フォントごとのライセンスに書かれています。

| ライセンスのパターン | 当てはまるフォントの例 |
|---|---|
| ロゴに使えて、ロゴの商標登録もできる | [Adobe Fonts](https://helpx.adobe.com/jp/fonts/web/font-licensing/font-licensing.html)（フォントのデザインそのものは登録できない）／[LETS](https://lets.fontworks.co.jp/services/license)（フォントワークスなど。モトヤLETSは申請前に有償の契約）／[イワタ](https://www.iwatafont.co.jp/support/faq/page/2/) |
| ロゴに使えるが、ロゴの商標登録はできない | [モリサワ（タイプバンク製品）](https://www.morisawa.co.jp/support/faq/4074)／学生向けLETS |
| プランで変わる | [Morisawa Fonts](https://support.morisawafonts.com/hc/ja/articles/10821591481497)（スタンダードプランなどは登録できる。フリープラン・Webフォントプランはできない） |
| 商標登録するロゴや、営利のロゴは別契約 | [ダイナコムウェア](https://www.dynacw.co.jp/support/support_faq_detail.aspx?qid=6)（商標登録するロゴ）／[視覚デザイン研究所](https://www.vdl.co.jp/license/)（営利目的のロゴと、その商標登録） |
| ロゴ用に別のライセンスがある | [Pangram Pangram](https://pangrampangram.com/pages/eula)（Logo License） |
| ロゴに使えるが、商標登録の記載は無い | [Google Fonts](https://fonts.google.com/faq)／[OFL](https://openfontlicense.org/ofl-faq/)のフォント |

==有料か無料かでは決まらず==、同じ販売元でも製品やプランで違います。

**アウトライン化して形を変えるのは？**<br>
Adobe Fonts、[Klim](https://klim.co.nz/faqs/)、[Grilli Type](https://www.grillitype.com/eula)は、アウトライン化した文字の改変を認めています。
どれも、フォントのファイルそのものの改変は認めていません。
Adobe Fontsは、改変した文字の画像を商標登録することも認めています。

**クライアントに納品するときは？**<br>
Adobe Fontsは、画像で渡すなら、クライアントのライセンスは要りません。
[Envato Elements](https://help.elements.envato.com/hc/en-us/articles/360000628966-Envato-Elements-License)は、フォントをクライアントに使わせられません。
[Monotype Fonts](https://www.monotypefonts.com/pages/eula)のCreate + Deployは、クライアントのロゴを作れません。

### ロゴコンペのルール

[99designs](https://support.99designs.com/hc/en-us/articles/204109569-Originality-Policy)は、リファレンスにするのはよいが、仕上がりはオリジナルでなければならないとしています。
よくあるモチーフでも、似すぎると複製の扱いです。

ロゴでのAIは、[99designs](https://support.99designs.com/hc/en-us/articles/29341768376212-Generative-AI-in-Design-Contests)が禁止、[Fiverr](https://help.fiverr.com/hc/en-us/articles/34998793899665-Using-AI-on-Fiverr-Guidelines-for-freelancers-and-clients)は許可です。
[クラウドワークス](https://crowdworks.jp/static/lp/ai_policy/)は、発注者と受注者の取り決めに任せています。
これはサービスごとのルールで、法律の基準とは別のものです。
