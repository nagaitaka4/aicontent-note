**description（案）**：
払う金額だけなら、AIで内製するほうが運用代行よりずっと安く済みます。私のツール代は月130ドル（約2万円）です。ただ、慣れても1本を公開するまでに、ならして3時間ほどかかります。何にいくら払っているか、代行の相場、浮くお金とかける時間の比べ方をまとめました。

**サブKW**：`ブログ 代行`（10件＝相場／費用）・`内製 外注`（10件。ただしシステム開発やデザインの話も混ざる語なので、主にはしない）・`claude code ブログ`（5件）
（`ブログ 内製`・`企業ブログ 費用`は0件。「内製」だけでは題を立てない）

**書き方（🔒 恒久ルール・`rules/article-flow.md` 5章）**
・前提：見やすく、誰が見てもわかりやすく、読んで為になること。AIが書いたような堅い表現は使わない
・言いたいことは下の1文だけ。リードの1文目と見出しで言い切る
・読者は最初の表だけ見れば、金額の答えが分かる形にする。各H2は表1つか、短い箇条書き・数行で終える
・短くするために理由を削らない。「何に時間がかかるのか」は、やっている作業の名前で具体的に書く
・読者の役に立たない個人的な数字は入れない（公開本数の推移・制作の経緯は書かない）。契約の金額と1本あたりの時間は、読者が自分に当てはめる材料なので入れる
・但し書きを積まない。プランの選び方はno.27へ、相場の内訳はno.40へリンクで逃がす
・決め方は1つだけ（お金が浮くぶん、その時間を毎月取れるか）。式や新しい言葉を作らない。読者の時給や「1時間あたりいくら」は書かない
・言葉をそろえる：「実費」「払う金額」「ツール代」＝お金として出ていく分。人の時間は「かける時間」と書き、お金と混ぜて「費用」と呼ばない
・円は「1ドル158円で換算」と1回だけ断り、ドルの後にカッコで添える（約2万円・約3,500円のように丸める）
・「3時間ほど」は測った数字ではなく本人の感覚。「ならすと3時間ほど」「記事によって差が大きい」をセットで書く。待ち時間の内訳は聞けていないので、「公開するまでにかかる時間」と書き、「手を動かした時間」とは書かない
・「テーマ決め」に統一する（「ネタ決め」と混ぜない）
・個人で始める読者もいるので、「社内」「担当者」だけで書かない（表は「自分たちの時間」「自分たちでやる作業」）
・初稿のMDで先に入れる：ブロックの中身を太字／章の要の一文を太字／「私は、」の後に読点

**この記事で言いたいこと（1文）**：AIで内製すると払う金額は運用代行よりずっと安いが、慣れても1本を公開するまでに、ならして3時間ほどかかるので、お金が浮くぶん、その時間を毎月取れるかで決める。
