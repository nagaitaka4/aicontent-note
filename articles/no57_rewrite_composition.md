### ② 「135件を分類した＝原因」→ **原因ではない**

noindex・404・canonical・検出 - インデックス未登録は、Search Console上では**それぞれ別の未登録理由**。
「クロール済み - インデックス未登録」に該当したのは**135件のうち4件だけ**。

さらにその4件も「旧URL・feed・記事2本」というURLの種類であって、
**Googleがなぜ登録しなかったのかという原因までは特定できていない。**

→ **タイトルから「原因」を外す。**一般論の原因を書かない方針を維持するなら、
「意味・確認方法・見分け方・対処」に寄せるほうが本文と一致する。

### ③ 「公式は登録リクエストは要らないと書いている」→ **範囲が広すぎた**

**同じヘルプに、逆方向の案内も載っている。**

|---|---|
| [ページ インデックス登録レポート](https://support.google.com/webmasters/answer/7440203?hl=ja)（ステータスの説明） | `この URL のクロールのリクエストを再送信する必要はありません。` |
| **同じページ**（一般のヒント） | `すばやいインデックス登録: 新しいコンテンツを追加すると、Google でインデックス登録されるまでに数日かかることがあります。インデックス登録の遅延を減らすには、インデックス登録をリクエストしてください。` |
| [URL の再クロールを Google にリクエストする](https://developers.google.com/search/docs/crawling-indexing/ask-google-to-recrawl?hl=ja) | `サイトにページを追加した場合、またはサイトのページに変更を加えた場合は、ここに記載されている方法を使用して、インデックスへの再登録を Google にリクエストできます。` |
| 同上 | `なお、個々の URL の送信には上限があり、同じ URL に対して再クロールを何度もリクエストしても、早くクロールされることはありません。` |
| 同上 | `クロールをリクエストしても、コンテンツが検索結果にすぐに表示されるとは限らず、まったく表示されないこともあります。` |

**「登録リクエストは不要」と一般化しない。**


公式文言は柱ではなく、**この切り分け方を支える根拠**として使う。
