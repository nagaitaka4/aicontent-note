### ② 「135件を分類した＝原因」→ **原因ではない**

noindex・404・canonical・検出 - インデックス未登録は、Search Console上では**それぞれ別の未登録理由**。
「クロール済み - インデックス未登録」に該当したのは**135件のうち4件だけ**。

さらにその4件も「旧URL・feed・記事2本」というURLの種類であって、
**Googleがなぜ登録しなかったのかという原因までは特定できていない。**

→ **タイトルから「原因」を外す。**一般論の原因を書かない方針を維持するなら、
「意味・確認方法・見分け方・対処」に寄せるほうが本文と一致する。

公式文言は柱ではなく、**この切り分け方を支える根拠**として使う。

| 最下段 | 未登録135件を2記事まで絞り込んだ記録 | 要差し替え（⚠️ **135件がこのステータスだと誤解されない文言に**。例：`対応が要るURLだけを絞る手順`） |

デザイン（青のグラデーション・アイソメトリック）は維持し、文言だけ差し替える。

## 書かないと決めたこと

| 書かない | 理由 |
|---|---|
| 世間で言われる原因（低品質・重複・生成AI・需要なし） | **自分で確かめていない** |
| 「135件を分類した＝原因が分かった」 | **このステータスに該当したのは4件だけ**。135件は未登録全体 |
| 「Googleがなぜ登録しなかったか」 | 4件についてもURLの種類までしか分かっていない |
| 「登録リクエストは不要」 | 同じヘルプに逆方向の案内もある。**再送信を繰り返す意味はない**までに限定 |
| 「大半は対応しなくて問題ない」 | 自サイトの135件では成立するが、このステータス全般では確かめていない |
| 「3週間後に9件に減った」 | **事実と違う。**9件は8/11も9/2も同じ |
| 「編集とリクエストのどちらが効いたか」 | **「効いた」が因果を前提にしている。**因果は判断できない |
| 「リストから消えた＝インデックス登録された」 | 同義ではない。**URL検査で確かめた分だけ「登録された」と書く** |
| 「URL検査で現在の状態が分かる」 | 見えるのは**Googleが最後に取得した状態**。いまの公開ページとは限らない |
| 「リライトすれば登録される」 | 編集もリクエストもしたので因果を分けられない |
| 解決までの一般的な日数 | 実測が1件しかない。**「1件だけなので判断できない」と書く** |
| 内部リンク本数を判断基準にする | 4記事を並べただけで傾向を確認できていない |
