# アイキャッチ画像 生成ルール

## 基本仕様

- サイズ：1200×630px（横長・OGP比率）
- フォーマット：PNG
- 用途：ブログ記事アイキャッチ（WordPress掲載）
- ブログ名：AIコンテンツ運用ノート

---

## デザインスタイル

### 全体方針

- フラットイラスト＋タイトルテキストを軸にしたデザイン
- 背景は単色またはシンプルなパターン（グリッド・ドット）
- **余白を十分に取る**：要素と要素の間・端からの余白を意識的に広く取る
- 情報量を絞る：タイトル＋イラスト1点が基本。サブテキストは本当に必要な場合のみ
- デザイン会社が制作したようなレイアウトの整合性・スタイリッシュな雰囲気を意識する
- **盛り込みすぎ禁止**：イラスト・テキスト・装飾を同時に多用しない。引き算の発想で設計する

### イラストスタイル

- 日本的なフラットイラスト（線画＋べた塗り）
- 人物：PCや端末を操作するビジネスパーソン / AIロボット・AIキャラクター
- 線の太さは統一感を持たせる（細すぎず・太すぎず）
- 写真・リアル系CG・3Dレンダリングは使わない
- イラストは1点に絞る（複数の人物を並べる場合は最大2点）

---

## カラーパレット

記事カテゴリーに応じて以下から選択する。各テーマで使用するのは2〜3色に絞る。

| テーマ | メインカラー | アクセントカラー | 背景 |
|---|---|---|---|
| Claude Code・AIツール系 | ネイビー（#1A2B4A）| ティール（#00B4D8）| ホワイト or ライトグレー |
| 運用・継続・仕組み系 | ミッドブルー（#2563EB）| ライトブルー（#BFDBFE）| ホワイト |
| 副業・検証・体験系 | コーラル（#FF6B6B）| イエロー（#FFD166）| ホワイト |
| SEO・マーケ系 | グリーン（#059669）| ライトグリーン（#D1FAE5）| ホワイト |
| コスト・判断系 | ダークネイビー（#0F172A）| オレンジ（#F97316）| ホワイト |

## レイアウトパターン

記事内容に応じて以下3パターンから選択する。

### パターンA：左タイトル＋右イラスト

```
[ 大きなタイトル文字 ]  [ イラスト ]
[ サブテキスト・バッジ ]
```

- タイトルを左寄せで大きく配置
- イラストを右1/3〜右半分に配置
- 最も汎用性が高い

### パターンB：中央タイトル＋左右にイラスト

```
[ イラスト ] [ 大きなタイトル ] [ イラスト ]
```

- タイトルを中央に置き、左右対称にイラスト配置
- ２人の人物を対比させる記事・比較系記事に向く

### パターンC：背景色＋中央タイトル＋上部または下部にイラスト

```
[ イラスト（上部または右コーナー） ]
[ 大きなタイトル（中央） ]
[ サブテキスト（下部） ]
```

- 背景を鮮やかな単色で塗りつぶす
- タイトルは白抜き文字
- エネルギッシュ・キャッチーな印象

---

## テキスト配置ルール

### 必須テキスト

- **メインタイトル**：記事タイトルから最も重要な単語・フレーズのみ抽出（全文そのままは使わない）
  - 目安：全角8〜16文字以内
  - **サイズ：画面の1/5〜1/4程度。画面いっぱいに広げない**
  - 余白とのバランスを優先する

### フォントの使い分け

記事の雰囲気・テーマに応じてフォントスタイルを選択する。**スタイリッシュ＝明朝ではない。**

| 記事の性質 | フォントの方向性 | 例 |
|---|---|---|
| 解説・実務・技術系 | ゴシック系（モダン・クリーン） | Noto Sans / 太めサンセリフ |
| 体験・検証・副業系 | ゴシック系（カジュアル・親しみやすい） | 丸ゴシック系 |
| 思考・考察・ブランド系 | 明朝系（落ち着いた知性的な印象） | Noto Serif / セリフ系 |
| エンタメ・遊び心のある記事 | コミカル・手書き風フォント | ポップ体・手書き風 |
| ミニマル・スタイリッシュ系 | 細めゴシックまたは英字フォント混在 | 細めサンセリフ＋英字サブ |

- フォントは1記事につき**最大2種類まで**（メイン＋サブ）
- 同じ記事内でゴシック・明朝・コミカルを混在させない

### 任意テキスト（いずれか1点まで）

- **サブテキスト**：5〜12文字の補足
  - バッジ・ラベル形式（角丸矩形の中に入れる）で配置
  - メインタイトルより明確に小さいサイズで配置すること
- **英語サブテキスト**：メインテキストの英訳・英語キーワード（デザインアクセントとして・細め）
- **数字バッジ**：「3選」「5ステップ」などの数字を円形バッジで強調

### 禁止テキスト

- 記事タイトルをそのまま全文入れる
- テキスト要素を3種類以上使う
- 本文の説明文・長い文章を入れる
- **文字を全体的に大きくする（余白がなくなるほどの文字サイズは禁止）**
- サイトURL・著者名（ブランド表記は除く）

---

## ブランド要素

- 右下または左上に「AIコンテンツ運用ノート」のテキストロゴを小さく配置
- フォント：細めゴシック
- 色：メインカラーまたはグレー（背景と干渉しない色）

---

## 装飾・アクセント要素（任意・最大2点まで）

- 角丸のカテゴリーバッジ（例：「Claude Code活用」「AI運用」）
- 対角線リボン（コーナーに「完全解説」「事例あり」など）
- 幾何学的なアクセント（細い矢印・ドット・サークル）
- テキスト下のアンダーライン（太めの単色ライン）

---

## 禁止事項

- 写真・フォトリアルな人物・リアルな風景の使用
- グラデーション背景（単色のみ可）
- 4色以上の使用
- ごちゃごちゃした背景パターン（複雑なテクスチャなど）
- **文字サイズが全体的に大きすぎるレイアウト（余白が潰れるほどの文字サイズ禁止）**
- **要素の盛り込みすぎ（イラスト・テキスト・バッジ・装飾を同時多用しない）**
- タイトルを全文そのまま画像に入れる
- フォントを3種類以上混在させる
- 「スタイリッシュ」という理由だけで明朝体を選択する（テーマに合うかで判断する）

---

## 画像生成プロンプトの構造（GPT使用時）

記事内容を受け取ったら、以下の手順で画像生成プロンプトを構築する。

1. **記事テーマを判定** → カラーパレット表から最適なテーマカラーを選ぶ
2. **レイアウトパターンを選択** → 記事の性質（解説系・比較系・体験系）に応じて選ぶ
3. **タイトルテキストを抽出** → 記事タイトルから10〜20文字に絞る
4. **イラストの被写体を決定** → 記事テーマに合ったフラットイラスト人物・キャラクターを指定
5. **プロンプトを英語で生成** → DALL-E向けに以下の要素を含むプロンプトを作成

### プロンプト必須要素

```
- Canvas: 1200x630px horizontal banner
- Style: flat Japanese illustration, stylish, clean, with generous whitespace
- Layout: [選択したパターン]
- Main color: [選択した色]
- Illustration: [被写体の説明] in flat vector style, simple line art with color fills
- Text: "[抽出したタイトルテキスト]" in [記事テーマに合ったフォントスタイル], medium size (not overly large, balanced with whitespace)
- Font style: [ゴシック系 / 明朝系 / 丸ゴシック / コミカル / 細めサンセリフ から選択]
- Background: solid [選択した背景色], clean
- Generous negative space — do not fill the entire canvas
- No gradients, no photorealism, no more than 3 colors
- Minimal elements: illustration + title text only, no decorative clutter
- Professional blog thumbnail quality, stylish design agency aesthetic
```
