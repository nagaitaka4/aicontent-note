# メディア戦略（2026-09-14時点）

戦略GPT用の要約。正はリポジトリの `CLAUDE.md`（軸・目的）・`operations/editorial-strategy.md`（実測・毎週月曜に更新）・`operations/theme-map.md`（テーマ）。

## 1. メディアの軸

- **「AIで環境を構築し、AIコンテンツで実際に動かしている」実況メディア。**「AIで稼ぐ方法」を教えるメディアではない
- 環境構築 → 実際に動かす、の過程をそのまま見せる。競合の多くは個人の稼ぎ方の発信で、このメディアは現場の実況で差をつける
- X・ブログ・note、すべてこの軸でそろえる
- 最重要思想：完璧より継続。止めずに回すことを最優先にする

## 2. 目的と導線

- 目的：コンテンツ運用を止めずに回す／検索流入を得る／運用代行の受注
- 導線：記事 → 信頼 → 問い合わせ → 運用代行
- ターゲット：個人・中小企業／コンテンツ運用に課題がある人／外注か内製か迷っている人／AIでラクして結果を出したい人

## 3. SEOの役割（2026-08-11に実測で確定）

- **SEOは受注を取る装置ではなく、流入と信頼を積む装置。**受注は営業チャネルで取る
- 根拠：受注系5本＋サービスページの合計が約124表示（過去3か月）。全部1位でも問い合わせは年に数件
- テーマの優先順位は「受注に近いか」ではなく、「流入が伸びるか × 一次データを持っているか」で決める

## 4. 現在地（公開64本・GSC直近3か月・2026-09-14）

- クリックがあった記事は25本、合計128クリック
- 上位2本（no.14 職種：32クリック／no.56 ChatGPT Work×Claude Code：26クリック）で約45%
- 読者の中心は、**Claude／Claude Codeを仕事で使えるか決めたい非エンジニア**。WordPress・SEOの手順を探す人と、代行の相場を調べる人は、既存記事のリライトで受けるにとどめる

### 当たっているもの

1. **製品名 × 仕事**：タイトルに製品名がある記事は、1日あたり表示の中央値が5倍（8/11・54本）。ただし、特定の製品について「いま知りたいこと」がある人を拾えた記事だけ
2. **自分で動かした一次情報**：CTRが高いのは、メルカリ出品12%・弁護士18%・社労士22%・no.56 11%。どれも実際にやった結果が本文
3. 「とは」で戦わない：no.9「Claude Codeとは」は3か月表示0
4. 具体的なほど拾う：一般語で上位を狙うより、具体的な状況を書くほうが表示が増える
5. 内部リンクの本数は成績を説明しない（8/11・逆相関）

### もう増やさないもの

| 種類 | 実測 | 扱い |
|---|---|---|
| 一般的なSEOの手順 | 837表示で7クリック（順位15〜70位） | 既存のリライトだけ |
| 概念解説「◯◯とは」 | README・ディレクトリ以外はクリック0〜3 | 増やさない |
| 副業検証（8本） | 表示0 | #08で終了済み |
| 受注・代行の一般論 | 6本で185表示・2クリック | 受注はSEOで取らない |
| 製品ニュースの報告型 | 記事では上位に出ない | X用にする |
| 士業シリーズ | 3本で61表示 | 3本で止める |

## 5. 記事の型

1. タイトルに製品名と仕事を入れる。「とは」「方法」だけの一般語にしない
2. 数字が主役（件数・期間・回数・クリック）
3. 実物を見せる（ファイル・画面・ログ）
4. 比べる相手を自分で作る（前後・AとB・人とAI）
5. 読者の判断で終わる。売り込みで終わらない

## 6. テーマの種類の比率（`operations/theme-map.md`・2026-09-14）

実況40%／Claude運用25%／AI動向15%／仕事20%

- 実況型でも、タイトルは「製品名＋読者の判断」で立てる（副業検証8本が表示0だった原因は、タイトルに製品名と判断が無かったこと）
- 「自分の制作の話」は、読者の判断が無ければ内輪になる

## 7. 書き方の前提

- 現実ベース・実体験重視。誇張しない・煽らない。ワクワク感は残す
- 検証ベース・再現性重視・実務に落とす
- 禁止：煽り表現・根拠のない断定・再現性のないノウハウ・AIっぽい文章
- 実体験のないことを「やった」として書かない
- AIと人は対等な目線で書く。「AIはこういうもの」と断定しない
