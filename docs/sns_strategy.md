## 投稿パターン（3種類）

### ① 気づき型（メイン）
記事の核心を1投稿に凝縮する。リンクなしでも成立させる。

```
例：
「AIライティングで副業を始めて気づいたこと。
条件を絞りすぎると1件も応募できない。
完璧な案件を探すより、低単価でも1件完走する方が先だった。」
```

### ② 実況型
副業検証の進捗をそのまま投稿する。「記事にします」で記事への誘導。

```
例：
「クラウドワークス、3件応募して1件が面談まで進んだ。
人見知りだけど、やってみる。記事にします。」
```

### ③ リンク型
気づき＋リンクのセット。「詳しくはこちら」単体は使わない。

```
例：
「AIでブログ記事を書くとき、一番時間がかかるのは構成作りではなく、
事実確認と言い換えだと気づいた。
実際の作業フローをまとめたのでよければ → [URL]」
```

## 投稿頻度

| 種別 | 頻度 |
|---|---|
| 気づき型 | 週2〜3本 |
| 実況型 | 随時（副業検証に動きがあるとき） |
| リンク型 | 記事公開時 |

**目安：週3〜4本**

---

## ネタ切れ防止の設計

- 副業検証シリーズの進捗が自動的にXのコンテンツになる
- 記事を書くたびに「気づき」が1〜3個必ず出る
- リサーチ中の発見・失敗・修正もそのままネタになる

---

## やってはいけないこと

- 「記事を書きました！」だけの告知投稿
- 「詳しくはこちら」単体リンク
- 煽り・誇張表現（メディアのトンマナ違反）
- 返信・エンゲージメントを無視した一方的な発信
