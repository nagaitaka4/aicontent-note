## 2026-08-06 分析：何が伸びて何が伸びないか（全56件の実測から）

### 伸びた投稿（30以上・13件）に共通する3条件

| # | 条件 | 該当例 |
|---|---|---|
| **1** | **「今」が理由になっている**（旬・変化・締切） | Opus5デフォルト化94／課金変更93／Fable5公開41・39／Gemini CLI有料化73／Claude障害64 |
| **2** | **自分の身に起きたことを具体物で語る** | メルカリ出品81（写真フォルダ→一言で6処理）／副業やめます94（8応募2テスト0契約435円）／344円納品39 |
| **3** | **強い感情の言葉が入口にある** | 「やめます」94／「全く気が付きませんでした」64／「更新するのが面倒で」42 |

**2つ以上を満たすと80超に届く。**Opus5-気（旬＋正直な感想）、メルカリ-リ（具体物＋実況）が典型。

### 伸びない投稿（10未満・25件＝全体の45%）に共通する3パターン

| # | パターン | 該当例 |
|---|---|---|
| **1** | **一般論・所感で終わる**（自分が主語でない） | 「AIに『あとはいい感じに』は通じません」4／「企業でコンテンツ運用が止まる理由は、だいたい同じです」5／「AIは便利」系 |
| **2** | **ニュースを紹介しただけ**（実務への落とし込みがない） | Claude Code Desktop刷新3／Opus 4.8発表9／ゼロクリック検索83%が5 |
| **3** | **数字はあるが「だから何が変わったか」がない** | 「20本以上書いて見えてきました」6／「41本書いて気づいたこと」6／「44本、8時間→4〜5時間」8 |

**3が最も重要な発見。**数字を出しても、その数字によって「読者の何が変わるか」がないと伸びない。「44本・8時間→4〜5時間」は数字として強いのに8ビュー。一方「8応募2テスト0契約435円」は94。**違いは、後者に「だからやめた」という決断が付いていること。**

### 軸別の実測（従来の推定を更新）

| 軸 | レンジ | 実態 |
|---|---|---|
| ① AI実験ログ | 2〜94 | **振れ幅が最大。**具体物と決断があれば最強、所感で終わると最弱 |
| ② AI動向 | 3〜94 | **旬×実務落としで最高値、ニュース紹介だけで最低値。**軸の問題ではなく処理の問題 |
| ③ Rシリーズ連動 | 7〜20 | 安定して中位。爆発はしないが下限も割らない |
| ④ 過去記事リンク型 | 8〜81 | **メルカリ-リ81は例外的成功。**具体物があるリンク型は伸びる |

**「AI動向は伸びる／実験ログは伸びない」ではない。**どちらの軸でも、上の3条件を満たすかどうかで決まる。

### この分析から決めた運用方針（2026-08-06〜）

**軸比率は変えない**（①50%／②30%／③15%／④5%）。AI動向に寄せると「Claudeに興味がある人」しか集まらず、アカウントのポジション（非エンジニアがClaude Codeでメディアを回している人）が薄まるため。

**代わりに「3条件チェック」を全下書きに適用する。**下書き作成時とキュー投入時に、以下を必ず自己判定する。

```
□ 今これを出す理由があるか（旬・変化・締切・自分に起きた出来事）
□ 具体物があるか（数字・固有名詞・実際の作業・画面・金額）
□ 決断か感情が入っているか（やめた・変えた・驚いた・イライラした）
```

- **0個 → 出さない**（★★☆☆☆以下。10未満になる）
- **1個 → ★★★★☆**（ヒット。週3本の枠を埋める）
- **2個以上 → ★★★★★**（ホームラン候補）

**数字だけの投稿を禁止する。**「◯本書いた」「◯時間→◯時間」は、必ず「だから何を変えたか／やめたか」とセットにする。単独では伸びないことが実測で確定した（8ビュー・6ビュー）。
