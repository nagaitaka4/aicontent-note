# note素材フォルダ

## 目的

cc-writerシリーズを書きながら、将来のnote販売に向けた素材を蓄積する。
「今販売しない。設計だけ今やる」という方針のもと、記録を積み上げるフォルダ。

## 販売予定コンテンツ（仮）

- cc-writer運用の全体フロー
- 記事作成テンプレ（構成・プロンプト）
- 作業時間のリアル
- うまくいったパターン / 失敗
- 運用ルール（止まらない設計）

## ファイル構成

| ファイル | 内容 |
|---|---|
| flow.md | cc-writer運用の全体フロー |
| template.md | 記事作成テンプレ（構成・プロンプト） |
| prompts.md | 実際に使っているプロンプト集 |
| failures.md | 失敗事例・うまくいかなかったパターン |
| improvement-log.md | 改善ログ・気づきの記録 |

## 運用ルール

- cc-writerシリーズを書くたびに気づきをここに記録する
- 販売はシリーズ完走後（S-17まで書き終えてから）
- 今は「売る前提の記録」として蓄積するだけでOK
