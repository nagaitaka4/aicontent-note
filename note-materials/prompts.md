# 実際に使っているプロンプト集

最終更新: 2026-04-27（S-14・S-15から抽出）

---

## 構成作成プロンプト

```
以下の情報をもとに、SEOブログ記事の構成（H1・H2・H3の骨格）を作成してください。

キーワード：〇〇
読者像：〇〇
記事の方向性：〇〇（この記事で伝えたいこと）

条件：
- H1は1つ・H2は4〜6個・H3は各H2に2〜3個
- 読者の理解の流れに沿った順序にする
- 重複は削除する
```

---

## 本文執筆プロンプト（H2単位）

```
以下の条件で、H2「〇〇」の本文を書いてください。

構成：（H2・H3の骨格）
トンマナ：現実ベース・実体験重視・誇張しない・具体例を入れる
記事方針：〇〇

※出力は下書き（素材）として使います。実体験は私が後から加えます。
```

→ 「下書きとして使う」と伝えることで、完璧な完成品を求めなくなる。

---

## リライトプロンプト

```
以下のテキストを、下記の条件でリライトしてください。

条件：
- 〇〇に変える（例：能動態に統一する・冗長表現を削る）
- トンマナを維持する
- 意味は変えない

【元テキスト】
〇〇
```

---

## トンマナ確認プロンプト

```
以下の文章のトンマナをチェックしてください。
問題があれば指摘のみ。修正は私がします。

チェック項目：
- 誇張表現がないか
- 抽象論のみになっていないか
- 一人称が統一されているか（主語→「私」、修飾→「自分」）
- AIっぽい文章になっていないか

【テキスト】
〇〇
```
