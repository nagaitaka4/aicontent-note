# 記事制作テンプレ・指示の型

最終更新: 2026-04-27（S-14・S-15から抽出）

---

## 構成作成の指示テンプレ

Claude Codeに渡す情報は3点。この3つが揃っていないと構成がぼやける。

```
【キーワード】〇〇
【読者像】〇〇（例：ブログ運用に課題がある個人・中小企業担当者）
【記事の方向性】この記事で伝えたいこと：〇〇
```

→ これを渡した後に「H1・H2・H3の骨格を作ってください」と指示する。

---

## 本文執筆の指示テンプレ（3点セット）

H2の本文を出力させるときに毎回渡すセット。

```
【構成】（確定済みのH1/H2/H3）
【トンマナ】（文体・語調・方針。例：現実ベース・誇張しない・実体験重視）
【記事方針】（この記事の目的・読者に届けたいこと）

上記をもとに、H2「〇〇」の本文を書いてください。
```

→ H2を1つずつ分割して指示する。1回で全部出させない。

---

## リライトの指示テンプレ

既存テキストを最適化するときの渡し方。

```
以下のテキストを【目的】に合わせてリライトしてください。
【目的】〇〇（例：読みやすくする・検索意図に合わせる・トンマナを統一する）
【元テキスト】〇〇
```

→「自然な文体で」「読みやすく」などの抽象的な指示は使わない。必ず具体的な方向性を渡す。

---

## CLAUDE.md（ルールファイル）に入れておくべき情報

毎回伝え直さなくていいように、ファイルに固定しておく情報。

- メディアのトンマナ（文体・語調・表現の方針）
- 禁止事項（誇張・抽象論のみ・AIっぽい文章など）
- 読者設定（ターゲット像）
- 内部リンク先の記事一覧
- チェックリスト（公開前に確認する項目）
