# note販売 戦略フォルダ

このフォルダはnote.comでの商品販売に関する戦略・計画・素材を管理する。

---

## フォルダ構成

| ファイル | 内容 |
|---|---|
| `strategy.md` | ターゲット・ポジショニング・価格帯・発売タイミング |
| `lineup.md` | 商品ラインナップ詳細・各記事の構成案 |
| `launch-checklist.md` | 発売前に揃えるもの・発売手順 |

## 素材の保管場所

執筆中に蓄積した素材は `note-materials/` フォルダにある。
- `flow.md` - 工程設計の気づき
- `template.md` - テンプレート素材
- `prompts.md` - プロンプト集
- `failures.md` - 失敗・やらなくていいこと
- `improvement-log.md` - 改善の記録

## 発売タイミング

**S-17完成後**（cc-writerシリーズ完走のタイミング）が最初の発売目安。
シリーズが完走することで「全工程を実践した人」という信頼性が生まれる。
