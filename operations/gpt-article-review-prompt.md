# 記事レビューをGPTに頼むときの前置き（2026-09-24新設）

記事や構成案をGPTに貼る前に、下の文を先頭に付ける。
**事実の精度だけを見て「公開してよい」と言わせないため**（no.27で2回、題の問いに答えていない記事を「公開してよい」と判定した）。

```
この記事をレビューしてください。順番を守って、1→2→3の順に見てください。

1. タイトルの約束を本文で果たしているか（最優先）
・タイトルの語句（問い・「〜した理由」など）を1つずつ取り出し、本文のどの見出しで答えているかを表にしてください
・答えが無い、または答えが弱い語句があれば、それを最初に指摘してください
・「〜した理由」のような筆者の体験は、読者が自分に当てはめて判断できる材料になっているかまで見てください

2. 検索してきた読者が、知りたい順に読めるか
・メインKWで検索する人（例：まだ無料で使っている人／有料プランで迷っている人）を2〜3種類想定し、それぞれが答えにたどり着けるかを見てください
・書き手の都合の並べ方（事実→体験→まとめ）になっていて、読者の問いの順になっていない箇所を指摘してください

3. 事実の正確さ
・公式の一次情報と照合し、誤りや古い情報を指摘してください

1か2に問題があるなら、3が正しくても「公開してよい」と判定しないでください。
直すべき量が大きいなら、部分修正ではなく構成から組み直す案を出してください。
```
