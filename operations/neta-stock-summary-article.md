## 【環境・導入】

- Claude Code の環境構築は非エンジニアでも可能。YouTube で導入動画を見てイメージしておくとスムーズ
- デスクトップアプリで md ファイルを画面右にプレビュー表示すると作業効率が上がる。ただしプレビューは閲覧のみで編集不可
- VS Code を使っているが、commit / push がバッティングして失敗することがよく発生する
- GitHubにプッシュするとき、バッティングしてプッシュできなかったり、commitができない場合が度々発生する。こまめにcommitとpushしたほうがいいのか、運用の仕方が悪いのかわからないが、結構頻繁に起きていて、毎回地味に面倒な作業が入る

## 【AIの精度・期待値】

- 導入当初ほど時間短縮できない。精度は50〜60点が現実。事実確認・方針決定・優先順位付けは人がやる必要がある
- WEBライティングの完全自動化は現状難しい
- AIの構成は60点以上を安定して出せるが、執筆フェーズはかなり不安定。確認・調整に最低1時間、3時間以上かかることもある
- 今ではAIなしでは回せないが、動きや出力の確認・軌道修正は人の仕事

## 【ルール管理・安定性】

- 安定した出力にはルールファイルの整理が不可欠
- 一度不安定になるとミスが続く。根気よくルールファイルの調整が必要
- ずっと同じフォーマットだったのに急に変えてくることがある（要注意サイン）
- 安定していたのに急に不安定になることがある

## 【タスク・ドキュメント管理】

- タスク・ドキュメント管理は圧倒的に省力化できる。ただし優先順位・方向性・方針の判断は人がやる必要があり、タスクが増えるとこれが結構大変

## 【AIの誤りへの対応】

- AIは間違う。GPTは開き直って謝らない。Claudeは謝る。結果が同じでもストレスの積み重なり方が違う

## 【AIの使い分け】

- GPTは方針設定・企画・計画が得意な陽キャ。Claudeは作業・整理・管理が得意な陰キャ。Perplexityは情報収集向け
- 基本はClaudeで動かし、構成・執筆内容の確認はGPTを使う。メディアの方針・計画はGPTの方が合っている印象
- 使うAIによって向き不向きがある。今の使い方に不満がなければそれでいい。もっとこうしたいなら他のAIも検討する価値がある

## 【音声入力】

- 音声入力は便利。ただし言語化できる力と滑舌が前提。うまくいかないと修正時間の方がかかる

## 【業務・職種との相性】

- Claude Code環境はWEBライティングより士業系の職種との相性が高そう。導入できるかどうかで差が広がる可能性がある

## 【WP入稿Tips】

- WP入稿前のmdファイルにフロントマター（no / title / date / url / slug / status / series / series_no / description / eyecatch / eyecatch_alt / category / tags）を書いておくと入稿がスムーズ

## 【X運用・SNS】

- X運用フローの半自動化がうまくいかない。CCだけでも、GPTだけでも、ルールファイルを整理してもゼロ戻しが起き、なかなか安定しない。投稿内容も安定せず、過去の文脈を忘れ、ルールも忘れ、修正や管理に時間がかかる。AIに任せたいが投稿できる内容にするまでがかなり大変。完全自動化もできると思うが、このメディアとの相性が悪いし、それだとやる意味がない。試行錯誤中。

## 【総括の核心】

- XやSNS広告など、煽るような宣伝文句が多い。自分もそこに目が行くし、そういう内容や投稿ほど人の目が集まる。焦りのバイアスがかかりやすい構造がある。でも結局は、メディア運用もX運用もコツコツ、泥臭く積み重ねていくしかないと思いはじめている。
