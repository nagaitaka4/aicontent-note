# レビュー依頼（GPT向け）：ai-like-text-checker.md

・目的：Webツール「AIっぽさチェック（AIっぽい文章チェッカー）」の、固定ページの説明文。文章のどこがAIっぽく読まれやすいかを、直し方の例つきで示す無料ツール。ツール本体は本文中の「【ツールをここに表示】」の位置に、ブラウザで動く入力欄として入る。ページの末尾のCTAはサイト共通の固定文
・読者：「aiっぽい文章 直す」「aiっぽい文章 特徴」「aiっぽい文章 判定」などで検索してきた人。ChatGPTなどで書いた文章（X投稿・メール・ブログ記事）が、AIっぽく読まれないか気にしている
・この稿の核心：AIっぽさは単語より文の形で出る。ツールは機械で拾える9つの形を、どこが・なぜ・どう直すかで示す。AIが書いたかどうかの判定ではない（上位の検索結果は「AI率○%」の判定ツールが多いので、そこと違うことが伝わる必要がある）。入力した文章は外部に送らず、保存もしない
・重点的に見てほしいこと：
  1. 「AIが書いたかどうかの判定ではない」が、判定を求めて来た人にも誤解なく、がっかりさせすぎずに伝わるか
  2. 「AIっぽく読まれやすい書き方と直し方」の表が、ツールを使わない人にも読んで為になるか。例と直し方が具体的か
  3. 堅い表現・人が声に出して言わない言い回しが残っていないか（あれば箇所を全部）。このページ自体がAIっぽいと、ツールの説得力がなくなる
  4. 「このサイトで実際に直してきた形」「公開している記事70本で試した」という根拠の書き方が、押しつけがましくなく、信頼につながるか
・見なくてよいこと：ツールの画面の文言（別ファイル）、CTAの文言、タイトル・説明文の字数（機械チェック済み）
・前回までのレビュー（旧ページ「投稿まえチェック（X投稿チェッカー）」）とは別物です。ツールの主役を「X投稿の文字数」から「文章のAIっぽさ」に作り替え、題・スラッグ・本文を書き直しました（2026-10-06）
