# レビュー依頼（GPT向け）：ai-like-writing-features-fix.md

・目的：新規記事「AIっぽい文章の特徴と直し方。直す前と後を並べた」の本文の確認（初回。構成案はGPTに2回見てもらい確定済み）
・この記事で言いたいこと（1文）：AIっぽく読まれる所の1つは、普段なら動詞で言う所を名詞や決まり文句にした所なので、禁止ワードを足すより、話すときの言葉に言い直す
・筆者の立場：ブログ運用代行を請ける側。自分のブログは全記事をAI（主にClaude Code）と一緒に書き、人が読んで直している。読者はClaudeユーザーに限らず、AIで文章（ブログ・メール・SNS）を書いている個人・中小企業の担当者
・この記事でしか出せないもの：ChatGPTの料金の記事をAIと書いたとき、使わない言葉のリストで調べると0件だったのに、人が20か所以上直した実話と、その直す前と後の組（表の3行は記録の文のまま）。記事を書くAIに毎回読ませている指示から抜き出した3行。自作の無料ツール
・H2-2で使う調査：広島大学の卒業論文（令和7年度）。20代16人が「AIらしい」「人間らしい」と感じた点の自由記述。AIらしい側で多かったのは「具体性がない」（最多）と「普段使わない言葉」。学術誌に載った研究ではない・使ったAIにGPT-3.5を含む
・本文を書いたあとの経緯：会話を持たない別のレビュー役に1回見てもらった（直してから公開・組み直し不要）。直したのは、①リード1文目「特徴は〜」→「特徴の1つは〜」（卒業論文で最多は「具体性がない」で、1つに言い切ると食い違う）②H2-1の答え「普段使う動詞で言い直す」→「話すときの言葉に直す」（決まり文句は動詞にならない）③表の目印「〜な状態です」→「〜状態です」（実物は「狭い状態です」）④「禁止ワードのチェックは0件」→「使わない言葉のリストで調べると0件」（何を調べたか見えない）⑤「この3行を渡します」→「渡してください」（筆者の記録は、書くAIに毎回読ませている所まで）⑥「どこにも送りません」→「どこにも送られません」。削った所：リード3文目「直す前と後を並べるので、自分の文章と見比べてください」
・変えていない所：表の「直した後」の文は人が実際に直した言葉なので書き換えない。表は3行（材料の記録にある組のうち、目印と直した後が1対1で対応するもの）
・重点的に見てほしいこと：

  2. H2-2が、調査の範囲（20代16人・自由記述）を越えて言い切っていないか
  3. 「AIっぽい文章 特徴」「AIっぽい文章 直す プロンプト」「AIっぽい文章 判定」で来た読者が、それぞれ答えにたどり着けるか
