# レビュー依頼（GPT向け）：blog-operation-automation-limit.md

・目的：既存記事（9月公開・3か月で0クリック・7表示）を全面改稿した本文「ブログ自動化をAIに任せると起きること。任せる作業と人が決めること」の確認（本文の1回目）。構成案は、GPTの2回のレビュー（2回目＝本文執筆GO・必ず直す0点）を経て確定したもの
・この記事で言いたいこと（1文）：ブログの作業をAIに任せると1〜2か月でずれが出るが、原因はAIではなく決まりを書かずに確かめる判断まで預けたことなので、手を動かす作業はAI、何を書くか・見出しの並び・出してよいかは人が持ち、決めたことはファイルとチェックに移す
・筆者の立場：ブログ運用代行を請ける側。エンジニアではない。自分のブログは記事・X投稿をAI（主にClaude Code）と回していて、WordPressの下書きまでAIに作らせ、公開ボタンだけ自分で押している
・読者：AIでブログを書き始めた、またはブログの更新をAIに任せようとしている個人・中小企業の担当者。エンジニアではない
・確定した構成案から変えた所（会話を持たない別のレビュー役の指摘で、材料の記録に合わせた）：
  1. 表1「少しずつ長くなる」の時期を「半年ほどかけて」→「4か月ほどかけて」（測った期間に合わせた）
  2. 表1の4行目の2つ目の例（題の問いに半分しか答えていない記事）を削った
  3. 表2の「起きること」の列から、H2-2の答えの言い直しを削り、実例だけにした
  4. H2-4の手当ての見出しを「記事ごとにずれるなら、〜」の形にし、どの症状への手当てかを見出しで分かるようにした
・重点的に見てほしいこと：
  1. 端的で見やすく、堅い表現・AIが書いたような言い回しが無いか（声に出して言いにくい文があれば挙げてほしい）
  2. 表1の4つの症状と、H2-4の4つの手当てが、本文でも1対1で読み取れるか
  3. 削った結果、読者が「何のことか」分からなくなった所が無いか（特にH2-2の表2と、H2-4の最後の手当て）
・見なくてよいこと：字数・記法（機械チェックで見る）。CTAの文言（最新の公開記事からそのまま写す決まり）。末尾の関連記事3本（本数が決まっていて、本文のリンクと重なってよい）
