# レビュー依頼（GPT向け）：chatgpt-training-opt-out.md

・目的：新規記事「ChatGPTに学習させない設定。会社の情報を入れる前に」の構成案の確認（1回目）
・この記事で言いたいこと（1文）：設定の「モデル改善に協力する」をオフにすれば、これからの会話は学習に使われない。ただし、オフにしても会社の情報を入れてよいことにはならない
・筆者の立場：ブログ運用代行を請ける側。エンジニアではない。ChatGPT Plusに課金し、チャットとアイキャッチの画像生成に使っている。Claudeの同じテーマの記事（Claudeに会社の情報を渡して大丈夫か）を9月に書き、そのときClaudeの学習設定はオフにした。ChatGPTの設定は今回の下調べで見たらオンのままだったので、オフにする（記事にもそう書く）
・読者：会社の仕事でChatGPT（無料版・Plus）を使っている／使い始めた人。取引先名・社内の資料・個人情報を入れる前に「学習されないか」を調べに来た
・事実の出どころ（構成案の事実はここから・2026-11-10に原文を確認）：
  1. OpenAIヘルプ「How your data is used to improve model performance」「Data controls in ChatGPT」「Chat and file retention in ChatGPT」（英語版が主・本文のリンクは日本語版）。個人向け（Free・Plus・Pro）は「データ共有がデフォルトで有効」、オプトアウト後は「新しい会話」が改善に使われない、👍👎を押すとオプトアウトしていても会話全体が学習に使われることがある、一時チャットは学習に使われず最大30日保持、Business・Enterprise・Edu・APIは既定で学習に使わない
  2. 今の日本語の画面の項目名は「モデル改善に協力する」（ヘルプの日本語版は「すべての人のためにモデルを改善する」で名前が違う）
  3. パナソニック オペレーショナルエクセレンスの公式発表（2026-10-23）：禁止していた外部の生成AIサービスに約33万人分の個人情報をアップロード。アップロード時に学習に使う機能は無効だった（事業者の回答）。個人情報保護委員会に報告。サービス名は非公開
・その前に、会話を持たない別のレビュー役に2回見てもらい、次を直した（構成案の冒頭の表）：材料に無い1文（会社の契約の保存期間）を削除／パナソニックの件は「報告し、本人への通知の代わりに公表した」までにし、30日の話を削除（ChatGPTの話に読めるため）／「ほかの人の回答に使われる」を公式の言い方「モデルの改善に使われる」に／表の行（削除したチャット・音声モードとCodex）と重なる文を削除／アカウントの区別を「自分で登録した」「会社が契約した」に／入れる前に見ることを2つに（Businessにすれば入れてよいと読めるため）
・重点的に見てほしいこと：
  1. 検索から来た人が、H2①だけで設定を見つけてオフにできるか。H2②の表で「オフで足りるか・デメリットはあるか」に答えが出ているか
  2. H2④（パナソニックの件）が、学習の設定の記事から浮いていないか。「学習オフでも事故になる」を、読者が自分の行動（入れる前に見る2つ）に移せるか
  3. 自分で登録したアカウントと会社が契約したアカウントの表（H2③）に、言いすぎや抜けがないか（Goプランは公式の該当ページに名前が無いので入れていない）
・見なくてよいこと：字数・記法（機械チェック済み）
