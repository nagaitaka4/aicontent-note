・目的：新規記事「プロンプトはマークダウンで書くべき？基本で足りる理由と3つの例外」の構成案の確認（1回目・新しいチャット）
・この記事で言いたいこと（1文）：分けたい中身がある指示なら、プロンプトはマークダウンで足りる（1文の頼みごとには要らない）。ただし、AIの返事をプログラムで読み取りたいとき・ツールが指示書の形を決めているとき・守らせたいルールが増えたときは、別の形に分ける

・検索の上位：「マークダウン記法◯選で精度が上がる」の一色。使わなくてよい場面・別の形にする場面・指示書が増えたときの話は無い。3つの場面の整理はnoteの記事（緑どんぐり「プロンプトはMarkdownでいいと思っていた｜使い分けが必要になる3つの場面」）から借り、本文で紹介してリンクする（元の記事の「大量のデータはCSV」は筆者が使っていないので入れ替えた）
