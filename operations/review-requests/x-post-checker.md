# レビュー依頼（GPT向け）：x-post-checker.md

・目的：Webツール「投稿まえチェック」（X投稿の文字数・伝わりにくい言い回し・直近の投稿との重なりを確認する無料ツール）の、固定ページの説明文。ツール本体は本文中の「【ツールをここに表示】」の位置に、ブラウザで動く入力欄として入る。ページの末尾のCTAはサイト共通の固定文（最新の公開記事からのコピー）
・読者：Xに投稿する前に文字数を確かめたい人。初めて来た人が、「自分に使えるか」「安心して貼れるか」を判断する
・この稿の核心：文字数だけでなく、前の投稿を知らないと伝わりにくい言い回しと、直近の投稿との重なりも見る。入力した文章は外部に送らない。判定は採点ではなく「確認してほしい所」
・重点的に見てほしいこと：
  1. 初めて来た人が、何ができるか・使い方・安全面（送らない・保存の扱い）を、ツールの前後を数秒見ただけで分かるか
  2. 「分からないこと」（Xの現在の数え方との差）の書き方が、正直で、読者を不安にさせすぎないか。迷ったときに何を信じればいいかが書いてあるか
  3. 堅い表現・人が声に出して言わない言い回しが残っていないか（あれば箇所を全部）
  4. 「このツールについて」（筆者の経緯）が、読者の役に立つ長さか。削ってよいか
  5. 3つの表（確認できること・保存の扱い・知っておくこと）と、ツールの後の並び（使い方 → 何を確認できるか → 入力・保存の扱い → 使う前に知っておくこと）が、読者の疑問に答える順になっているか。「使う前に知っておくこと」の表が長すぎないか
・見なくてよいこと：ツールの画面の文言（別ファイル）、CTAの文言、タイトル・説明文の字数（機械チェック済み）、記事の「タイトルの約束」の対応表（これは記事ではなくツールのページ）
