# レビュー依頼（GPT向け）：x-post-checker.md

・目的：Webツール「投稿まえチェック」（X投稿の文字数と、伝わりにくい言い回しを確認する無料ツール）の、固定ページの説明文。ツール本体は本文中の「【ツールをここに表示】」の位置に、ブラウザで動く入力欄として入る。ページの末尾のCTAはサイト共通の固定文（最新の公開記事からのコピー）
・読者：Xに投稿する前に文字数を確かめたい人。初めて来た人が、「自分に使えるか」「安心して貼れるか」を判断する
・この稿の核心：文字数だけでなく、前の投稿を知らないと伝わりにくい言い回しも見る。入力した文章は外部に送らず、保存もしない。判定は採点ではなく「確認してほしい所」
・重点的に見てほしいこと：
  1. 「直近の投稿との重なり」を外したことで、説明の抜け・食い違い・不自然なつながりが残っていないか
  2. 初めて来た人が、何ができるか・使い方・安全面（送らない・保存しない）を、ツールの前後を数秒見ただけで分かるか
  3. 堅い表現・人が声に出して言わない言い回しが残っていないか（あれば箇所を全部）
  4. 「使う前に知っておくこと」の表で、ツールでは分からないこと（おもしろさ・通じるか・誤字・炎上しそうな表現・事実の誤り）が、過信させずに伝わるか
・見なくてよいこと：ツールの画面の文言（別ファイル）、CTAの文言、タイトル・説明文の字数（機械チェック済み）、記事の「タイトルの約束」の対応表（これは記事ではなくツールのページ）
・前回のレビューを反映した第3稿です。前回の指摘が直っているか、直したことで新しい問題が出ていないかを、最初に見てください。前回から変えた点：
  1. ツールから「直近の投稿との重なり」（自分の過去の投稿を保存して比べる機能）を外した。初めての人には必ず空で出る・投稿をためる手間が続かない・端末ごとで共有されない、の3点で使う人が少ないと判断した
  2. それに合わせて、ツールは何も保存しない形にした。説明文・リード・使い方（5項目→3項目）・何を確認できるかの表（3行→2行）・「入力した文章の扱い」の節（保存した投稿の行を「保存しません」に）を直した
  3. 言い回し：「出たからといって、直す必要はありません」→「出ても、必ず直す必要はありません。読み返して通じるなら、そのままで大丈夫です」／「表示された内容を見る」→「出た所を読み返す」／ファイル名の例を「README.md」だけにした／「2026年9月30日に確認しました」→「2026年9月30日時点の数え方」
  4. 「ツールでは分からないこと」に「誤字、炎上しそうな表現、事実の誤りも見ていません」を足した
