# アイキャッチのプロンプト：no.69「AIの使い方で迷う10の問い。記事66本をAIで作った記録で答える」

作成：2026-09-17 16時台。**参考画像なしでCCがプロンプトを作り、ユーザーがGPTでトンマナを合わせて仕上げる方式の初回**（ユーザー発案）。

## 決めたこと

| 項目 | 決めたこと | 理由 |
|---|---|---|
| レイアウト | 左テキスト・右イラスト | no.67が中央寄せ、no.68が左テキスト。見出しの「10」を左から大きく読ませたい |
| 主役 | 数字の「10」 | no.67の「64本」と同じく、数字のジャンプ率で目を止める。題の「10の問い」と一致 |
| 配色 | 深いネイビー＋からし色＋温かいオフホワイト | no.67（紫）・no.68（深い緑）と重ならない。落ち着いたトーン |
| モチーフ | 10枚の問いカードを並べた「記録シート」＋鉛筆 | 「10の問い」と「記録で答える」を1つの絵で見せる。人物はno.68で使ったので入れない |
| 白熊効果のフック | Q7のカードだけ、白熊の顔を細い線で描く | 記事でいちばん他に無い材料（実験）を、小さく1か所だけ見せる |
| 文字 | 4か所（ラベル・見出し・サブ・キーワード3つ） | テキストは最小限。キーワードは記事の中身が一目で分かる3語 |

## プロンプト（GPTにそのまま貼る）

```
ブログ記事のアイキャッチ画像を1枚作ってください。

■サイズ
横1200px × 縦630pxで出力してください。

■全体の雰囲気
デザイン会社が作ったような、ミニマルで洗練された日本語の解説バナーにします。
画面の4割くらいを余白にして、ゆったり見せてください。
左に文字、右にイラストを置きます。

■色
・背景：温かみのあるオフホワイト（#F6F3EC）の無地
・文字とイラストの主な色：深いネイビー（#1F2A44）
・アクセント：からし色（#E0A526）。使うのは、数字の「10」、左の小さな丸3つ、チェックの印、白熊のカードの塗り、鉛筆の5か所だけ
・カードの線や薄い罫線：明るいグレー（#D9D6CE）
落ち着いたトーンでまとめ、色数はこの4色に絞ってください。

■左側の文字（上から順に。文言は一字一句このとおり）
左余白は80px。すべての行の文字の左端を、1本の縦線にぴったりそろえてください。どの行も、同じ左端から始めます。
文字のまとまりは、左から80px〜620pxの幅に収め、右のイラストとの間に80px以上のすき間をとります。

1. 「AIの使い方で迷う」
   太めのゴシック体、高さ40pxくらい、ネイビー。

2. 「10の問い」
   このバナーの主役です。
   「10」は極太のゴシック体で、高さ150pxくらいの特大サイズ、からし色。
   「の問い」は極太のゴシック体で、高さ84pxくらい、ネイビー。「10」の下端と「の問い」の下端を同じ高さにそろえます。
   大きさの差（ジャンプ率）をはっきり効かせてください。

3. 「記事66本をAIで作った記録で答える」
   中くらいの太さのゴシック体、高さ28px、ネイビー。「10の問い」の下に、少し間をあけて1行で置きます。

4. キーワードを3つ、横一列に並べます：「プロンプト」「ルールファイル」「白熊効果」
   それぞれを、細いネイビーの線で囲んだ角丸の小さなタグにします（塗りはオフホワイト、文字は高さ20pxのネイビー）。
   3つのタグは同じ高さ・同じ角丸・同じ間隔にして、1つ目のタグの左端を、上の文字の左端と同じ縦線にそろえます。

5. あしらい：「記事66本を〜」の行と、キーワードのタグの間に、直径8pxの小さな丸を10個、横一列に等間隔で並べます。左から3つだけからし色で塗り、残り7つはグレーの線だけにします。1つ目の丸の左端も、文字の左端と同じ縦線にそろえます。

■右側のイラスト「10の問いの記録シート」
画面の右側（左から700px〜1120pxあたり）に、角丸の大きなパネルを1枚置きます。
・パネル：白い塗り、細いグレーの枠、ごく薄い影。左上に小さなタブ状の出っ張りがあり、パネル上部には細い横線が1本通っています
・パネルの中に、同じ大きさの角丸カードを横2列×縦5段、合計10枚、上下左右とも等しい間隔でぴったり並べます
・各カードの左端に、小さな太字のネイビーで番号を入れます。左の列は上から「Q1」「Q3」「Q5」「Q7」「Q9」、右の列は上から「Q2」「Q4」「Q6」「Q8」「Q10」
・番号の右には、文字の代わりに、薄いグレーの短い横線を2本（上が長く、下が短い）描きます
・「Q1」「Q4」「Q9」のカードの右端に、からし色の丸の中に白いチェックの印を描きます
・「Q7」のカードだけ、塗りをごく淡いからし色にして、横線の代わりに、白熊の顔を細いネイビーの線だけで小さく描きます（丸い耳2つ、点の目2つ、小さな鼻。シンプルな線のアイコン）
・パネルの右下の角に、からし色の鉛筆を1本、斜め45度で置きます。鉛筆の先がパネルの右下の枠線にちょうど触れる位置にします

■仕上がり
・線の太さはイラスト全体でそろえ、フラットで清潔な描き方にします
・カードの大きさ・角丸・間隔は、定規で測ったように正確にそろえます
・画像の中の文字は、上で指定した文言と「Q1」〜「Q10」だけにします
```
