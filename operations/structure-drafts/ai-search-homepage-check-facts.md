## 5. この環境の実物（2026-11-13 12〜13時台・curlで実測）

| 項目 | 何を見ているか（平易に） | aicontent-note.comの結果 |
|---|---|---|
| robots.txt | AIや検索のロボットに、読んでよい所を伝えるファイル | **あり**。`Disallow: /wp-admin/`と`Sitemap:`の行。AIのロボットを名指しで止める行は無い＝止めていない |
| サイトマップ | ページの一覧 | **あり**（`/sitemap.xml`が200） |
| AIへの使い方の宣言（Content Signals） | 検索・AIの回答・学習に使ってよいかをrobots.txtで宣言 | 無い |
| Markdownで返す | AIが頼んだときに、飾りの無い文章だけを返す仕組み | **無い**（`Accept: text/markdown`で頼んでもHTML）・`Vary: Accept`も無い |
| Linkヘッダー | サイトマップなどの場所を、ページの返事に添える | WordPressが自動で付けるもの（`wp-json`・記事のJSON・短いURL）だけ |
| 構造化データ（JSON-LD） | ページの中身を機械に分かる形で添えるもの | **あり**。トップ＝Organization・WebSite・SearchAction／記事＝Article・BreadcrumbList・Person・ImageObjectほか（SWELL・SEO SIMPLE PACKが出している。自分で書いたものは無い） |
| 存在しないページ | 無いページで「無い」と正しく返すか | **404を返す** |
| og:image | SNSやAIに出る画像 | トップ＝`ogp-default.png`／記事＝アイキャッチ |
| 本文の割合 | HTMLのうち本文が占める割合（is-agenticの目安5%） | トップ＝**約2.8%**（HTML約11.2万字のうち本文約3,100字・スクリプトとスタイルを除いて数えた）＝落ちる見込み |
| 運営者のページ（About） | 誰が運営しているか | **無い**（`/about/`・`/profile/`・`/company/`は404）。`/service/`（ブログ運用代行）と`/contact/`・`/privacy-policy/`はある |
| llms.txt | AI向けの案内ファイル | **無い**。`/llms.txt`を開くと、WordPressが似た名前の記事（no.65 llms.txtの記事）へ301で転送する＝ファイルがあるように見えるが、中身は記事のHTML |

→ 写す元と同じく、**Markdownで返す・Linkヘッダーで落ちる見込み**。事業のサイトとして気になるのは**運営者のページが無いこと**と、トップの本文の割合。llms.txtの転送は、診断ツールが「ある」と誤って数える可能性がある（測って確かめる）

## 8. 構成の方針（材料から）
