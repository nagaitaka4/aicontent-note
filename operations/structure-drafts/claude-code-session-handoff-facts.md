## 3. 公式の一次情報（[Manage sessions](https://code.claude.com/docs/en/sessions)・2026-09-11取得）

- 再開：`claude --continue`（直近）／`claude --resume`（一覧）／`claude --resume <name>`／`/resume`。セッションは`~/.claude/projects/<project>/<session-id>.jsonl`に保存、保持は30日（`cleanupPeriodDays`）
- 再開で戻るもの：会話履歴（ツール結果含む）・モデル・エージェント・許可モード（条件あり）・期限内の定期実行。**戻らないもの**：`--add-dir`で足したディレクトリ、`--mcp-config`等の起動フラグ
- **要約からの再開**（Pro・Max）：verbatim `when you resume a session that has been inactive for more than about an hour and is over 100,000 tokens, Claude Code restores the conversation and then opens a dialog` → `Resume from summary`（/compactを実行）／`Resume full session as-is`／`Don't ask me again`
- `/branch`（分岐）：会話をコピーして別セッションにする。`--fork-session`でも可
- `/compact [instructions]`：履歴を要約に置き換える。**プロジェクトのCLAUDE.mdは圧縮後に読み直される**（memoryのドキュメント）
- 名前：`claude -n <name>`／`/rename`。デスクトップアプリは独自のセッション履歴を持つ
- `/export`：会話をテキストで書き出す
