# 作例ロゴの画像生成プロンプト（no.68・GPT用）

作成：2026-09-15 10時台／更新：同日 10時台（ユーザー指摘「シンボルだけ。テキストも含める。名前も考える」→ 店名の文字を入れた）・同日 10:38（ユーザー指摘「見本Aは添付ではなく、同じスレッドの続きでB・C・Dを生成する」→ 添付の前提をやめた）／対応する構成案：`logo-plagiarism-how-far-ai-copyright-font.md` 第2稿（H2②に3枚・H2③に1枚）

## この作例の考え方

- **見本Aは架空のカフェのロゴ。**「スタバ風」から借りるのは、円形のエンブレム・円に沿って並ぶ店名・中央のキャラクター・単色の描き方という**テイストだけ**。モチーフはフクロウ、色はボルドー、店名は造語にして、実在のロゴとは別の印象にする
- **プロンプトに実在ブランドの名前や、その特徴（人魚・王冠・緑など）を書かない。**書くと実在のロゴに寄った画像が出る。Adobe Fireflyのガイドラインは商標を生成させるプロンプトを禁止の例に挙げ、OpenAIの規約も他人の権利を侵害する使い方を禁じている
- **実在のロゴを参考画像として上げない。**文化庁の資料で、既存の作品を画像として入力するImage to Imageは依拠性の例に当たる
- **例B・C・Dは、同じスレッドの続きで、1枚目に生成した見本Aをもとに作る。**見本Aは自作の架空ロゴなので、比較のためにそろえてよい。毎回「もとにするのは1枚目の見本A」と書き、直前に作った例B・Cの変更が引き継がれないようにする
- 文字は店名と「COFFEE」の英字だけ。つづりが崩れやすいので、プロンプトで1文字ずつ区切って指定する。「A」「B」などのラベルは、CCが並べるときに入れる
- 1つのスレッドで、下の順番（前提 → 1 → 2 → 3 → 4 → 5）に貼る

## 生成したあと

1. 5枚をダウンロードして`images/`に置き、「アップしました」と伝える（ファイル名はそのままでよい）
2. CCが中身を開いて、意図どおりか確かめる（**店名のつづり**／Bは少し離れて見ると同じか／Cは顔だけ同じか／Dは別のロゴに見えるか／Eはシンボルが似ているか）。ずれていたら直しのプロンプトを出す
3. CCが見本Aと例B・C・Dを横に並べて幅1200pxにし、`img_0068_01`〜`03`で保存する。例Eは`img_0068_04`。ICCプロファイルは除く

## 0. スレッドの最初に貼る前提（1回だけ）

```
これから、ブログ記事に載せる作例のロゴを5枚、続けて作ります。
記事は「デザイナーが既存のロゴにどこまで似てよいか」を説明するもので、作例で「似ている程度」の違いを見せます。

5枚とも、どの実在ブランドとも関係のない架空のカフェのロゴとして作ってください。
共通の条件：
・画風：フラットなベクター風。単色の塗りと、均一な太さの線だけで描く
・文字：各プロンプトで指定した英字の店名と「COFFEE」だけを入れる。太めのサンセリフ体の大文字で、つづりは指定のとおり1文字も変えない
・背景：白の無地
・1枚に1つのロゴを中央に置き、周りに十分な余白をとる（例Eだけ2つ並べる）
・サイズは各プロンプトで指定する

1枚目で基準の「見本A」を作り、2〜4枚目は、このスレッドの1枚目で作った見本Aをもとに、似せる程度を変えた作例を作ります。5枚目は見本Aを使わない別の作例です。
理解したら「OK」とだけ返してください。
```

## 1. 見本A（LUNOWL COFFEE・基準）

**意図**：記事のすべての比較の基準。円形のエンブレム・円に沿う店名・中央のキャラクター・単色というテイストを持ちつつ、モチーフ・色・店名は実在のロゴと別にする。例B・C・Dの「どこが同じか」を読者が見分けやすいよう、外枠・帯の文字・顔・胸の模様・翼と、要素をはっきり分けておく。

**使う場所**：H2②の画像1〜3の左側

```
見本Aを作ってください。

・円形のエンブレム型のロゴ。外枠は太い円と細い円の二重線で、2本の円の間を文字の帯にする
・帯の上側に、円に沿って店名「LUNOWL」（L-U-N-O-W-L の6文字）を置く
・帯の下側に、円に沿って「COFFEE」（C-O-F-F-E-E の6文字）を置く

・中央に、正面を向いたフクロウを左右対称に描く。大きな丸い目、頭の上に2本の羽角、胸には羽根をうろこ状に3段並べた模様、翼は体の両側に沿わせる
・色は深いボルドー（#6B1E2E）1色と、白の抜き
・線の太さはそろえ、小さく表示しても形が分かるくらいに要素を絞る
・サイズは1024×1024px、背景は白

## 2. 例B（LUNOUL COFFEE・✕：全体の印象がほぼ同じ）

**意図**：並べれば細部と店名のつづりの違いが分かるのに、少し離れて見ると見本Aと同じロゴに見える例。本人の感覚の「印象がほぼ同じはだめ」に当たる。資料では、商標は並べて見分けられるかではなく、記憶に残る全体の印象で比べ（TMEP §1207.01(b)・EUIPOの「不完全な記憶」・特許庁の「離隔的観察」）、つづりが違っても読み方が同じなら紛らわしい（USPTOの例）。

**使う場所**：H2②の画像1（見本A｜例B）

```
このスレッドの1枚目に作った見本Aをもとに、例Bを作ってください。

目的：並べると細部と店名のつづりは違うのに、少し離れて見ると見本Aと同じロゴに見える作例です。
・円形の二重線の外枠、帯の上下に円に沿って並ぶ文字、帯の左右の点、中央の正面を向いたフクロウ、左右対称の構図は、見本Aと同じにする
・帯の上側の店名は「LUNOUL」（L-U-N-O-U-L の6文字）に変える。帯の下側は「COFFEE」のまま。書体と文字の大きさは見本Aと同じ
・図形で変えるのは細部の3か所だけ：羽角の先を丸くする／胸の模様を3段から2段にする／目の瞳を少し小さくする

```

**使う場所**：H2②の画像2（見本A｜例C）

```
