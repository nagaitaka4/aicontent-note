# 作例ロゴの画像生成プロンプト（no.68・GPT用）

作成：2026-09-15 10時台／対応する構成案：`logo-plagiarism-how-far-ai-copyright-font.md` 第2稿（H2②に3枚・H2③に1枚）

## この作例の考え方

- **見本Aは架空のカフェのロゴ。**「スタバ風」から借りるのは、円形のエンブレム・中央のキャラクター・単色の描き方という**テイストだけ**。モチーフはフクロウ、色はボルドーにして、実在のロゴとは別の印象にする
- **プロンプトに実在ブランドの名前や、その特徴（人魚・王冠・緑など）を書かない。**書くと実在のロゴに寄った画像が出る。Adobe Fireflyのガイドラインは商標を生成させるプロンプトを禁止の例に挙げ、OpenAIの規約も他人の権利を侵害する使い方を禁じている
- **実在のロゴを参考画像として上げない。**文化庁の資料で、既存の作品を画像として入力するImage to Imageは依拠性の例に当たる
- **例B・C・Dは、見本Aを添付して作る。**見本Aは自作の架空ロゴなので、比較のためにそろえてよい
- **文字は入れない。**GPTは文字が崩れやすく、名前が実在のブランドと重なるのも避けたい。「A」「B」などのラベルは、CCが並べるときに入れる
- 1つのスレッドで、下の順番（前提 → 1 → 2 → 3 → 4 → 5）に貼る

## 生成したあと

1. 5枚をダウンロードして`images/`に置き、「アップしました」と伝える（ファイル名はそのままでよい）
2. CCが中身を開いて、意図どおりか確かめる（Bは少し離れて見ると同じか／Cは顔だけ同じか／Dは別のロゴに見えるか／Eは2つが似ているか）。ずれていたら直しのプロンプトを出す
3. CCが見本Aと例B・C・Dを横に並べて幅1200pxにし、`img_0068_01`〜`03`で保存する。例Eは`img_0068_04`。ICCプロファイルは除く

## 0. スレッドの最初に貼る前提（1回だけ）

```
これから、ブログ記事に載せる作例のロゴを5枚、続けて作ります。
記事は「デザイナーが既存のロゴにどこまで似てよいか」を説明するもので、作例で「似ている程度」の違いを見せます。

5枚とも、どの実在ブランドとも関係のない架空のカフェのロゴとして作ってください。
共通の条件：
・画風：フラットなベクター風。単色の塗りと、均一な太さの線だけで描く
・背景：白の無地
・ロゴは図形だけで構成し、文字は入れる場所を作らない
・1枚に1つのロゴを中央に置き、周りに十分な余白をとる（例Eだけ2つ並べる）
・サイズは各プロンプトで指定する

1枚目で基準の「見本A」を作り、2〜4枚目は見本Aを添付して、似せる程度を変えた作例を作ります。
理解したら「OK」とだけ返してください。
```

## 1. 見本A（基準になる架空のロゴ）

**意図**：記事のすべての比較の基準。円形のエンブレム・中央のキャラクター・単色というテイストを持ちつつ、モチーフと色は実在のロゴと別にする。例B・C・Dの「どこが同じか」を読者が見分けやすいよう、外枠・帯の点・顔・胸の模様・翼と、要素をはっきり分けておく。

**使う場所**：H2②の画像1〜3の左側

```
見本Aを作ってください。

・円形のエンブレム型のロゴ。外枠は太い円と細い円の二重線で、2本の円の間の帯に、小さな丸い点を等間隔に8つ並べる
・中央に、正面を向いたフクロウを左右対称に描く。大きな丸い目、頭の上に2本の羽角、胸には羽根をうろこ状に3段並べた模様、翼は体の両側に沿わせる
・色は深いボルドー（#6B1E2E）1色と、白の抜き
・線の太さはそろえ、小さく表示しても形が分かるくらいに要素を絞る
・サイズは1024×1024px、背景は白
```

## 2. 例B（✕：全体の印象がほぼ同じ）

**意図**：並べれば細部の違いが分かるのに、少し離れて見ると見本Aと同じロゴに見える例。本人の感覚の「印象がほぼ同じはだめ」に当たる。資料では、商標は並べて見分けられるかではなく、記憶に残る全体の印象で比べる（TMEP §1207.01(b)・EUIPOの「不完全な記憶」・特許庁の「離隔的観察」）。

**使う場所**：H2②の画像1（見本A｜例B）

```
添付した見本Aをもとに、例Bを作ってください。

目的：並べると細部は違うのに、少し離れて見ると見本Aと同じロゴに見える作例です。
・円形の二重線の外枠、帯の8つの点、中央の正面を向いたフクロウ、左右対称の構図は、見本Aと同じにする
・変えるのは細部の3か所だけ：羽角の先を丸くする／胸の模様を3段から2段にする／目の瞳を少し小さくする
・色は見本Aより少し明るい赤茶（#8A3B2E）1色と、白の抜き
・サイズは1024×1024px、背景は白
```

## 3. 例C（△：いちばん目立つ要素だけが同じ）

**意図**：外枠・色・構成は違うが、いちばん目に入るフクロウの顔だけが見本Aとほぼ同じ例。本人の感覚の「グレー」に当たる。資料では、見分けられる要素が1つ一致すると外観の類似が認められやすく（EUIPO §3.4.1.4）、目立つ要素に重みを置いて比べる（TMEP §1207.01(c)(ii)）。

**使う場所**：H2②の画像2（見本A｜例C）

```
添付した見本Aをもとに、例Cを作ってください。

目的：全体の形や色は違うのに、いちばん目に入るフクロウの顔だけが見本Aとほぼ同じ作例です。
・フクロウの顔（丸い目、2本の羽角、くちばしの形と位置）は、見本Aとほぼ同じにする
・それ以外は変える：外枠は、角を丸めた正方形の1本線だけにする。顔の下には、体と翼の代わりにコーヒーカップのシルエットを置く
・色は深いネイビー（#1F2F4A）1色と、白の抜き
・サイズは1024×1024px、背景は白
```

## 4. 例D（◯：テイストだけが同じ）

**意図**：円形のエンブレムという型・線の太さ・単色の描き方・余白は見本Aと同じ系統だが、モチーフ・形・色が違い、別のロゴという印象になる例。本人の感覚の「テイストやトンマナを寄せるのはあり」に当たる。資料では、作風や画風といったアイデアが似るだけなら著作権侵害にならず（文化庁 本体PDF p.24）、円のようなありふれた図形は著作権で保護されない（米国著作権局 Compendium §906.1）。

**使う場所**：H2②の画像3（見本A｜例D）

```
添付した見本Aは、雰囲気の参考としてだけ使ってください。例Dを作ります。

目的：雰囲気は見本Aと同じ系統なのに、モチーフ・形・色が違って、別のロゴという印象になる作例です。
・見本Aから引き継ぐのは、円形のエンブレムという型、線の太さ、単色で塗る描き方、余白のとり方、左右対称の落ち着いた構図だけ
・モチーフは、中央に立つ灯台と、その足元の2本の波線だけで構成する。灯台の光は、短い放射状の線3本で表す
・外枠は細い円の1本線にする
・色は深い墨色（#2E2E2E）1色と、白の抜き
・サイズは1024×1024px、背景は白
```

## 5. 例E（偶然似る：ありがちな形の組み合わせ）

**意図**：別々の店がそれぞれ独自に作っても、ありがちな形の組み合わせは似てしまうことがある、という説明の作例。H2③の「何も参考にせず作ったロゴが、偶然似ていたら」に置く。キャプションで「説明のための架空の作例」と書く（実際に別々に作ったものではないため）。

**使う場所**：H2③の画像4

```
例Eを作ります。見本Aは使いません。

目的：別々の2つの店が、それぞれ独自に作ったのに似てしまった、という説明のための作例です。
・横長の画面に、2つのロゴを左右に並べる。2つの間は大きく空ける
・左のロゴ：細い円の中に、縦長のコーヒー豆1粒と、その上に立ちのぼる3本の湯気の曲線
・右のロゴ：左と同じく円の中にコーヒー豆と湯気を描く。豆は少し丸く、湯気は2本、円の線は少し太くする
・色は、左が深い茶色（#4A3426）、右が深いグレーブルー（#3E4A5A）の各1色と、白の抜き
・サイズは1536×1024px、背景は白
```
