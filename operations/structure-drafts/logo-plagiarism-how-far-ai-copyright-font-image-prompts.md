## 3. 例C（YUVANTE COFFEE：同じモチーフのまま描き方・色・店名を変える）

**意図**：同じフクロウ・同じ円の構成で、描き方と色と店名を変えれば別のロゴと言えるか、という迷い。資料では、図形どうしは主に外観で比べ、違いがあっても紛らわしい場合がある（TMEP §1207.01(c)）。一方で、文字と図形を組み合わせた商標では文字に重みを置くことが多い（TMEP §1207.01(c)(ii)）ので、店名が違うことは判断を分ける材料になる。作風や画風といったアイデアが似るだけなら著作権侵害にならない（文化庁 本体PDF p.24）ので、「描き方を変えた同じモチーフ」がアイデアに当たるかも迷いどころになる。

**使う場所**：H2②の画像2（上：見本A／下：例C）

```
1枚目の見本Aをもとに、例Cを作り直してください。前回の例Cは、見本Aとシンボルの形がほとんど同じで、色だけが違いました。

目的：同じフクロウ、同じ円の構成のまま、フクロウの描き方を変え、色と店名も変えた作例です。
・シンボルの構成（外側の細い輪、白の輪、塗った円、中央に正面を向いたフクロウを左右対称に大きく描く）は見本Aのまま
・変えるのは次の5つで、どれも並べたときにはっきり分かる大きさで変える：
　1. 羽：流れる長い曲線ではなく、直線でできた山形（くの字）を左右に3段ずつ重ねて表す
　2. 目：大きな二重丸にする
　3. 顔の輪郭：上が平らな逆三角形にする
　4. 頭上の三日月：小さな満月（白く塗った丸）にする
　5. 色と店名：シンボルの色を深いネイビー（#1F2F4A）、店名を「YUVANTE COFFEE」（Y-U-V-A-N-T-E、半角スペース1つ、C-O-F-F-E-E）にする
```
