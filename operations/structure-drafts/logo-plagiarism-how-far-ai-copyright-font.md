## ロゴのパクリはどこまで？明確なラインは無く、著作権と商標で見る所が違う

## 商標で「問われる」と何が起きる？出願の審査・警告・有名ブランド
→ H2のリード：商標で問われる場面は、自分が出願したときと、ロゴを使っているときの2つ。どちらも「業種が近いか」と「見た目・読み・イメージが似ているか」の両方で見られる
### 出願したとき：審査で拒絶される
→ 日本：先に出願された似た登録商標があり、商品・サービスも同じか似ていれば、登録を受けられない（商標法第4条第1項第11号）。似ているかは、マークは外観・称呼・観念の総合、業種は「類似群コード」が同じなら類似と推定される（特許庁。例：書籍と新聞は類似、書籍とタオルは非類似）
→ 照らされる相手の規模を1文：日本は約230万件、米国は約350万件の登録と、出願中のもの。一次審査までは日本で約6〜7か月（特許庁・USPTO）
→ 米国：審査官が連邦データベース（登録済み・出願中）を必ず調べ、紛らわしければ拒絶する。拒絶の理由でいちばん多い（USPTO）
→ 登録された後も：日本は公報の発行から2か月以内なら誰でも登録異議を申し立てられ、利害関係人は無効審判を請求できる（第43条の2・第46条。第11号などを理由とする場合は登録から5年まで・第47条）。米国は公告から30日以内に異議（USPTO）
### 使っているとき：権利者から警告や請求が来る

| 同じ・近い業種の登録ロゴと、見た目・読み・イメージのどれかが紛らわしい | 商標。参考にしていなくても問われ、知らなくても過失は推定される（商標法 第37条・第39条） | 出願は拒絶。使っていれば警告、差止め、損害賠償 |
| 既存の作品をリファレンスにして、形や描き込みまで似せた | 著作権。登録していない作品にもある（著作権法 第17条第2項） | 差止め、損害賠償（著作権法 第112条） |
| 違う業種の、有名ではない登録ロゴと似ている | 商標は「マーク×商品・サービス」の組み合わせ（特許庁のよくある質問 1-5） | 原則、商標権の侵害にならない |
| テイストやよくある形だけが似た／何も参考にせず、たまたま似た | 著作権ではアイデア扱い（文化庁）／参考にしていなければ侵害にならない（Feist判決・文化庁） | 著作権では問われない。商標は2行目・4行目で判断 |

・行の順番は「問われる条件の少なさ」（有名ブランド＝業種も紛らわしさも問われない → 登録ロゴ＝業種と紛らわしさ → 著作権＝参考にしたか＋表現）。リスクの大きさを点数にはしない<br>
・「起こりうること」は資料に書かれた請求・結果だけ。どのくらいの割合で起きるかは、表の下の3行で規模だけ示す
