⚠️ **参考画像なしの方式は、2026-09-17のno.69で2回試して「不可」で終了している**（`knowledge/eyecatch-rules.md`「試行」の節。背景が無地で部品も無く、テンプレートのような薄い画面になった）。今回は同じ失敗を避けるため、①背景に面と点の模様を入れる ②絵の部品は「何を表すか」を一言で言えるものだけ入れる ③影と重なりで奥行きを出す、を書いた。それでも薄く出たら、参考画像を添付する方式に戻す。

## 決めたこと

| 項目 | 決めたこと | 理由 |
|---|---|---|
| レイアウト | 左に文字、右に投稿カード | ラフAで選択。ツールの正体（投稿の下書きを確認する画面）が一目で分かる |
| 配色 | クリーム地（#F4F1EA）＋ティール（#12A594）＋黄色のマーカー（#FFE27A） | 直近 no.70（ベージュ×オレンジ）・no.71（薄グレー×水色×黄）・no.72（ラベンダー×緑×オレンジ）と重ならない。**黄色の差し色はno.71と共通**なので、地を温かいクリーム、主役をティールにして別物にした |
| 部品と意味 | 古い投稿カード2枚＝直近の重なり／黄色のマーカー＝要注意表現／メーター＝文字数／右上のミントの円＝面の変化 | 意味の無いあしらいは入れない（no.69の指摘） |
| 人物 | 描かない | ツール紹介で、画面が主役。マスコットも使わない |
| 文字 | 5か所（ラベル・タイトル・サブ・カードの数字・チップ） | 最小限。カードの数字とチップは実際の画面の表記（「140 / 280」）に合わせた |

## プロンプト（GPTにそのまま貼る）

```
ブログの固定ページ（無料ツールの紹介ページ）のアイキャッチを1枚作ってください。サイズは横1200px×縦630pxです。

■全体の雰囲気
デザイン会社が作ったような、ミニマルで洗練された日本語の紹介バナーにします。
左に文字、右にツールの画面を表す投稿カードを置く、落ち着いてやさしい雰囲気です。
薄い・平らな画面にならないよう、影と重なりで奥行きを出し、背景にも面と点の模様を入れて密度を出します。人物とキャラクターは描きません。

■余白と配置
文字のかたまりとイラストで画面の横幅をほぼ半分ずつ使い、上下の中心をそろえる。上下は端から約110px、左右は約50〜60px空け、文字とイラストは画面の高さの6割前後に収める。片側に寄せない。

■背景
・地：温かいクリーム（#F4F1EA）。真っ白は使わない
・地の全面に、直径2pxの小さな点（#E4DFD3）を24px間隔の格子で、ごく控えめに敷く
・右上に、ミント（#D9EEE9）の大きな円を1つ（直径620px、中心は画面の右端から190px・上端から170px。画面の端で切れる）。円の上にカードを重ねる

■右側のイラスト「投稿の下書きを確認する画面」
画面の右側（左から690px〜1140px、上から108px〜510px）に、投稿カードを1枚と、その後ろに古い投稿カードを2枚、重ねて置きます。

・手前のメインカード：左から690px〜1140px（幅450px）、上から152px〜510px（高さ358px）。角丸28px、塗りは白に近い温かいグレー（#FBFAF6）。カードの下に、ぼかさない色の面だけの影を12pxずらして置く（#C9DDD8）。カードの内側の余白は、上下左右とも28px
・メインカードの中身（上から順。縦の位置はカードの上端からの距離）：
　1. 上から28px：左上に、ティール（#12A594）の円（直径44px）を1つ。投稿者のアイコンを表す
　2. 上から88px：グレー（#E3E6E3）の角丸の横線（太さ14px）を4本、間隔12pxで並べる。長さはカードの内側の幅に対して、上から92%・78%・86%・40%。3本目だけ、左端から44%の長さを黄色のマーカー（#FFE27A）で塗る（蛍光ペンで引いたように、線の上に重ねる）
　3. 上から202px：文字「140 / 280」。「140」は高さ36pxくらい、濃いグレー（#1F2A30）、太め。「/ 280」は高さ26pxくらい、灰色（#7B8A90）。カードの内側の右端にそろえる
　4. 上から246px：細長いメーター（高さ22px、カードの内側の幅いっぱい）。土台はグレー（#E3E6E3）、左から52%をティール（#12A594）で塗る。両端は丸い
　5. 上から282px：黄色の角丸のチップ（高さ36px、塗りは #FFF1B8、文字は茶色 #7A5B00・高さ22pxくらい）。中の文字は「要注意表現 1件」。チップの左端はカードの内側の左端にそろえる
・後ろの古い投稿カード2枚：メインカードの後ろに、上へずらして積み重ねる。1枚目は上へ22px、左右をメインカードより18pxずつ狭く。2枚目は上へ44px、左右を36pxずつ狭く。塗りは淡いミント（#EAF4F1）、細い枠（#BFD9D3・太さ2px）、角丸28px。上に出ている細い帯の部分に、グレー（#E3E6E3）の短い横線（太さ8px、カード幅の40%）を1本ずつ入れる。文字は入れない（直近の投稿との重なりを表す）

■左側の文字（上から順に。文言は一字一句このとおり）
左余白は60px。すべての行の文字の左端と、ラベルの左端を、1本の縦線にぴったりそろえる。どの行も、同じ左端から始める。
文字のまとまりの幅は、左から60px〜600pxに収め、右のカードとの間に90px以上のすき間をとる。文字のまとまりの上下の中心は、右のカード（古い投稿カードを含む）のまとまり全体の上下の中心とそろえる。

1. ラベル（いちばん上）：「無料・ブラウザだけで動く」
　角丸のピル型（塗りなし、ティール #0F7F70 の枠、太さ3px）。文字は同じティール、高さ26pxくらい、中くらいの太さ。ピルの左端を文字の左端の縦線にそろえる。

2. タイトル（2段・主役）：1段目「投稿まえ」、2段目「チェック」
　どちらも極太のゴシック体、高さ104pxくらい、濃いグレー（#1F2A30）。字間はやや広め。ラベルの約4倍の大きさにして、大きさの差（ジャンプ率）をはっきり効かせる。
　2段目の「チェック」の文字の下半分に、黄色（#FFE27A）のマーカーを、文字の左端から右端までの幅で重ねる（蛍光ペンで引いたような、角のあるまっすぐな帯）。

3. サブタイトル（タイトルの下、1行）：「Xに投稿する前の、文字数と言い回し」
　中くらいの太さのゴシック体、高さ34pxくらい、灰色がかった濃い色（#4A5A63）。

■配色（色はこれだけ）
クリーム（#F4F1EA）、ミント（#D9EEE9・#EAF4F1・#C9DDD8・#BFD9D3）、ティール（#12A594・#0F7F70）、黄色（#FFE27A・#FFF1B8・#7A5B00）、濃いグレー（#1F2A30・#4A5A63・#7B8A90）、薄いグレー（#E3E6E3・#E4DFD3）、カードの白に近い色（#FBFAF6）。

■仕上がり
・線は使わず、色の面だけで描くフラットなスタイル（古い投稿カードの細い枠だけ例外）。角丸と影の大きさは、全体でそろえる
・カードの大きさ・間隔・文字の位置は、定規で測ったように正確にそろえる
・文字がカードや円に欠けたり重なって読みにくくなったりしないようにする
・画像内の日本語テキストは、上に指定した文言（「無料・ブラウザだけで動く」「投稿まえ」「チェック」「Xに投稿する前の、文字数と言い回し」「要注意表現 1件」）と、数字の「140 / 280」だけにしてください。
```

## ラフAの画像を添付して仕上げる場合（プロンプトの最後に足す・任意）

CCのラフ（`operations/structure-drafts/x-post-checker-eyecatch-layout-a.png`）を添付すると、GPTが配置を取りやすくなる。ラフは粗いので、**品質は取り込ませない**。

```
■添付した画像について
添付画像は、配置を示す粗いラフです。取り入れるのは、左に文字、右に投稿カードを置く組み方と、カードの中身（アイコン・横線・マーカー・文字数・メーター・チップ）の並びだけです。
線の質感、影、重なり、背景の模様、全体の仕上がりの品質は、このプロンプトの指定に合わせて、ラフよりずっと描き込んだ水準で新しく描いてください。
```

## 生成後に確認する所

・文言が一字一句合っているか（「無料・ブラウザだけで動く」「投稿まえ」「チェック」「Xに投稿する前の、文字数と言い回し」「要注意表現 1件」「140 / 280」）／英数字・記号の誤りが無いか<br>
・左のラベル・タイトル・サブの左端が1本の縦線にそろっているか<br>
・古い投稿カードが2枚、メインカードの後ろに積まれて見えるか（上に細い帯が2段見える）／3本目の横線にだけ黄色のマーカーがあるか／メーターが約半分か<br>
・背景が無地になっていないか（点の格子とミントの円があるか）／**真っ白（#FFFFFF）が地に使われていないか**<br>
・人物・マスコットが入っていないか／色が上の配色に収まっているか<br>
・全体が薄く平らに見えないか（影と重なりが出ているか）。薄いときは、**参考画像を添付する方式に戻す**判断をユーザーに仰ぐ
