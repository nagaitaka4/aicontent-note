# WPブロック活用ガイド（SWELL）

記事制作時にどのブロックをどう使うかの運用基準。
MDファイル上では`>`（Markdown引用記法）を使わず、`【ブロック名】`を1行目に単独で書く形式で記載する（2026-07-22〜）。WP入稿時に差し替える。

行を分けたい箇所は`<br>`を使う（空行ではなく`<br>`。2026-07-22再訂正）。

```
【ポイント】<br>
内容
```

複数項目を列挙する場合も、各項目の末尾に`<br>`を付けて改行する（最後の項目には不要）。

**この`<br>`ルールは【ブロック名】の中に限らない（2026-07-23〜）**：本文中の`・`箇条書き（ブロックに入っていない、地の文の中の箇条書き）でも、複数項目を並べる場合は空行ではなく`<br>`で改行する。空行区切りは段落として扱われWP上で余白が大きく空くうえ、コピペ後の編集が大変になるため使わない。

```
【インフォ】<br>
見出し<br>
・項目1<br>
・項目2
```

**理由**：
- `>`（Markdown引用）を使うと、WPにコピペした際に各行が個別の引用ブロックとして認識され、ユーザー側で1行ずつ`>`マークを消す作業が発生する
- 単純な改行（空行なし）はMarkdown上で無視され、行が連結されて1行の文章になってしまう
- 空行を入れると別々の段落として扱われ、WP上で段落間の余白が大きく空いてしまう
- `<br>`を使うと、1つの段落のまま・余白を作らずに・行だけを分けられる。この3点を同時に満たすのは`<br>`のみ

## ブロック一覧と使いどころ

### 強調・注意系

| ブロック | 色 | 使いどころ | MD記法 |
|---|---|---|---|
| ポイント | オレンジ | 読者に持ち帰ってほしい気づき・要点 | `【ポイント】` |
| チェック | 緑 | うまくいったこと・確認済みの事実・OKな手順 | `【チェック】` |
| バツ印 | 赤 | エラー・失敗・NG例・やってはいけないこと | `【バツ印】` |
| アラート | 黄 | 注意・落とし穴・見落としやすいこと | `【アラート】` |
| はてな | 青 | 疑問・不確かなこと・調査中の事項 | `【はてな】` |
| メモ | グレー | 補足情報・ちょっとした余談 | `【メモ】` |

### 比較・評価系

| ブロック | 使いどころ | MD記法 |
|---|---|---|
| グッド | メリット・良かった点・おすすめ理由 | `【グッド】` |
| バッド | デメリット・悪かった点・注意点 | `【バッド】` |

### 情報・解説系

| ブロック | 使いどころ | MD記法 |
|---|---|---|
| インフォ | 背景情報・補足説明・定義 | `【インフォ】` |
| アナウンス | 更新情報・お知らせ・変更点 | `【アナウンス】` |
| ペン | ライティング・制作に関するTips | `【ペン】` |
| 本 | 参考情報・用語説明・引用元 | `【本】` |

### 会話・引用系

| ブロック | 使いどころ | MD記法 |
|---|---|---|
| 吹き出し | 実際の画面テキスト・会話・セリフ調の引用 | `【吹き出し】` |
| 引用 | 外部からの引用・他記事・公式情報 | Markdownの `>` をそのまま使う |

## スタイル一覧と使いどころ

ブロックに追加で装飾を加えるオプション。多用しない。

| スタイル | 使いどころ |
|---|---|
| 付箋 | カジュアルなメモ・ちょっとした補足 |
| 左に縦線 | 重要な一文・印象に残したい言葉 |
| 窪み | 定義・説明ボックス |
| かぎ括弧 | キーワード・短いフレーズを目立たせる |
| 浮き出し | セクションの区切り・まとめボックス |
| ストライプ | 使用頻度低・デザイン的なアクセント用途 |

## SWELLブロック（構造・レイアウト系）

記事の構造を整えるために使う。多用しすぎない。

| ブロック | 使いどころ | MD記法 |
|---|---|---|
| ステップ | 手順を番号付きで見せる（設定・ハウツー系） | `<!-- ステップブロック -->` でメモ |
| FAQ | よくある質問と回答をセットで見せる | `<!-- FAQブロック -->` でメモ |
| アコーディオン | 補足情報・読まなくていい人向けの詳細を折りたたむ | `<!-- アコーディオン -->` でメモ |
| リッチカラム | 2カラム比較（ツール比較・Before/Afterなど） | `<!-- リッチカラム -->` でメモ |
| 説明リスト(DL) | 用語とその説明をセットで並べる | `<!-- 説明リスト -->` でメモ |
| ふきだし | 会話形式・クライアントとのやり取り再現 | `<!-- ふきだし -->` でメモ |
| タブ | 複数のパターンを切り替えて見せる | `<!-- タブブロック -->` でメモ |
| キャプションボックス | 画像に説明を添えるとき | WP入稿時に対応 |
| SWELLボタン | CTA・リンクを目立たせる（SEO記事・仕事記事のみ） | `<!-- SWELLボタン: テキスト / URL -->` でメモ |
| 関連記事 | 記事末尾の関連記事表示 | MDのコメントアウトから設定 |
| リンクリスト | 複数の外部リンクをまとめて見せる | `<!-- リンクリスト -->` でメモ |

## 埋め込み（このメディアで使う可能性があるもの）

| ブロック | 使いどころ |
|---|---|
| Twitter埋め込み | X（旧Twitter）の投稿を記事内に表示する。実況感・リアリティの補強に使える |
| YouTube埋め込み | 動画コンテンツを作った場合。現時点では出番少なめ |

その他の埋め込み（Spotify・TikTok等）は現時点では使用予定なし。

## パターン（SWELLプリセット）

WP編集画面の「パターン」タブから呼び出せる雛形。

| パターン | 内容 |
|---|---|
| [SWELL] テーブル | 比較表・まとめ表などのテーブルレイアウト |
| [SWELL] ページ用 | 固定ページ向けのレイアウト |
| [SWELL] 汎用パターン | ランディング・セクション区切りなど汎用的なレイアウト |

記事制作では「[SWELL] テーブル」が比較系記事で使いやすい。

---

## 使用頻度の目安

- **多用するブロック**：ポイント・チェック・バツ印
- **ときどき使うブロック**：アラート・グッド・バッド・メモ
- **特定の場面だけ使うブロック**：吹き出し・インフォ・アナウンス・はてな
- **スタイル・ボーダー**：1記事に多くても2〜3か所。使いすぎると見た目がうるさくなる

| 仕事記事 | チェック・ポイント・インフォ |
