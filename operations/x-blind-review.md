# X投稿の盲検レビュー（x-blind-review）

**目的：朝ブリーフが出す投稿を、ユーザーが1文字も直さずに出せる品質にする。**
CCは下書きの元ネタを全部知っているので、**読者に通じない言葉・面白くない構成を自分では見抜けない**（2026-09-24ユーザー指摘「昨日の『無料でリセット』も、意味が通りますか？」）。
そこで、**元ネタを何も知らないサブエージェント**に、読者として読ませる。費用はかからない（Claude Codeのサブエージェント。API課金なし）。

## いつ使うか

朝ブリーフ手順5で、`x-count.py`・`x-firstline.py`・`x-hook.py` を通した**あと**、ユーザーに出す**前**。省略禁止。

## やり方（2026-09-25改訂：読者3人・合否はスクリプト・最後にゲート）

| # | やること | コマンド |
|---|---|---|
| 1 | **候補を3本書く**（①告白・失敗 ②数字・落差 ③読者の損得。型を変える）。本文をファイルに保存 | — |
| 2 | 基準の3本と混ぜてシャッフルし、**読者像の違う3人分**の依頼文を作る | `python3 operations/x-review-pack.py 候補1 候補2 候補3` |
| 3 | **Agent（general-purpose）を3つ並列**で起動し、`prompt-N.md`の中身だけを渡す。返ってきたJSONを`result-N.json`に保存。**ファイルパス・会話の文脈は渡さない** | Agentツール |
| 4 | **合否をスクリプトが出す**（CCが点数を読んで決めない） | `python3 operations/x-review-judge.py operations/x-review-runs/<日付>/<run>` |
| 5 | 不合格ならコメントで3本とも書き直して2〜4。同じ題材で3回不合格なら**題材を捨てて次の材料へ**。**合格が1本出るまで上限なしで続ける。未合格の1本を出す・基準を下げる、はしない**（2026-09-25ユーザー指摘「どうやってもちゃんとHR級以上のポスト内容を1本つくるのがこのブリーフです」） | — |
| 6 | **出す本文はゲートで[出してよい]のものだけ**。レビュー後に1文字でも直したら盲検からやり直し | `python3 operations/x-gate.py 本文ファイル` |
| 7 | **リプライも別エージェント3人のレビューを通す**（本人・フォロワー・通りすがり）。合否は`x-reply-review-judge.py`、出すのはゲートの`--reply`で[出してよい]のものだけ（`rules/x-post-flow.md`「リプライも別エージェントのレビューを通す」） | `python3 operations/x-reply-review-pack.py 親投稿.txt 案1 案2 --link 要旨.txt` → Agent3並列 → `python3 operations/x-reply-review-judge.py <run>` → `python3 operations/x-gate.py 本文ファイル --reply` |

**読者像の3人**（`x-review-pack.py`の`PERSONAS`）：①ChatGPTを少し使う会社員 ②有料プランに入るか迷っている個人事業主（ブログ・SNS）③外注か社内でAIかで迷う中小企業のWeb担当。**このメディアの読者像から取っている**。

## 合格判定（HR級・`x-review-judge.py`が出す・全部満たす）

| # | 条件 | なぜ |
|---|---|---|
| 1 | 分からない言葉・前提を挙げた読者が**1人以下** | 初見で通じないと止まっても読まれない |
| 2 | 止まる・面白い・フォローの**平均がすべて4.0以上** | HR級の水準（基準の3本は2.0〜3.0だった） |
| 3 | ニュースの紹介に見えると答えた読者が**1人以下** | 解説型は伸びない（`x-post-flow.md`） |
| 4 | 本人の決断・感情・失敗が見えると答えた読者が**2人以上** | 3条件の③。フォローの理由になる |
| 5 | 平均順位が**基準の3本のうち2本より上** | 「過去のそこそこ」ではなく上位を出す |

参考値として**プロフィールを見に行く人数**も出る（フォロワー獲得の直前の行動）。

## ゲート（`x-gate.py`・出す直前）

重み（残り5以上）／1行目が報告型でない／自分の話が最後だけでない／前を知らないと通じない言い回しがない／**この一字一句が今日か昨日の盲検で合格している**（本文のハッシュで照合）。1つでも落ちたら[出さない]。

## 旧・レビュー依頼文（2026-09-24〜25朝。いまは`x-review-pack.py`が依頼文を作る）

```
あなたはXのタイムラインを流し見している日本の会社員です。AIツール（ChatGPT・Claudeなど）は仕事で少し使っていますが、詳しくはありません。
この投稿者のことは何も知りません。前の投稿も読んでいません。

下のA〜Fは、同じアカウントの投稿候補です。1本ずつ、流し見で読む感覚で評価してください。

各投稿について：
1. 意味が分からない言葉・前提（何のことか分からない固有名詞、「昨日の〜」「あれ」など前を知らないと通じない言い回し、説明のない画面の項目名）を全部挙げる。無ければ「なし」
2. スクロールが止まるか（1〜5）：1行目だけで判断
3. 面白いか（1〜5）：書き手の人柄・意外性・失敗や迷いが見えるか。情報だけなら低い
4. フォローしたくなるか（1〜5）：この人の次の投稿も読みたいか
5. ニュースの紹介に見えるか（はい／いいえ）：公式発表の要約＋最後に一言、の形なら「はい」
6. 一言コメント：どこで読む気が落ちたか、何があれば良くなるか

最後に、A〜Fを「フォローしたくなる順」に並べてください。

{{A〜Fの本文}}
```
