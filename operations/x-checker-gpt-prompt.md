あなたは、個人メディアの集客とWebツール企画に詳しい編集者兼プロダクト企画者です。次の前提で相談に乗ってください。

## 私について
- 非エンジニア。Claude Code（AIのコーディング支援）で、AI活用のブログメディアを運営している（記事は70本ほど）
- Xアカウントはフォロワー10人前後の小さなアカウント。目的はバズではなく「Claude Codeを実務に使っている非エンジニア」として認知され、記事 → 信頼 → コンテンツ運用代行の問い合わせにつなげること
- Webアプリ・ツールを作って公開したことは一度もない
- Claude Code のクラウド版の無料クレジットが残り約186ドル（11/5期限）。普段ならやらない挑戦に使いたい

## 作りたいもの（第一候補）：X投稿チェッカー
私は毎日のX投稿の前に、自作のチェックを通している。これを誰でも使えるWebツールにして公開したい。
- 文字数の重み（日本語は1文字2、英数字は1で数える。上限280）
- 1行目のチェック（1行目だけで何の話か分かるか、固有名詞があるか）
- 構成のチェック（報告型の語尾で終わっていないか、自分の話が真ん中にあるか、「昨日の」「前回の」のような前提を知らないと通じない言い回しがないか）
- 直近の投稿との重なり（同じ数字や目印の語が続いていないか）
- 条件：ブラウザだけで動く（AIのAPIを使わない＝公開後の費用ゼロ）、日本語、スマホで使える、自分のブログ（WordPress）に置くか別ページで公開

## ほかの候補（比較用）
1. 「自分の職種でClaudeは使える？」診断（サイトで一番読まれている記事の読者向け）
2. 「ClaudeとChatGPT、どっちに課金？」診断
3. 「Claudeのプラン、どれにする？」診断
4. 「この情報、AIに渡して大丈夫？」チェック
5. ブログ代行の相場計算機（「ブログ代行 相場」で検索表示が出ている＝問い合わせに近い）
6. Claude Code 用語の逆引き

## 聞きたいこと
1. **題材の判断**：X投稿チェッカーは、上の候補と比べて「非エンジニアが初めて作って公開する題材」として最善か。もっと良い案があれば、同じ条件（ブラウザだけ・費用ゼロ・私のメディアの読者に効く・私にしか無い材料）で新しい案を3つ出してほしい
2. **よくある「作ってみた」との差**：「非エンジニアがアプリを作った」話はXに大量にある。埋もれないために、作る過程と公開後に何を見せればいいか
3. **X投稿チェッカーの最小構成**：最初の公開版に入れる機能を3つまでに絞って、理由を添えて。既存の「X文字数カウンター」系ツールとの違いを1行で言えるように
4. **名前**：日本語で覚えやすいツール名を5案
5. **リスク**：Xの仕様変更（文字数の数え方など）、チェックの基準が私個人の好みでしかない問題、への対処
6. **X投稿の筋書き**：作り始め → 公開 → 使われた結果、を3〜4本の投稿で見せるなら、それぞれ何を書くか（1投稿ずつ単体で通じる形で。連投はしない）
