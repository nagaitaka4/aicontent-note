# AIっぽさチェック（AIっぽい文章チェッカー）

==文章のどこがAIっぽく読まれやすいかを、直し方の例つきで示す無料ツール==です。
AIが書いたかどうかの判定ではありません。
下の入力欄に文章を貼ると、その場で結果が出ます。

【ツールをここに表示】

---

## 使い方

・**貼り付ける**：X投稿・メール・ブログ記事など、文章を入力欄に貼ります。記事を丸ごと貼っても使えます
・**出た所を読み返す**：結果は「①AIっぽく読まれやすい所」「②伝わりにくい言い回し」「③X投稿の文字数」に出ます。出た所を読み返して、直すか決めます
・**自分でも読む**：0件でも、AIっぽさが残ることはあります。最後は「自分で確かめる所」を見ながら、声に出して読んでください

スマホでも、同じ画面で使えます。

---

## AIっぽく読まれやすい書き方と直し方

==AIっぽく読まれるのは、難しい単語より文の形のせい==です。ツールが見るのは、次の形です。

| ツールが見る所 | 例と直し方 |
|---|---|
| 「〜の要否」のように、動詞を名詞にまとめた言い方 | 「課金の要否」→「お金を払わないと使えない」 |
| 書き言葉の硬い言い回し | 「変更を余儀なくされた」→「変えるしかなかった」 |
| まとめ・つなぎの決まり文句 | 「ここまで3つの方法を説明してきました」「という点が重要です」→ 削って、言いたいことから書く |
| 何のことかが抜けた言葉（1行目） | 「明確なライン」→「どこまで似たらパクリかの線」 |
| 「◯◯は〜としています」と、資料の言い分で終わる文 | 読む人にとって何が変わるかまで書く |
| 決まった言い回しの繰り返し（「今振り返ると」「そう感じています」など） | 2回目を言い換えるか、削る |
| 文の始めのつなぎが多い | 「また、」「さらに、」「次に、」が3回 → 減らして、文を短く切る |
| 同じ文末が続く | 「〜ています。」が4文続く → 1つ変えるか、文をまとめる |
| 「〜させる」が続く | 「集めさせて、まとめさせた」→ 誰が何をするかを主語にして書く |
| 自分の話が最後だけ（X投稿） | 説明が続いて、最後に自分の一言 → 自分の話を真ん中に置く |

どれも、このサイトで記事とX投稿を書くときに、実際に直してきた形です。公開している記事70本で試し、ふつうの文章に出すぎる形は外しました。

## 入力した文章の扱い

| 対象 | 扱い |
|---|---|
| 入力した文章 | このツールから、どこにも送られません。AIも使っていません |
| 保存 | 入力した文章も設定も、どこにも保存しません。ページを閉じると消えます |
| アクセス解析 | このページにも、ほかのページと同じアクセス解析（Google アナリティクス）が入っています。ツールは、入力した文章をアクセス解析に渡しません（[プライバシーポリシー](https://aicontent-note.com/privacy-policy/)） |

---

## 使う前に知っておくこと

| 項目 | 内容 |
|---|---|
| AIの判定ではない | AIが書いたかどうかは判定しません。人が書いた文章に出ることも、AIが書いた文章で0件のこともあります |
| 出ても直す必要はない | 「NG」ではなく「確認してほしい所」です。読み返して通じるなら、そのままで大丈夫です |
| ツールでは分からないこと | 内容がおもしろいか、言いにくくないか、1行目だけで話が通じるか（1行目は一部の形だけ拾います）。誤字、炎上しそうな表現、事実の誤りも見ていません |
| 日本語向け | ①と②は、日本語の文章向けです |
| X投稿の文字数 | 通常のポスト用（上限280）です。日本語は1字を2と数えるので、日本語だけなら140字までです。Xの公式の数え方（[twitter-text](https://github.com/twitter/twitter-text/blob/master/config/v3.json)のv3・2026年9月30日時点）に合わせています。新しい絵文字の一部や、日本語を含むURLは、Xの表示とずれることがあります。違うときは、Xの投稿画面の表示を優先してください |
