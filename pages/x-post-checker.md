# 投稿まえチェック（X投稿チェッカー）

Xに投稿する前の確認に使える、無料のブラウザツールです。==文字数に加えて、前の投稿を知らないと伝わりにくい言い回しと、直近の投稿との重なりも確認できます==。
Xの文字数は、日本語だけなら140文字、半角英数字だけなら280文字までです。

【ツールをここに表示】

---

## 何を確認できるか

| 確認 | 見るもの |
|---|---|
| 文字数 | Xの数え方で数えます。ツールには「140 / 280」のように、使った数と上限が出ます（日本語70字なら140） |
| 要注意表現 | 「昨日の」「前回の」のように、前の投稿を知らないと伝わりにくい言い回し。1行目が「〜しました」の報告で終わっていないか。1行目に「これ」「それ」「あれ」がないか |
| 直近の投稿との重なり | 保存した直近14日（7日・30日にも変えられます）の投稿と、同じ数字・同じ語・似た文章がかぶっていないか。同じ話を何度もしていないかに気づくための確認です |

文字数の数え方は、次のとおりです。

| 文字の種類 | 数え方 |
|---|---|
| 日本語・全角の文字・半角カタカナ・絵文字、→や★のような記号 | 1つで2 |
| 半角の英数字・記号（!?@など）・スペース | 1つで1 |
| URL | 長さに関係なく23 |

要注意表現と重なりは、「NG」ではなく「確認してほしい所」として出します。直すかどうかは、あなたが決めます。

初めて読む人は、前の投稿を知りません。昨日の続きです のような言い方や、報告だけで始まる1行目は、読む気が起きにくいと考えています。

たとえば、次のように出ます。

| 入れた文章 | 出る表示 |
|---|---|
| 昨日の続きです。やっと完成しました | 要注意表現に2件（昨日の／1行目が報告で終わっている） |
| 下書き：100ドルのプランを1か月使った感想です ／ 保存済みの投稿：月100ドルのプランに課金しました。使い道を書きます | 直近の投稿との重なりに1件（数字つきの語が同じ：100ドル） |

---

## 使い方

・**貼り付ける**：下書きを入力欄に貼ると、その場で文字数が出ます
・**出た所を見る**：「要注意表現」と「直近の投稿との重なり」に出た所を見て、直すか決めます
・**投稿したら保存する**：「投稿した → 保存」を押すと、次の下書きから比べられます
・**過去の投稿を入れる**：「まとめて追加」で、直近の投稿を一度に入れられます。最初は保存した投稿がないので、重なりは出ません
・**設定を変える**：「見る項目を選ぶ」でチェックの項目を、「比べ方の設定」で比べる期間を変えられます

スマホでも、同じ画面で使えます。

---

## 入力した文章と、保存した投稿の扱い

| 対象 | 扱い |
|---|---|
| 入力した文章 | 書いた文章は、このツールからどこにも送られません。AIも使っていません |
| 保存した投稿 | このブラウザの中にだけ残ります。スマホとパソコンでは共有されません。ブラウザのサイトデータを消すと消えます |
| アクセス解析 | このページにも、ほかのページと同じアクセス解析が入っています。ツールは、入力した文章をアクセス解析に渡しません（[プライバシーポリシー](https://aicontent-note.com/privacy-policy/)） |

## 使う前に知っておくこと

| 項目 | 内容 |
|---|---|
| 対象 | 通常のポスト用（上限280）です。Premiumの長文ポストには対応していません |
| 文字数の数え方 | Xが公開している文字数の計算プログラム（[twitter-text](https://github.com/twitter/twitter-text/blob/master/config/v3.json)）と同じ数え方にしています。2026年9月30日に確認しました。Xの仕様が変わると、ずれることがあります |
| ずれるかもしれないもの（新しい絵文字） | 2019年以降に追加された絵文字のうち、複数の絵文字をつないだものや、肌の色がついたものです。ハートに炎がついた絵文字は、ツールでは5と出ます |
| ずれるかもしれないもの（ファイル名） | 「CLAUDE.md」「README.md」「main.py」のように、「.md」「.py」で終わる言葉です。計算プログラムはURLと見て、23と数えます |
| ずれるかもしれないもの（日本語のURL） | パスに日本語が入るURLです。例：https://ja.wikipedia.org/wiki/日本 は、日本語の分が上乗せされて27と出ます |
| 迷うとき | 3つとも、実際のXと違うかもしれません。ツールの数字は、たいてい大きめに出ます。迷うときは、Xの投稿画面の表示が正解です |
| 要注意表現 | 日本語の投稿向けです。文字数のほうは、日本語以外の投稿でも使えます |
| ツールでは分からないこと | 内容がおもしろいか、1行目だけで話が通じるか。1行目はツールが要注意表現の欄の上の方に出すので、自分で読んで確かめてください |

## このツールについて

毎日のX投稿の前に、伝わりにくい言い回しがないか、最近の投稿とかぶっていないかを自分で見ていました。毎回やるならツールにしようと思い、AIのコード作成ツール「Claude Code」で作りました。

・作るときにAIを使っただけで、ツールが動くときにAIは使っていません
・入れたのは、自分が投稿前に見ている項目です。基準は自分で決めたので、合わないこともあります
