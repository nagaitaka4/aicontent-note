# 採用課題企業への営業戦略

## 戦略の概要

ハローワーク求人DBを活用して「採用に困っている企業」をリスト化し、
「求人を出しているのに、会社サイトの情報発信が止まっている」を切り口に営業する。

サービス自体は「ブログ記事更新代行」のまま変えない。
変えるのは営業の切り口とターゲティングだけ。

---

## このアイデアの評価

### 強み
・ハローワークは無料・公開・継続更新される自己補充型リスト
・採用課題が顕在化している企業だけが並んでいる（自分で掘らなくていい）
・「今まさにお金を使っている or 使いたい状態」の企業に絞れる
・競合のブログ運用代行業者がこの発想で営業しているケースはほぼない

### 弱点
・ブログ更新と採用成功の因果関係を証明する実績がまだない
・最初の数社は実績作りと割り切って動く必要がある

---

## ROIの説明軸

### 求職者の動線
ハローワークで求人を見る → 社名で検索する → HPを確認する → 「この会社どうだろう」と判断する

### ブログが止まっている場合
「最近どうなの？」という不安が生まれ、離脱につながる

### ブログが動いている場合
「ちゃんと動いている会社」という安心になり、応募につながる

### ROIの数字
・人材紹介の採用単価：数十〜数百万円
・自社サイトで採用できれば、その費用が丸ごと浮く
・月4〜8万のブログ運用費との対比で費用対効果が説明しやすい

### 「応募が増えた」の実態
劇的な変化ではなく、月1〜2人の応募が安定して来るようになるイメージ。
それでもハローワーク頼みだった企業には十分な変化。

## 営業メールの形式（2026-08-17確定・⚠️適用範囲に注意）

> **2026-08-19注記**：この形式は**ブログ運用代行を売る場合**の設計。中心商品がサイトリニューアルの営業（新モデル）では、初回メールの主役は完成記事ではなく**ファーストビュー試作**にする（記事はタイトル提示のみ、完成記事はAランク企業か返信後）。詳細は `operations/gpt-strategy-session-2026-08-19-2.md`。

**提案書ではなく、その会社の記事を1本完成させて送る。**A評価10件に絞り、全件に送る（件数を絞ることで全件本気が成立する）。

### 送り方

| 項目 | 決定 | 理由 |
|---|---|---|
| 形式 | **プレーンテキスト・本文直貼り** | HTMLメールは迷惑メール判定率が上がる。個人ドメインからの初回HTMLメールは届かない確率が高い |
| 画像 | **入れない** | 多くのメールクライアントが既定で画像をブロックする。表示されない枠だけが残り逆効果 |
| 添付 | **なし** | 開かれない・スパム判定される |
| リンク | **なし** | 知らない差出人のURLは踏まれない。サイトへの限定公開もNG（許可なく他社の記事をネット上に置くリスク） |
| 見出し | `■ 見出し` の記号で構造を出す | H1/H2の構造はテキストでも伝わる |
| 長さ | **1,500〜2,000字** | メール本文で読み切れる。かつ「月4本のうちの1本」の実物サンプルとして正確な分量 |
| 品質 | **本気（そのまま公開できる状態）** | 半分本気は最悪。「この程度か」と思われたら逆効果 |

装飾を削るのは手抜きではない。**テキストの方が「個別に書いた」感が出る**ため、狙い（予想外性・本気度）と一致する。HTMLは一斉配信の営業メールに見える。

### 2手目（返信が来てから）

初回で全部出さない。返信後に渡すもの：

- 入稿できる形（見出し装飾つき）
- アイキャッチ画像1枚
- **他に書ける2本のテーマ**（「次も出せる」＝運用を売っていることを見せる）

### 制作時間の想定

1本あたり1.5時間前後（リサーチ30分・構成15分・執筆仕上げ45分）。10件で約15時間。**要実測**。

## サービスのポジション

SEOで流入を増やす話ではない。
すでに興味を持っている人（ハローワーク経由）を離脱させないための更新。

「SEOより、止めないブログ更新をするのが優先」が正しい整理。
月4本のブログ更新で最大化できる採用サポートが目的。

---

## コンテンツバランス（月4本の場合）

| 本数 | 種類 | 内容 |
|---|---|---|
| 1本 | 採用・職場系 | 職場環境・働き方・チームの雰囲気 |
| 2本 | サービス・実績系 | 事業内容・事例・強み |
| 1本 | お役立ち系 | FAQ・業界情報・よくある質問 |

採用記事と明示しなくても、サービス・実績記事は「この会社がどんな仕事をしているか」を伝える採用コンテンツとして機能する。

### ヒアリングについて
・基本：初回ヒアリング → 月初に構成案 → クライアントは確認のみ
・オプション：月1回のヒアリングでその会社らしいコンテンツを取る（クライアント希望の場合のみ）

## アプローチ方法

### 優先順位
1. お問い合わせフォーム（確実に届く）
2. メール（フォームがない場合）
3. SNS（相手がアクティブと確認できた場合のみ補助的に）

### 営業文の切り口
「求人を出しているのに、会社サイトの情報発信が止まっている」

## 進め方

1. まず10社を手動でリストアップ
2. CCがURL調査・スコアリング・営業文作成
3. 4項目の精度確認（従業員数推定・更新日・採用中・優先度）
4. 精度が高ければ数を増やす
