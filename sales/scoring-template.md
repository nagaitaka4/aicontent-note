# 企業調査・スコアリングテンプレート

## 使い方

1. ユーザーが会社名とURLをリスト化して渡す
2. CCがWebFetchで1社ずつ調査して以下の全項目を埋める
3. 営業優先度A/B/Cを判定し、初回営業文を生成する
4. ユーザーが最終判断・送信

---

## テンプレート

```
会社名：
URL：
業種：
所在地：
地方企業か：
従業員規模の推定：（会社概要ページから。記載なければ推定・不明と記載）
採用中か：（ハローワーク求人 or 採用ページの有無で判断）
ブログ・お知らせの有無：
最終更新日：
更新停止期間：
WordPress利用有無：（HTMLソースで判定）
採用ページの有無：
施工事例・事例ページの更新状況：
お問い合わせフォーム：あり / なし
メールアドレス記載：あり / なし
連絡手段：（フォーム / メール / 電話のみ / なし）
【ブログ運用代行】営業優先度：A / B / C / 除外
【HP制作営業】対象か：対象 / 除外
提案切り口：
初回営業文：
```

## スコアリング基準

### ブログ運用代行

| 判定 | 条件 |
|---|---|
| A | WordPress ＋ ブログ停止6ヶ月以上 ＋ 採用中 ＋ 地方 ＋ 連絡手段あり |
| B | WordPress ＋ ブログ停止あり ＋ 採用中（停止期間が短い・連絡手段が電話のみ等、条件が一部弱い） |
| C | WordPress ＋ ブログはあるが更新が月1以下 ＋ 採用中 |
| D | ブログ活発に更新中 / WordPress以外 / 採用していない / 連絡手段なし |

### HP制作営業

| 判定 | 条件 |
|---|---|
| A | WordPress以外の古いサイト（fc2・静的HTML等）＋ 採用中 ＋ フォームorメールあり |
| B | WordPress以外 ＋ 採用中 ＋ 連絡手段が電話のみ |
| C | WordPress以外だが採用は一時的・パートのみ |
| D | HPなし / 連絡手段なし / 大企業 / WixやJimdo等の比較的新しいサイト |

### 振り分けルール

| 分類 | 条件 |
|---|---|
| ブログ運用代行リスト | WordPress ＋ ブログ停止 ＋ 採用中 → A/B/Cで判定 |
| HP制作営業リスト | WordPress以外 ＋ 採用中 → A/B/Cで判定 |
| 除外（D） | HPなし / 連絡手段なし / 両サービスとも対象外 |

---

## WordPress判定方法（CC調査時）

以下のいずれかが確認できればWordPress判定：
・URLに `/wp-content/` `/wp-includes/` が含まれる
・HTMLに `<meta name="generator" content="WordPress">` がある
・`wp-json` エンドポイントが存在する

---

## 優先度判定基準

| 優先度 | 条件 |
|---|---|
| A | 求人中 ＋ ブログ停止半年以上 ＋ WordPress ＋ 地方 |
| B | 求人中 ＋ ブログ停止 ＋ WordPress以外 or 更新停止期間が短い |
| C | 求人中だがブログあり or 更新頻度が低い程度 |
| 除外 | HPなし / 大企業 / ブログ活発に更新中 / WordPress非対応（HomepageBuilder・静的HTML・fc2・Jimdo等） |

---

## 初回営業文のベース

以下を企業ごとにカスタマイズして生成する。

```
件名：貴社のホームページについてご提案があります

はじめまして。ブログ記事更新代行を行っております○○と申します。

ハローワークで貴社の求人を拝見し、ご連絡いたしました。
貴社のホームページを確認させていただいたところ、[最終更新日]以降
ブログ・お知らせの更新が止まっているようでした。

求人に応募を検討している方は、ハローワークの情報だけでなく
会社のホームページを必ず確認します。
ブログが更新されていない状態は「最近どうなのか」という不安につながり、
応募をためらわせる原因になることがあります。

弊サービスでは、月4記事のブログ更新を代行します。
初回ヒアリングをもとに記事テーマを設計し、
クライアント様の作業は月初の内容確認のみです。

まずはお気軽にご相談ください。

[お問い合わせURL or メールアドレス]
```
