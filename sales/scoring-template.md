# 企業調査・スコアリングテンプレート

## 前提条件

- 新卒・既卒求人で検索済みのリストのため、**全社が採用中**。「採用中かどうか」はスコアリング条件に含めない。

---

## スコアリング基準

### ブログ運用代行

| 判定 | 条件 |
|---|---|
| A | WordPress ＋ ブログ停止6ヶ月以上 ＋ 記事が5本以上存在する ＋ フォームorメールで連絡可 |
| B | WordPress ＋ ブログ停止あり ＋ フォームorメール（停止期間が短い・記事が少ない等、条件が一部弱い） |
| C | WordPress ＋ ブログはあるが更新が月1以下 |
| D | ブログ活発に更新中 / WordPress以外 / 電話のみ / 連絡手段なし |

### HP制作営業

| 判定 | 条件 |
|---|---|
| A | ① WordPress以外 ＋ スマホ非対応（非レスポンシブ） ＋ フォームorメールで連絡可<br>② WordPress以外 ＋ サイト全体をCCが低品質と判断 ＋ フォームorメールで連絡可<br>③ HPなし ＋ メールアドレスが判明している |
| B | WordPress以外 ＋ スマホ対応済み ＋ フォームorメールで連絡可 |
| C | WordPress以外 ＋ 電話のみ |
| D | HPなし＋連絡手段不明 / WixやJimdo等の比較的新しいサイト / 連絡手段なし |

### ロゴ制作営業

| 判定 | 条件 |
|---|---|
| A | ロゴが文字のみ / 明らかに古い・低品質とCCが判断 ＋ フォームorメールアドレスが判明 |
| B | ロゴが古い・改善余地あり ＋ 電話のみ |
| C | ロゴはあるが改善余地あり（軽微） |
| D | ロゴが新しい・問題なし / HPなし＋連絡手段不明 / 連絡手段なし |

```
会社名：

ロゴ評価：新しい / 古い / 文字のみ / なし
ファビコン：あり / なし
連絡手段：
　- フォーム：あり（URL）/ なし
　- メール：あり（アドレス）/ なし
　- 電話：あり / なし
【ブログ運用代行】判定：A / B / C / D
【HP制作営業】判定：A / B / C / D
【ロゴ制作】判定：A / B / C / D
```

---

## 連絡手段の記載ルール

| 種別 | 記載内容 |
|---|---|
| フォーム | URLをそのまま記載（例：https://example.com/contact） |
| メール | アドレスをそのまま記載（例：info@example.com） |
| 電話のみ | 「電話のみ」と記載 |
| なし | 「なし」と記載 |

---

## WordPress判定方法

以下のいずれかが確認できればWordPress判定：
・URLに `/wp-content/` `/wp-includes/` が含まれる
・HTMLに `<meta name="generator" content="WordPress">` がある
・`wp-json` エンドポイントが存在する

## 初回営業文のベース

### ブログ運用代行

```
件名：貴社のホームページについてご提案があります

はじめまして。ブログ記事更新代行を行っております○○と申します。

ハローワークで貴社の求人を拝見し、ご連絡いたしました。
貴社のホームページを確認させていただいたところ、[最終更新日]以降
ブログ・お知らせの更新が止まっているようでした。

求人に応募を検討している方は、ハローワークの情報だけでなく
会社のホームページを必ず確認します。
ブログが更新されていない状態は「最近どうなのか」という不安につながり、
応募をためらわせる原因になることがあります。

当サービスでは、月4記事のブログ更新を代行します。
初回ヒアリングをもとに記事テーマを設計し、
クライアント様の作業は月初の内容確認のみです。

まずはお気軽にご相談ください。

[フォームURL or メールアドレス]
```

### HP制作営業

```
件名：貴社のホームページのリニューアルについてご提案があります

はじめまして。ウェブサイト制作を行っております○○と申します。

ハローワークで貴社の求人を拝見し、ご連絡いたしました。
貴社のホームページを確認させていただいたところ、
スマートフォンからご覧になると表示が崩れる状態のようでした。

現在、求人応募の多くはスマートフォンから行われています。
サイトが見づらいと、応募前に離脱してしまう可能性があります。

リニューアルのご提案など、まずはご相談だけでも歓迎です。

[フォームURL or メールアドレス]
```
