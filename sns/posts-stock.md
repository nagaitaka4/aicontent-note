# X投稿 ストック

## 運用ルール

- 投稿前に内容・文字数を確認する（目安：100〜140文字）
- 投稿したら「状態」を `draft` → `posted` に更新し、投稿日を記入
- ネタは随時追加。副業検証に動きがあればすぐ実況型を書く
- リンク型は記事公開のたびに1本セットで作る

## Xのポジション（最重要）

- Xは記事への「カジュアルな入口」。記事は真剣に読ませる場所。
- X投稿は告知・宣伝にしない。読んだ人が「あるある」「気になる」と感じる内容にする
- 気づき型でも実況型でもリンク型でも、トーンは常にカジュアル・ラフ・本音ベース
- リンク型も「記事書きました」ではなく、読みたくなる入口として設計する
- 記事は真面目でいい。Xはその手前の引き込みの場所

## 投稿パターン早見表

| 種別 | 目的 | 頻度 |
|---|---|---|
| 気づき型 | 単体で価値を出す。フォロワーに刺さる | 週2〜3本 |
| 実況型 | 副業検証の進捗。「記事にします」で記事へ誘導 | 随時 |
| リンク型 | 気づき＋リンク。告知だけにしない | 記事公開時 |

---

## トーン指針

- カジュアル寄り・入りやすい・肩苦しくない
- 失敗談もポジティブに着地させる
- 絵文字は感情アクセントとして1個まで
- 語尾：「〜しました」「〜でした」をベースに、常体混在OK
- 基本は絵文字なしでも成立する文章にする
- 黒猫キャラクターとして 🐱 / 🐾 は世界観に合わせて使用OK

### 絵文字ルール

- 😅 は連続使用しない
- 失敗感：🙈 / 🫠 / 😅
- 記録・検証：📝 / 🔍
- 気づき：💡 / 👀
- 猫キャラ感：🐱 / 🐾
- リンク型は絵文字なし〜1個まで
- 「絵文字なし7割・あり3割」を意識

### 強くする方向（追記）

- 「優等生な気づき」より「リアルな実務の違和感」を優先する
- 「楽しくなった」「面白かった」「景色が変わった」は避ける
- その瞬間の感情・数字・ビフォーアフターを出す
- 「仕組み」「止まらない」「運用」「継続」「回す」を定期的に再接続する
- 実況型は強い。「何がわからないのかも、わからなかった」レベルの初心者感はむしろ価値
- Xで強いのは：共感・驚き・失敗・本音・ギャップ・数字
