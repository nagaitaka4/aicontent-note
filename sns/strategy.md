# X 投稿戦略

## 開始タイミング

記事15本公開時点で開始（現在16本・開始条件クリア済み）

---

## 投稿パターン（3種類）

### ① 気づき型（メイン）

記事の核心を1投稿に凝縮する。リンクなしでも成立させる。
「この気づき単体で価値がある」状態にする。

```
例：
AIで記事を書いても、速くなったのは「処理」だけだった。
方向性を決める判断は、今も全部自分がやっている。
```

### ② 実況型

副業検証の進捗をそのまま投稿する。「記事にします」で記事への誘導。
起きたことをそのまま出す。加工しない。

```
例：
クラウドワークス、3件応募して1件が面談まで進んだ。
人見知りだけど、やってみる。記事にします。
```

### ③ リンク型

気づき＋リンクのセット。「詳しくはこちら」単体リンクはNG。

```
例：
記事構成はどこまで自動化できるのか、実際に検証しました。
ChatGPTとの一番の違いは「手戻りの少なさ」でした → [URL]
```

---

## 投稿頻度

| 種別 | 頻度 |
|---|---|
| 気づき型 | 週2〜3本 |
| 実況型 | 随時（副業検証に動きがあるとき） |
| リンク型 | 記事公開時 |

**目安：週3〜4本**

---

## ネタの探し方

- 記事を書くたびに「気づき」が1〜3個必ず出る → そのままXへ
- 副業検証シリーズの進捗が自動的にネタになる
- リサーチ中の発見・失敗・修正もそのままネタになる
- 「なんでこうなるんだろう」と思ったことをメモしておく

---

## やってはいけないこと

- 「記事を書きました！」だけの告知投稿
- 「詳しくはこちら」単体リンク
- 煽り・誇張表現（メディアのトンマナ違反）
- 返信・エンゲージメントを無視した一方的な発信
- うまく書こうとして投稿できなくなること
